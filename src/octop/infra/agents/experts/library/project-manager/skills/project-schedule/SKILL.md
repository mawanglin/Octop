# 排期与甘特图

> `scripts/` 和 `references/` 路径相对于本技能目录；示例：`references/example-tasks.md`。

## 1. WBS 拆解

- 按交付物拆（需求文档、设计稿、前端、后端、测试报告），不按部门拆。
- 每个任务 1–10 个工作日，有唯一负责人和完成标准（"接口文档评审通过"而不是"写接口"）。
- 不确定的任务用三点估算：(乐观 + 4 × 最可能 + 悲观) ÷ 6。
- 里程碑（评审、上线）工期写 0。

## 2. 任务表

```markdown
| 编号 | 任务 | 负责人 | 工期 | 前置任务 | 进度 |
|------|------|--------|------|----------|------|
| 1 | 需求调研 | 张三 | 5 | | 100% |
| 6 | 测试用例编写 | 钱七 | 4 | 2+2 | 0% |
| 8 | 上线 | 张三 | 0 | 7 | |
```

- 前置任务写编号，多个用逗号；`2+2` 表示任务 2 完成后再过 2 个工作日开始。
- 进度可选，用于跟踪。

## 3. 排期

```bash
python scripts/gantt.py outputs/project/任务.md --start 2026-11-02 -o outputs/project/项目排期.xlsx [--holidays outputs/project/节假日.txt] [--today 2026-11-20]
```

- 默认周一到周五工作；`--holidays` 文件每行一个日期（法定节假日）；调休上班日暂不支持，可用 `--weekends` 后手工调整。
- 终端：总工作日、完成日期、关键路径、各任务浮动时间；`--today` 时列出按计划应完成比例与实际进度相差 20% 以上的任务，并说明是否影响完成日期。
- Excel「排期」：最早 / 最晚开始结束、浮动、是否关键；「甘特图」：按日期的色块图，横向一页打印。

## 4. 解读

- 浮动时间 = 最晚开始 − 最早开始；为 0 的是关键任务，任何延误都会推迟项目。
- 压缩工期：把关键路径上的任务并行（快速跟进，有返工风险）或加资源（赶工，有成本）；非关键任务落后但未超过浮动时间，不影响完成日期。
