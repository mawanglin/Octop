# PPT 策划与大纲

## 1. 澄清（一次问全，最多 3 个问题）

| 维度 | 默认值（用户没说时） |
|------|----------------------|
| 用途 / 场合 | 内部工作汇报 |
| 受众 | 直属领导和同级团队 |
| 页数 / 时长 | 10–15 页；按每页 1–2 分钟估算 |
| 风格 | 商务蓝（`business-blue`），16:9 |
| 素材 | 只用用户给的内容；缺的地方占位 |

用户已经给出的信息不要再问。材料齐全或用户说"直接做"时，不提问，直接用默认值并在大纲开头一行写明。

## 2. 选故事线

| 结构 | 适用 | 骨架 |
|------|------|------|
| 结论先行（金字塔） | 汇报、决策请示 | 结论 → 3 个支撑论点 → 各论点证据 → 下一步/请求 |
| 问题-方案 | 方案提案、立项 | 背景 → 问题与影响 → 方案 → 收益/成本 → 计划 → 需要的支持 |
| 时间线 | 项目复盘、年度总结 | 目标回顾 → 阶段进展 → 成果数据 → 问题与教训 → 下阶段计划 |
| 对比选型 | 采购、技术选型 | 需求 → 候选方案 → 维度对比表 → 推荐及理由 → 风险 |
| 教学 | 培训、课件 | 学习目标 → 概念 → 示例 → 练习/要点回顾 |
| 路演 | 融资、产品发布 | 痛点 → 方案 → 市场 → 产品 → 商业模式 → 团队 → 里程碑 → 请求 |

## 3. 逐页大纲格式

给用户看的大纲用表格，一页一行：

| # | 版式 | 标题（结论句） | 内容要点 | 数据/素材 |
|---|------|----------------|----------|-----------|
| 1 | cover | 2026 Q3 业务复盘 | 副标题：增长放缓的原因与三项动作 | — |
| 2 | kpi | 营收增长 18%，未达 25% 目标 | 营收 / 留存 / 获客成本 | 〔待补充：Q3 营收〕 |

规则：

- 标题是**完整的结论句**，读标题串起来就能看懂整份 PPT。
- 版式从 `ppt-build` 支持的列表中选：cover、agenda、section、bullets、two-column、cards、kpi、chart、table、timeline、image、quote、closing。
- 第 1 页 cover；超过 8 页加 agenda；最后一页 closing 或"下一步/需要的支持"。
- 每页只讲一件事；一页内容超过 6 条要点就拆页。
- 用户给的长文档：先提炼成 3–5 个核心观点，再分配到页面，不要逐段搬运原文。
- 数据缺失写〔待补充：xx〕，并在大纲后汇总"需要用户补充的数据"。

## 4. 交接给 ppt-build

大纲确认后（或用户要求直接出稿），按 `ppt-build` 技能写 spec 并生成文件。用户修改大纲时只改相应行，不必重写整份大纲。
