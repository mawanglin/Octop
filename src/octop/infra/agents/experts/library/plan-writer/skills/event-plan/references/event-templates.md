# 活动流程模板与物料清单

## 年会（约 3 小时）

| 时间 | 环节 | 说明 |
|------|------|------|
| 17:30–18:00 | 签到、暖场 | 签到墙、合影、暖场视频 |
| 18:00–18:10 | 开场 | 开场 VCR、主持人开场 |
| 18:10–18:25 | 领导致辞 | 年度回顾与展望 |
| 18:25–18:55 | 颁奖（一） | 优秀员工、优秀团队 |
| 18:55–20:00 | 晚宴 + 节目 | 节目穿插抽奖 |
| 20:00–20:20 | 颁奖（二） | 年度特别奖 |
| 20:20–20:40 | 大奖抽奖、合唱 | 高潮收尾 |

物料：签到墙、背景板、奖杯证书、抽奖系统、礼品、节目道具、音响灯光、餐饮、伴手礼。

## 团建（1 天）

集合出发 → 破冰游戏（30 分钟）→ 团队协作项目（2 小时）→ 午餐 → 自由活动或第二个项目 → 分享与颁奖 → 返程。物料：分组标识、游戏道具、急救包、保险（户外必须）、交通。

## 产品发布会（约 1.5 小时）

| 环节 | 时长 | 说明 |
|------|------|------|
| 签到、媒体接待 | 30 分钟 | 媒体区、资料袋 |
| 开场视频 | 3 分钟 | 品牌/产品预热 |
| 主讲（产品发布） | 30 分钟 | 产品亮点、演示 |
| 嘉宾/客户分享 | 15 分钟 | 背书 |
| 价格与上市信息 | 5 分钟 | |
| 媒体问答 | 15 分钟 | 发言口径提前统一 |
| 体验区开放 | 30 分钟 | 产品试用、合影 |

物料：主视觉 KV、LED 屏、演示设备、样机、新闻通稿、媒体资料袋、直播设备。

## 促销活动

活动机制（满减、折扣、赠品、抽奖，写清规则和适用范围）→ 预热（D-7）→ 正式期 → 返场。注意：促销规则清晰，"最低价""限时"等用语符合《广告法》和平台规则；奖品价值、抽奖规则合法合规。

## 展会

展位设计（面积、主视觉、功能区：展示、洽谈、体验）→ 展品清单 → 人员排班 → 获客方式（扫码登记、礼品）→ 会后跟进（48 小时内联系线索）。

## 培训

培训需求 → 目标 → 课程安排（时间、主题、讲师、形式）→ 学员管理（报名、签到、分组）→ 考核方式 → 培训评估（反应、学习、行为、结果四级）。
