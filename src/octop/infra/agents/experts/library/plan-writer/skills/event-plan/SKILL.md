# 活动策划方案

各类活动的流程模板和物料清单见 `references/event-templates.md`（相对本技能目录）。

## 1. 方案结构

1. **活动概述**：名称、主题（一句话 + 释义）、时间、地点、对象和人数、主办/承办。
2. **活动目标**：2–3 个可衡量的目标（参与人数、满意度、线索数、销售额、传播量）。
3. **活动内容与流程**：流程表（时间、环节、内容、负责人、所需物料）。
4. **宣传推广**（对外活动）：渠道、节奏（预热、引爆、长尾）、物料。
5. **执行排期**：倒排表（见下）。
6. **组织分工**：总负责、各组（策划、物料、场地、接待、宣传、安全）负责人和职责。
7. **物料与场地清单**：名称、规格、数量、负责人、到位时间。
8. **预算**：明细表（交给 `plan-export` 生成 Excel），列出预算合计。
9. **风险预案**：风险、可能性、影响、预防措施、应急方案、负责人。
10. **效果评估**：评估指标、数据来源、复盘时间。

## 2. 倒排执行表

```markdown
| 时间节点 | 事项 | 负责人 | 完成标准 |
|----------|------|--------|----------|
| D-30 | 方案定稿、预算审批 | 〔策划组〕 | 方案签批 |
| D-21 | 场地、供应商确定并签约 | 〔场地组〕 | 合同签订 |
| D-14 | 宣传启动、报名开放 | 〔宣传组〕 | 报名页上线 |
| D-7 | 物料到位、节目彩排 | 〔物料组〕 | 物料清点 |
| D-1 | 场地布置、全流程彩排 | 全体 | 彩排完成 |
| D | 活动执行 | 全体 | 按流程表执行 |
| D+3 | 复盘、费用结算 | 〔策划组〕 | 复盘报告 |
```

D 为活动日，交付时换算成具体日期。

## 3. 常见风险与预案

天气（户外活动准备室内备选场地/雨具）、人数偏差（报名确认 + 签到控流）、嘉宾或演员缺席（备用节目/备用嘉宾）、设备故障（备用音响投影、技术人员在场）、安全（急救箱、医护联系人、疏散路线、餐饮食品安全）、舆情（对外活动的发言口径）。

## 4. 写法提示

- 主题要有记忆点，但先保证与目的一致（年会重凝聚和激励，发布会重产品信息）。
- 流程表的时间精确到 5 分钟，每个环节写明主持串场和物料。
- 预算控制：先按预算上限倒推档次，再分配到各项；预留 5%–10% 预备费。
