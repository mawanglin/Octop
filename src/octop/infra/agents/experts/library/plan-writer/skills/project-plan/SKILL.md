# 项目方案

## 1. 实施方案 / 工作方案

1. **背景与依据**：为什么做（问题、政策或战略依据，注明文件名称）。
2. **总体目标**：总目标 + 分阶段目标，量化（"到 2026 年底，线上办理率达到 90%"）。
3. **主要任务**：分条，每条写"任务内容 + 牵头单位/负责人 + 配合单位 + 完成时限"。可用表格：

| 序号 | 任务 | 牵头 | 配合 | 时限 |
|------|------|------|------|------|

4. **实施步骤**：动员部署 → 组织实施 → 检查评估 → 总结提升，每阶段写时间段和工作内容。
5. **保障措施**：组织领导、资金保障、制度保障、督查考核、宣传引导。
6. **附件**（可选）：任务分解表、进度表、预算表。

政府部门的工作方案交给「政务公文专家」按国标排版（`--style gov`），并用公文的层次序数"一、（一）1."。

## 2. 可行性研究报告

1. 项目概况（名称、承办单位、建设内容、规模、周期、投资）；
2. 必要性分析（需求、现状问题、政策依据）；
3. 市场/需求分析（数据要注明来源）；
4. 建设方案/技术方案（方案比选，至少 2 个备选并说明选择理由）；
5. 实施进度；
6. 投资估算与资金筹措（交给 `plan-export` 生成预算表）；
7. 效益分析（经济效益：投资回收期、净现值等，只在用户提供基础数据时计算；社会效益）；
8. 风险分析（技术、市场、政策、财务、实施风险及对策）；
9. 结论与建议。

## 3. 项目建议书（立项）

简版可研：项目背景与必要性 → 项目内容与目标 → 初步方案 → 投资估算 → 预期效益 → 实施计划 → 需要的支持。篇幅控制在可研报告的 1/3。

## 4. 写作要点

- 目标、任务、步骤、预算一一对应，避免"任务里有、预算里没有"。
- 时限写具体日期或月份，不写"近期""适时"。
- 财务测算：只用用户提供的数据和明确的假设计算，假设单独列出；不编造市场规模和增长率。
- 风险分析：每个风险都给出应对措施和责任人。
