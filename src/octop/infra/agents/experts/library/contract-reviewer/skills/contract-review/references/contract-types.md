# 常见合同类型审查重点

> 条款范例中的数字（比例、天数）仅为常见做法的参考，应结合交易实际协商确定。

## 采购合同（用户为买方）

- 质量标准和验收：明确标准（国标/行标/样品/技术参数），到货验收 + 质保期；
- 付款：预付比例不宜过高，尾款与验收挂钩，保留质保金（常见 5%–10%）；
- 交付：逾期交付违约金、迟延超过一定天数买方可解除；
- 质保：质保期、响应时间、更换或退货条件；
- 知识产权担保：卖方保证产品不侵犯第三方权利。

## 销售合同（用户为卖方）

- 付款保障：预付款、分期、逾期付款违约金和利息、所有权保留（付清前所有权归卖方）；
- 验收期限：约定买方验收期限，逾期未提出异议视为验收合格；
- 责任上限：赔偿责任以合同总价为限，排除间接损失；
- 收货确认：签收单作为交付凭证。

## 服务 / 技术开发合同

- 服务范围和交付物清单（附件化），需求变更的程序和费用；
- 里程碑与付款节点挂钩；
- 成果知识产权：定制开发成果归委托方，开发方保留通用组件并授予永久使用许可；
- 源代码、文档交付；数据安全和保密；
- 运维服务等级（SLA）：响应时间、可用率、违约扣款。

## 租赁合同

- 租赁物现状、用途限制、转租条件；
- 租金调整、押金退还条件和期限；
- 维修责任划分；提前解约的条件和违约金；
- 到期续租优先权、装修物处理。

## 劳动合同 / 劳务合同

- 区分劳动关系和劳务关系；
- 试用期期限与合同期限匹配（按《劳动合同法》规定，建议核实）；
- 工作内容地点、工时、薪酬构成、社保；
- 竞业限制：范围、期限、补偿金；
- 违约金只能在法律允许的情形下约定（服务期、竞业限制），其他情形约定无效的风险。

## 保密协议

- 保密信息定义和标识方式；例外情形（已公开、独立开发、依法披露）；
- 保密期限（合同终止后仍持续若干年）；
- 返还或销毁义务；违约责任和禁令救济。

## 合作 / 框架协议

- 合作范围、各方投入和分工；
- 收益分配和结算方式；
- 排他性、竞业；
- 框架协议与具体订单的关系、优先适用顺序；
- 退出机制。

## 通用条款范例

**争议解决（对用户有利）**：因本合同引起的争议，双方应协商解决；协商不成的，任何一方均可向〔用户所在地〕人民法院提起诉讼。

**责任上限**：除故意或重大过失外，任何一方在本合同项下的累计赔偿责任不超过本合同总价款，且不包括间接损失、预期利益损失。

**通知送达**：双方确认本合同首页地址、联系人、电子邮箱为有效送达地址，一方变更的应提前〔5〕个工作日书面通知对方。
