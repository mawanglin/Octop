# AI Agent 产品卖点提炼

## 1. 先收集产品信息（缺什么就问）

| 项目 | 要问清楚的 |
|------|-----------|
| 产品 | 名称、一句话定位、是 App / 小程序 / 网页 / 企业部署 |
| 能做什么 | 3–5 个最常用的任务，每个任务的输入和输出（"说一句话 → 得到一份周报"） |
| 给谁用 | 主力人群、行业、公司规模；谁付钱、谁使用 |
| 证据 | 真实用户数、案例、内部测试数据（数据来源和条件）、资质、获奖 |
| 价格和转化 | 免费额度、试用期、价格；投放的转化目标（下载 / 注册 / 表单 / 私信 / 直播间） |
| 投放 | 平台、预算级别、素材形式（真人口播 / 数字人 / 纯录屏）、时长 |
| 不能说的 | 法务或品牌方明确禁止的说法；接入了哪些大模型、能否公开 |

**没有证据的数字不写进口播**；用户只给了"大概省一半时间"，写成"很多原来要半天的活，几分钟就能出初稿"，或者请用户提供测试条件。

## 2. 卖点公式：能力 → 场景 → 结果

AI Agent 的用户不关心"多智能体""工作流编排"，只关心"我的哪件事被解决了"。

| ✗ 能力说法 | ✓ 场景 + 结果说法 |
|-----------|------------------|
| 支持多 Agent 协作 | 你说一句"整理本周销售数据发群里"，它自己查表、做图、发消息 |
| 接入 50+ 工具 | 表格、文档、邮件、企业微信，常用的软件它都能帮你操作 |
| 基于大模型的智能客服 | 半夜来的咨询它先接住，常见问题自动回复，复杂的转给你 |
| RAG 知识库 | 把公司资料丢进去，新员工有问题直接问它，不用再翻文件 |
| 自动化工作流 | 每天早上 9 点自动把昨天的数据整理好放到你桌面上 |

一条素材只讲**一个**核心卖点，讲透；其余卖点留给其他版本测试。

## 3. 人群 × 痛点 × 卖点

| 人群 | 典型痛点 | 卖点方向 | 开口方式 |
|------|----------|----------|----------|
| 中小企业老板 | 招人贵、人员流动、重复工作多 | 降本、一个人顶一个小团队的部分工作 | "老板们，你公司还在花钱请人做……吗" |
| 销售 / 客服 | 线索跟不过来、半夜咨询没人回 | 不漏客户、自动跟进 | "客户半夜发消息，你是不是第二天才看到" |
| 电商卖家 | 上新、写详情、回评价、做数据 | 省时、多店铺批量处理 | "一个人管三个店，你每天睡几个小时" |
| 自媒体 | 选题、写稿、剪辑、多平台分发 | 产能翻倍、稳定更新 | "日更累不累" |
| HR / 行政 | 筛简历、排面试、做报表 | 把重复事务交出去 | "一天看两百份简历是什么体验" |
| 财务 | 对账、报销审核、月报 | 准确、省时、可追溯 | "月底对账又要熬几个通宵" |
| 开发者 | 重复编码、写测试、查文档 | 效率、可控、能接入现有系统 | 直接演示，少说形容词 |

## 4. 价值量化（只写能证实的）

- 时间：同一个任务"以前 × 小时 → 现在 × 分钟"，并在字幕注明"以内部测试为例，实际因数据量而异"；
- 成本：可以说"把重复工作交给它"，不要说"省下一个员工的工资""取代人工"；
- 规模：真实的用户数、企业数、调用次数，注明截止日期；
- 效果：不承诺涨粉、出单、收入，只描述产品做了什么。

## 5. 演示画面：让人一眼看懂"它真的会自己干活"

1. **一句话下任务**：录屏特写输入框，任务要具体（"把这 50 条评价按好评差评分类，差评原因做成表"）；
2. **展示过程**：快进显示它一步步执行（打开文件 → 处理 → 生成结果），关键步骤放大；
3. **结果特写**：最终产出要清晰可读，停留 1–2 秒；
4. **前后对比**：左手工、右 AI，或者计时器对比；
5. 演示用真实产品录屏，不用效果图冒充；涉及客户数据要脱敏。

## 6. 信任和异议

| 用户心里的疑问 | 口播里怎么回应 |
|---------------|---------------|
| AI 靠谱吗，会不会乱来 | 展示它的执行过程和结果；"每一步你都能看到，关键操作会先问你" |
| 数据安全吗 | 只说真实的措施：数据存储位置、权限控制、可私有化部署；不说"绝对安全" |
| 难不难用 | "会打字就会用"，演示从注册到完成第一个任务 |
| 贵不贵 | 免费试用、按需付费；用"先免费试一个任务"降低门槛 |
| 跟 ChatGPT / 豆包有什么区别 | 聊天工具给建议，它直接帮你做完（只在确属事实时这样对比，不贬低他人） |
