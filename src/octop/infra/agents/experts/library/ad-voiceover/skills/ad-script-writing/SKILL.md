# 投流口播写作

> 示例稿：`references/example-scripts.md`（含两个可用版本和一个反面示例），路径相对于本技能目录。

## 1. 投流口播和自然流的区别

| | 自然流（涨粉、内容） | 投流（获客、转化） |
|--|------------------|------------------|
| 目标 | 完播、互动、关注 | 点击、留资、注册、付费 |
| 节奏 | 可以铺垫、讲故事 | 3 秒内说清"跟你有关"，15 秒内演示价值 |
| 结尾 | 引导关注、评论 | 明确的下一步：点哪里、得到什么 |
| 产出 | 一条精品 | 一次写 3–6 个版本，用数据挑 |
| 约束 | 平台社区规范 | 广告审核 + 广告法，拒审直接浪费时间 |

## 2. 六种结构模板（30 秒为例）

| 结构 | 段落 | 适合 |
|------|------|------|
| 痛点演示型 | 痛点提问（0–3s）→ 产品登场 + 一句话任务（3–8s）→ 录屏演示（8–20s）→ 结果和价值（20–25s）→ 行动引导（25–30s） | 通用首选 |
| 数字结果型 | 结果数字开场（"3 分钟做完周报"）→ 演示怎么做到 → 价值 → 引导 | 效率类卖点 |
| 反常识型 | "别再自己××了" → 原因 → 新做法（产品）→ 演示 → 引导 | 点击率高，注意承接 |
| 对比型 | 左右分屏或前后对比：手工 vs AI → 差距 → 引导 | 直观，但不能贬低具体竞品 |
| 老板自述型 | "我是做××的，以前……现在……" → 演示 → 推荐 | 真实用户或创始人出镜；必须真实 |
| 场景故事型 | 一个具体场景（半夜来客户咨询）→ 问题 → AI 接住 → 结果 → 引导 | 客服、销售类 Agent |

## 3. 前 3 秒钩子库

- **提问**："你还在每天手动整理销售日报吗？"
- **喊人群**："做电商的老板注意了。"
- **数字结果**："3 分钟，做完一份周报。"
- **反常识**："别再让员工复制粘贴了。"
- **痛点场景**："客户半夜发消息，你第二天才看到？"
- **演示先行**：开头直接给结果画面，口播"这份报表是 AI 自己做的"。

钩子要和后面的内容一致：开头说"3 分钟做周报"，演示的就必须是做周报。钩子和落地页不一致会带来高点击、低转化。

## 4. 时长和字数（语速约 4.5 字/秒）

| 时长 | 字数 | 写法 |
|------|------|------|
| 15 秒 | 约 60 字 | 钩子 + 一个演示结果 + 引导，适合再营销和已认知人群 |
| 30 秒 | 约 130 字 | 主力时长，完整走一遍痛点演示型 |
| 60 秒 | 约 260 字 | 讲 1 个场景 + 2 个演示，适合高客单价、需要教育的人群 |

口播句子要短，一口气不超过 18 字；少用英文术语，必须用时紧跟一句解释。

## 5. 行动引导（按转化目标写）

| 转化目标 | 引导写法 |
|----------|----------|
| 下载 / 安装 | "点击下方链接下载，注册就送××次免费使用" |
| 注册试用 | "点下方链接，免费先让它帮你做一份××试试" |
| 表单 / 预约演示 | "点左下角预约，顾问一对一帮你配好第一个流程" |
| 私信 / 加微 | "评论区扣‘日报’，私信发你使用教程" |
| 直播间 | "点头像进直播间，现场演示你的场景" |

引导里的权益必须和落地页一致；免费额度、赠送内容写清条件。

## 6. 平台差异

| 平台 | 投放后台 | 口播注意 |
|------|----------|----------|
| 抖音 | 巨量引擎 | 节奏最快，前 3 秒决定成败；竖屏、大字幕 |
| 视频号 / 朋友圈 | 腾讯广告 | 人群偏成熟、偏职场，真实可信比花哨重要；可承接企业微信 |
| 快手 | 磁力引擎 | 语言更接地气、口语化，老铁式的直接 |
| 小红书 | 聚光平台 | 种草笔记感，"亲测分享"的第一人称，避免硬广腔 |
| B 站 | 效果广告 | 用户反感硬广，演示和干货为主，可以稍长 |

具体素材规格、审核细则以各平台最新说明为准。

## 7. 三种形式

- **真人口播**：可信度最高；出镜人需授权，不能冒充用户或专家；
- **数字人口播**：成本低、可批量出版本；必须按规定标注"AI 生成"，数字人形象和声音要有授权；
- **纯录屏 + 配音**：最能展示产品，适合工具类；开头加一句人声钩子提升停留。

## 8. 一稿多版和格式

每次至少出 3 个版本，变量**一次只改一个**（只换钩子，或只换卖点），才能从数据里看出是哪个因素起作用。版本命名和测试矩阵见 `ad-test-review`。

稿件统一用下面的格式（`ad_script_check.py` 按此检查）：

```markdown
---
产品: 产品名
平台: 抖音
时长: 30
数字人: 否
---

## A｜痛点开场
画面：……
口播：……
```
