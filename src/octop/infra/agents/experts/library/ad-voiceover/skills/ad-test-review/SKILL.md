# 素材测试与数据复盘

> `scripts/` 和 `references/` 路径相对于本技能目录；示例数据：`references/example-report.csv`。

## 1. 生成测试矩阵

```bash
python scripts/ad_test.py matrix --product 小智 --hooks 痛点,数字,反常识,对比 \
  --points 省时,降本,零门槛 --ctas 免费试用,预约演示 --durations 15,30 --max 12 -o outputs/投流/测试矩阵.xlsx
```

- 组合数超过 `--max` 时均衡抽样：先保证每个钩子、卖点、引导、时长都至少测到一次，再尽量平均；
- 素材命名统一为 `日期_产品_钩子_卖点_引导_时长_序号`，**在投放后台创建素材时照抄这个名字**，复盘时才能按维度汇总；
- 产品简称和各维度取值里不要有下划线。

## 2. 复盘投放数据

```bash
python scripts/ad_test.py review 投放后台导出.csv -o outputs/投流/复盘.xlsx
python scripts/ad_test.py review references/example-report.csv --min-spend 200
```

- 自动识别列：素材/创意名称、展示/曝光、点击、消耗/花费、转化/表单/注册/激活/线索；多天多行的同一素材会合并；
- `--fields` 指定素材名各段的含义（默认与 matrix 命名一致）；
- `--min-spend` 以下的素材标为"数据不足"。

## 3. 指标和判断

| 指标 | 公式 | 反映什么 |
|------|------|----------|
| 点击率 | 点击 ÷ 展示 | 开头和画面吸不吸引人 |
| 转化率 | 转化 ÷ 点击 | 口播承诺与落地页是否一致、人群是否精准 |
| 转化成本 | 消耗 ÷ 转化 | 最终看这个 |
| 千次展示成本 | 消耗 ÷ 展示 × 1000 | 竞争和人群贵不贵 |

| 结论 | 规则 | 怎么做 |
|------|------|--------|
| 放量 | 转化成本低于平均 20% 以上 | 加预算；保留钩子和卖点，衍生 2–3 个新版本 |
| 改开头 | 点击率不到平均一半；或转化率高但点击率偏低 | 中后段不动，只换前 3 秒 |
| 改承接 | 点击率不低但转化率明显偏低 | 检查口播承诺和落地页是否一致、引导是否清楚 |
| 关停 | 消耗超过平均转化成本 2 倍仍无转化，或转化成本超过平均 2.5 倍 | 停掉，记录原因 |
| 观察 | 接近平均 | 继续积累数据 |
| 数据不足 | 消耗低于阈值 | 不下结论 |

## 4. 复盘报告结构

1. 整体：消耗、转化、转化成本，与上周对比；
2. 优胜素材：哪几条、共同点（钩子类型、卖点、时长）；
3. 维度结论：哪类钩子、哪个卖点、哪种引导更好（注意样本量）；
4. 下周计划：放量哪些、关停哪些、新写哪些版本（列出新版本的变量）；
5. 素材疲劳：同一素材投放超过 1–2 周、点击率持续下降时提前准备替换。

结论要克制：样本少时差异可能只是随机波动，单条素材至少积累 2–3 倍目标转化成本的消耗再判断；不把相关当因果。
