# 投流合规与口播检查

> `scripts/` 路径相对于本技能目录。关键词检查只是提示：命中不等于违规，未命中也不代表一定过审。最终以平台审核和法律意见为准。

## 1. 运行

```bash
python scripts/ad_script_check.py outputs/投流/口播稿.md
python scripts/ad_script_check.py 口播稿.md --target 15 --rate 5 --json
```

- 有需要调整的地方时退出码为 3；
- 稿件格式见 `ad-script-writing` 第 8 节，`时长` 写在开头的元信息里，`数字人: 是` 会触发 AI 标识提醒。

## 2. 法律依据（以现行有效版本为准）

| 规定 | 要点 |
|------|------|
| 《广告法》第九条 | 不得使用"国家级""最高级""最佳"等用语 |
| 《广告法》第二十八条 | 虚假广告：商品或服务不存在、性能功能与实际不符、虚构使用效果等 |
| 《广告法》第三十八条 | 代言人只能推荐自己使用过的商品；不得利用不满十周岁的未成年人作代言人 |
| 《反不正当竞争法》 | 不得对商品性能、功能、用户评价等作虚假或引人误解的商业宣传 |
| 《互联网广告管理办法》（2023 年 5 月 1 日起施行） | 互联网广告应当具有可识别性，显著标明"广告" |
| 《个人信息保护法》 | 落地页收集手机号等信息要告知用途、取得同意，不得超范围收集 |
| 《生成式人工智能服务管理暂行办法》 | 向公众提供生成式 AI 服务的相关要求；宣传接入的模型和能力要属实 |
| 《人工智能生成合成内容标识办法》 | AI 生成合成的视频、音频（包括数字人、AI 配音）需按要求标识 |

## 3. AI 产品高频风险和改写

| ✗ 风险说法 | 问题 | ✓ 改写 |
|-----------|------|--------|
| 最强 / 第一款 / 遥遥领先的 AI 员工 | 极限用语 | 一个能帮你干活的 AI 助手 |
| 完全取代你的运营团队 | 夸大、易引发争议 | 把重复的整理、汇总工作交给它，团队专注更重要的事 |
| 100% 准确、永不出错 | 无法证实 | 每一步都能看到过程，关键操作会先确认 |
| 用它的老板都月入十万 | 收益承诺 | 不提收入，只讲它帮你做了什么 |
| ChatGPT 官方同款 / DeepSeek 内部版 | 冒用品牌 | 如确有接入：支持接入××大模型（与授权和事实一致）；否则不提 |
| 雷军都在用 | 冒用名人 | 删除 |
| 最后 3 个名额，明天涨价 | 虚假紧迫 | 属实才写，并能举证；否则改为"现在注册可免费试用" |
| 数据绝对安全，永不泄露 | 绝对承诺 | 数据加密存储，支持权限管理和私有化部署（按实际情况） |

## 4. 平台常见拒审原因

1. 极限用语、绝对化用语；
2. 效果、收益承诺，"保证""稳赚""躺赚"；
3. 素材内容与落地页、推广产品不一致；
4. 冒用他人品牌、商标、名人肖像，未授权使用影视音乐片段；
5. 虚构用户评价、假冒新闻报道或官方通知样式；
6. 诱导点击：假关闭按钮、假系统弹窗、假红包；
7. 数字人或 AI 配音未标识；
8. 资质缺失：涉及金融、教育、医疗等特殊行业需要对应资质。
