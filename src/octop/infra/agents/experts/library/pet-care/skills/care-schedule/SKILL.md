# 疫苗驱虫日程

> `scripts/` 路径相对于本技能目录。日程为常见兽医推荐，疫苗种类、品牌和间隔以兽医建议为准。

## 1. 幼宠（1 岁以内）

```bash
python scripts/pet_care.py plan --species dog --name 旺财 --birth 2026-08-20 -o outputs/pet/旺财日程.xlsx --ics outputs/pet/旺财提醒.ics
```

| 项目 | 狗 | 猫 |
|------|----|----|
| 核心疫苗 | 犬多联苗：8、12、16 周龄 | 猫三联：8、12、16 周龄 |
| 加强 | 首免完成 1 年后，之后每年（部分疫苗 3 年一次） | 同左 |
| 狂犬疫苗 | 16 周龄（约 4 月龄）首针，之后每年 | 同左 |
| 体内驱虫 | 12 周龄前每 2 周，3–6 月龄每月，之后每 3 个月 | 同左 |
| 体外驱虫 | 8 周龄起每月（按药品说明） | 同左 |

日期已经过去的项目会提示"请确认是否完成"，没有完成的请咨询兽医如何补种。

## 2. 成年宠物

```bash
python scripts/pet_care.py plan --species cat --name 咪咪 --birth 2023-05-01 \
  --last-core 2026-03-10 --last-rabies 2026-03-10 --last-deworm-in 2026-09-01 --last-deworm-out 2026-10-01
```

只提供部分记录时，缺少的项目会提示"尽快咨询兽医补种 / 驱虫"。`--months` 控制排多少个月（默认 12），`--days` 控制终端显示多少天内的待办（默认 30）。

## 3. 输出

- 终端：近期待办、已过期项目数量；
- Excel：日期、项目、说明、状态，以及"实际完成日期""医院 / 药品"空列，打完一针记一针；
- .ics：每项一个全天事件，提前 1 天提醒，导入手机日历即可。

## 4. 接种注意

接种前确认精神食欲正常、没有腹泻；接种后留观 30 分钟，一周内不洗澡、避免剧烈运动和应激；出现面部肿胀、呕吐、呼吸急促立即回医院。
