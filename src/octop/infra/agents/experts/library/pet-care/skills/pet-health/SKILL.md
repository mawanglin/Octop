# 日常照护与健康

> 一般性照护建议，不能代替兽医诊断；身体异常请及时就医。

## 1. 立即就医的危险信号

误食有毒物、呼吸困难或张口呼吸（猫）、持续呕吐或腹泻超过 24 小时、便血或吐血、公猫频繁蹲盆却尿不出、抽搐、昏迷、外伤大量出血、腹部迅速胀大（大型犬）、高处坠落、24 小时以上不吃不喝（猫更危险）。

就医前：记下症状开始时间、吃了什么（带上包装）、拍下呕吐物或异常排泄物照片，带上疫苗本。

## 2. 有毒食物和物品

| 类别 | 例子 |
|------|------|
| 食物 | 巧克力、咖啡、茶、葡萄和葡萄干、洋葱、大蒜、韭菜、木糖醇（口香糖）、酒精、夏威夷果、生面团、熟骨头（易刺伤） |
| 植物 | 百合（对猫极毒，花粉也不行）、绿萝、滴水观音、郁金香、杜鹃 |
| 药物和日用品 | 人用止痛退烧药（布洛芬、对乙酰氨基酚）、感冒药、老鼠药、杀虫剂、精油（对猫）、防冻液 |

## 3. 喂养

| 年龄 | 每天次数 | 说明 |
|------|----------|------|
| 2–3 月龄 | 4 次 | 幼犬 / 幼猫粮，可泡软 |
| 3–6 月龄 | 3 次 | |
| 6 月龄–1 岁 | 2–3 次 | 1 岁左右换成年粮（大型犬可延后） |
| 成年 | 2 次 | 按包装推荐量和体型调整，零食不超过每日热量的 10% |

**换粮**：7 天过渡，新粮比例 25% → 50% → 75% → 100%。始终保证清洁饮水；猫可以多提供湿粮帮助饮水。

## 4. 洗护

- 洗澡：狗 2–4 周一次，猫一般不需要常洗；用宠物专用沐浴露，洗完彻底吹干。
- 刷牙：每天或隔天，用宠物牙膏（不能用人用牙膏）。
- 剪指甲：2–4 周一次，避开粉色血线。
- 梳毛：长毛品种每天梳。

## 5. 绝育

一般在 6 月龄左右（大型犬可能建议更晚），具体时机咨询兽医。术前禁食禁水按医院要求，术后戴伊丽莎白圈防舔伤口，7–10 天拆线前避免剧烈运动和洗澡。

## 6. 基础训练

- 原则：正向奖励（零食 + 表扬），每次 5–10 分钟，在行为发生后 1–2 秒内奖励；不打骂。
- 定点如厕：起床、饭后、玩耍后带到固定地点，成功立即奖励；失误时不惩罚，用除味剂清理。
- 不扑人：扑人时转身不理，四脚着地时再给关注。
