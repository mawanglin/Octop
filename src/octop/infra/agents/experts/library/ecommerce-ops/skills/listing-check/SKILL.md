# 标题文案自查

> `scripts/` 和 `references/` 路径相对于本技能目录；示例：`references/example-items.csv`。

## 1. 单个标题

```bash
python scripts/listing_check.py "夏季新款连衣裙女显瘦 法式碎花长裙 雪纺 度假风" --platform taobao --keywords 连衣裙,显瘦,碎花
```

## 2. 批量检查

```bash
python scripts/listing_check.py inbound/商品.csv --platform pdd -o outputs/shop/检查结果.xlsx
```

CSV 需要"标题"列；"卖点""详情"列一起检查违规词；"关键词"列（`|` 或 `,` 分隔）检查是否出现在标题中；"类目"列为化妆品、食品时增加对应检查。

## 3. 等级

| 等级 | 内容 | 处理 |
|------|------|------|
| 违规 | 极限用语（最、第一、顶级、国家级、唯一…）、医疗功效（治疗、根治、降血压、减肥…）、诱导好评和站外引流（好评返现、加微信…）、普通食品宣称保健功能 | 必须删除或改写 |
| 风险 | 纯天然、无添加、100%、有机、进口、专利、孕婴可用等需要证明的宣称；化妆品美白、祛斑、防晒、防脱等特殊功效 | 有检测报告、认证、注册证时可以用，否则删除 |
| 建议 | 长度过长或过短、重复词、特殊符号、核心关键词未覆盖、多个商品标题完全相同 | 按需优化 |

## 4. 改写示例

- "全网最低价" → "限时特惠"；"顶级面料" → "100% 桑蚕丝面料（附检测报告）"；"根治痘痘" → 删除（普通化妆品不能宣称治疗）。
- 关键词筛查只能发现常见问题，不能替代平台审核和法律意见；新规则以平台公告为准。
