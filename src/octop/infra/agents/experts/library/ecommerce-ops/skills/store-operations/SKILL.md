# 店铺运营

## 1. 标题公式

**核心词 + 属性词 + 卖点词 + 场景 / 人群词**，例如：连衣裙（核心）+ 雪纺 碎花 长款（属性）+ 显瘦（卖点）+ 度假 女夏（场景人群）。

- 关键词来源：平台搜索下拉框、搜索发现、生意参谋 / 商家后台的搜索词数据、竞品标题（只借鉴通用词，不用竞品品牌词）。
- 重要的词放前面；不重复堆砌；同一款不同 SKU 不要用完全相同的标题。
- 写完用 `listing-check` 自查。

## 2. 主图与详情页

1. 首屏：核心卖点 + 价格利益点（主图五张：卖点、细节、场景、规格、售后保障）；
2. 痛点：买家担心什么（尺码、质量、效果）；
3. 卖点：3–5 个，每个配图和证据（检测报告、材质、工艺）；
4. 规格参数和使用说明；
5. 售后：退换政策、发货时间、客服时间。

## 3. 活动策划

| 步骤 | 内容 |
|------|------|
| 目标 | 清库存 / 拉新 / 冲销量 / 提升客单价，设定可衡量的数字 |
| 玩法 | 满减、第二件半价、优惠券、限时折扣、赠品、会员价 |
| 测算 | 活动价 − 成本 − 平台扣点 − 物流 − 优惠 = 单件利润，确认不亏或可接受 |
| 节奏 | 预热（收藏加购）→ 爆发 → 返场；库存和客服排班 |
| 复盘 | 目标完成率、流量来源、转化率、客单价、退款率 |

## 4. 核心指标与诊断

**销售额 = 访客数 × 转化率 × 客单价**

| 问题 | 先看 | 常见原因 |
|------|------|----------|
| 访客少 | 搜索曝光、点击率 | 标题关键词不匹配、主图不吸引、价格无竞争力 |
| 转化低 | 详情页停留、咨询转化、评价 | 卖点不清、差评、价格、尺码问题 |
| 客单价低 | 关联购买 | 缺少搭配和满减设置 |
| 退款率高 | 退款原因 | 描述不符、质量、尺码、物流 |

## 5. 客服话术

- 售前：先回答问题，再推荐（"这款偏小一码，您平时穿 M 建议拍 L"）。
- 催付：提醒库存或优惠时效，不骚扰，一次即可。
- 售后：先致歉和共情，给出明确方案和时间。
- 差评回复：感谢反馈 → 说明原因（不争辩）→ 给出处理方案 → 欢迎联系客服；不泄露买家信息，不诱导修改评价。

## 6. 合规红线

不刷单刷评、不好评返现、不虚假发货、不使用极限用语和虚假宣传、不侵犯他人商标和图片版权。
