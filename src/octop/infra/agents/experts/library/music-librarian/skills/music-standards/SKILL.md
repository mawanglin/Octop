# 音乐库规范

## 1. 目录结构（推荐）

```
音乐/
├── 周杰伦/
│   ├── 叶惠美 (2003)/
│   │   ├── 01 - 以父之名.flac
│   │   ├── 01 - 以父之名.lrc
│   │   └── cover.jpg
├── 群星/                      ← 合辑用"群星"/"Various Artists"作专辑艺术家
│   └── 中国好声音 (2012)/
└── 歌单/
```

- 一张专辑一个文件夹；专辑名后加年份，避免同名专辑混在一起。
- 多碟专辑：整理脚本目前不读取碟号，不同碟的同号音轨会被加序号区分；需要时在整理方案里把目标路径手动改到 `CD1/`、`CD2/` 子目录。

## 2. 标签字段

| 字段 | 规范 |
|------|------|
| 标题 | 歌名本身；"(Live)""(伴奏)"等版本信息可以保留在括号里 |
| 艺术家 | 演唱者；合唱写"周杰伦; 费玉清"（多数播放器用分号分隔） |
| 专辑艺术家 | 专辑的署名艺术家；**合辑统一写"群星"**，否则合辑会按每首歌的艺术家被拆散 |
| 专辑 | 专辑名，与官方发行名一致 |
| 音轨号 | 数字，如 1 或 1/10 |
| 年份 | 四位年份 |
| 流派 | 可选，同一类统一写法（流行 / Pop 二选一） |

## 3. 音质分级

| 级别 | 判断 | 建议 |
|------|------|------|
| 无损 | FLAC、APE、WAV、ALAC、DSD | 优先保留；APE 兼容性差，可建议转 FLAC（需要用户自己用工具转换） |
| 高码率 | MP3/AAC ≥ 256kbps | 日常收听足够 |
| 普通 | 192–256kbps | 可保留 |
| 低码率 | < 192kbps | 标记出来，建议用户寻找更好的版本 |

查重时同一首歌保留音质更好的版本。

## 4. 封面和歌词

- 封面：内嵌封面或专辑文件夹里的 `cover.jpg`（建议 500×500 以上）；体检中的"无封面"同时检查这两处。
- 歌词：与歌曲同名的 `.lrc` 文件（`01 - 以父之名.lrc`），或内嵌歌词；整理时 `.lrc` 会跟随改名。

## 5. 播放器兼容

Navidrome、Jellyfin、Plex、飞牛音乐都主要依据**标签**归类，目录结构只是辅助：标签不全时，目录整理得再好，播放器里也可能显示为"未知艺术家"。所以顺序是：查重 → 补标签 → 整理目录 → 让播放器重新扫描。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| 标签乱码（如"ºóÀ´"） | 老 MP3 的 GBK 编码被当成 Latin-1 读取；用 `tags-from-name` 从文件名补，或在标签方案里手工填写正确的"新值" |
| 合辑被拆成很多艺术家 | 把专辑艺术家统一设为"群星" |
| 同一专辑被拆成两张 | 专辑名或专辑艺术家写法不一致（全半角、空格、繁简）；统一写法 |
| 文件名带网站水印 | `tags-from-name` 的模式无法匹配时，先批量修正文件名或在标签方案里手工填写 |
| NAS 上整理后播放器没更新 | 在播放器里手动触发音乐库重新扫描 |
