# 体检对比

> `scripts/` 和 `references/` 路径相对于本技能目录；示例（虚构）：`references/example-checkup.csv`。

## 1. 录入数据

宽表（每年一列，适合指标固定的年度体检）：

```csv
指标,单位,参考范围,2024,2025,2026
总胆固醇,mmol/L,<5.2,5.0,5.4,5.9
幽门螺杆菌,,阴性,阴性,阳性,阴性
```

长表（每条一行，适合从不同医院的报告逐条录入）：`年份,指标,结果,单位,参考范围`。

- 参考范围以**每份报告上印的为准**（不同医院、不同性别可能不同），写法：`3.5-5.5`、`<5.2`、`≤1.7`、`>1.04`、`阴性`。
- 结果写报告上的数字或 阴性 / 阳性 / +；报告上的 ↑↓ 箭头不用抄。
- 指标名称尽量用报告原文，英文缩写也可以（ALT、LDL-C、HbA1c）。

## 2. 运行

```bash
python scripts/checkup_compare.py outputs/health/体检数据.csv -o outputs/health/体检对比.xlsx
```

终端输出三组：最近一次异常、连续两次及以上异常、连续三次越来越偏离；常见指标附通俗解释和一般就诊科室。Excel「历年对比」表中偏高 / 阳性标红、偏低标蓝，另有各组明细表。加 `--json` 输出结构化结果。

## 3. 解读要点

- 单次轻度超出参考范围很常见（饮食、熬夜、运动、采血前未空腹），建议 1–3 个月后复查。
- 连续异常、逐年变差、多个相关指标同时异常（如血脂四项、肝功能几项）更值得重视。
- 参考范围不等于治疗目标：已有糖尿病、冠心病等的人群，医生设定的目标值可能更严格。
- 所有解读不能代替医生诊断。
