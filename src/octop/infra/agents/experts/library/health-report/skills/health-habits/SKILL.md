# 健康习惯与就诊建议

> 以下为一般性健康建议，不能代替医生诊断和治疗；已确诊疾病或正在服药的，以主治医生意见为准。

## 1. 立即就医的危险信号

胸痛胸闷、呼吸困难、突发剧烈头痛、一侧肢体无力或口角歪斜、意识模糊、大量出血、报告标注“危急值”或医生电话通知复查——立即就医或拨打 120。

## 2. 常见异常的一般建议

| 情况 | 生活方式 | 复查 / 就诊 |
|------|----------|-------------|
| 血脂偏高 | 少吃肥肉、油炸、动物内脏和甜食，多吃蔬菜、全谷物、鱼；每周 150 分钟中等强度运动；戒烟限酒；控制体重 | 3–6 个月复查血脂；心内科或内分泌科评估心血管风险 |
| 空腹血糖偏高 | 控制精制碳水和含糖饮料，规律三餐，增加运动，减重 | 复查空腹血糖并查糖化血红蛋白，必要时做糖耐量试验；内分泌科 |
| 尿酸偏高 | 每天饮水 2000 ml 以上，少喝啤酒和含糖饮料，少吃动物内脏和浓肉汤，控制体重 | 1–3 个月复查；关节红肿热痛时看风湿免疫科 |
| 转氨酶偏高 / 脂肪肝 | 戒酒，减重 5%–10%，少熬夜，避免自行服用保健品和“护肝药” | 1–3 个月复查肝功能，查肝炎病毒和腹部 B 超；消化内科 / 肝病科 |
| 血压偏高 | 减盐（每天少于 5 克）、减重、规律运动、戒烟限酒、保证睡眠 | 家庭血压连续测量 1–2 周并记录；心内科 |
| 超重肥胖 | 每周减重不超过 0.5–1 公斤，饮食控制 + 运动 | 营养科；可交给「健身教练」制定计划 |
| 血红蛋白偏低 | 多吃瘦肉、动物血、深绿色蔬菜，女性注意月经量 | 血液科或消化内科查原因，不要自行补铁 |
| 甲状腺指标异常 | 不需要自行忌碘或补碘 | 内分泌科，结合甲功全套和 B 超 |
| 幽门螺杆菌阳性 | 分餐、使用公筷 | 消化内科评估是否需要根除治疗，家人可一起检测 |

## 3. 就诊准备

1. 带齐近几年的体检报告（或用 `checkup-compare` 生成的对比表）；
2. 写下想问的问题（“需要吃药吗”“多久复查”“饮食要注意什么”）；
3. 问清是否需要空腹（一般抽血前空腹 8–12 小时，可少量饮水）；
4. 正在吃的药和保健品列出来带给医生看。

## 4. 复查时间（一般情况）

| 异常程度 | 复查 |
|----------|------|
| 轻度超出、无症状 | 生活方式调整 3 个月后复查 |
| 明显超出或连续异常 | 1 个月内就诊 |
| 危急值、伴有症状 | 立即就医 |
