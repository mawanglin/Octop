# 论文结构与写作

## 1. 选题

好选题回答三个问题：**问题是什么**（具体、可研究）、**为什么重要**（理论或实践意义）、**能不能做完**（数据、方法、时间可行）。创新点可以是新问题、新方法、新数据或新场景，用一句话说清楚。

## 2. 章节结构

**学位论文（常见）**

1. 绪论：研究背景、问题提出、研究意义、研究内容与技术路线、论文结构
2. 文献综述 / 理论基础
3. 研究设计 / 方法
4. 结果与分析（可分多章）
5. 讨论（可与上章合并）
6. 结论与展望：主要结论、创新点、不足与展望

**期刊论文（IMRaD）**：引言 → 方法 → 结果 → 讨论（+ 结论）。

## 3. 各部分写法

| 部分 | 要点 |
|------|------|
| 摘要 | 目的、方法、结果、结论四要素；结果写具体数字；学位论文中文摘要一般 500–1000 字，期刊 200–300 字；不出现引用和图表 |
| 关键词 | 3–8 个，从题目和摘要中提取，由宽到窄 |
| 引言 | 漏斗结构：大背景 → 具体领域现状 → 现有研究不足（研究空白）→ 本文要做什么、怎么做、贡献 |
| 文献综述 | 按主题或观点组织，每段先给结论再列文献；比较不同研究的方法和结论；最后总结不足，引出本文研究 |
| 方法 | 写到别人能复现：研究对象、数据来源、样本量、变量定义、模型 / 实验步骤、工具 |
| 结果 | 只陈述发现，配图表；每个图表在正文中先提到再出现，并说明看出了什么 |
| 讨论 | 解释结果的含义，与已有研究比较，说明局限 |
| 结论 | 回答研究问题，不引入新数据，不夸大 |

## 4. 学术写作规范

- 客观表述，少用"我认为""显然"；用"结果表明""可能"区分事实和推断。
- 引用他人观点必须标注；直接引用加引号，转述也要标注出处。
- 图表有编号和标题（表题在上，图题在下），单位齐全。
- 缩略语首次出现写全称。

## 5. 开题与答辩

- 开题报告：选题依据、国内外研究现状、研究内容和方法、技术路线、进度安排、预期成果。
- 答辩：10–15 分钟讲清问题、方法、主要结论和创新点；准备"创新点是什么""方法为什么这样选""结果的局限""实际应用价值"等常见问题。
