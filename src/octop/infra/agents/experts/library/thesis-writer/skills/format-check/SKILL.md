# 论文格式检查

> `scripts/` 路径相对于本技能目录。

## 1. 运行

```bash
python scripts/thesis_check.py inbound/论文.docx
```

只读原文件。输出正文字数、标题数、图表数、引用数、参考文献条数和问题清单；加 `--json` 输出结构化结果。

## 2. 检查项

| 类别 | 检查内容 |
|------|----------|
| 章节 | "第一章 / 第1章 / 1"、"1.1"、"1.1.1" 是否连续、是否跳级（一级下直接出现三级） |
| 图表 | 图 2-1 / 表 3.2 / 图 1 是否连续、重复，每章是否从 1 开始，正文中是否提到 |
| 引用 | 正文 [n]、[n-m]、[n,m] 是否在参考文献范围内；每条参考文献是否被引用；首次引用顺序是否递增 |
| 摘要 | 是否有中文摘要、关键词、Abstract、Key words；关键词数量 3–8 个 |

## 3. 识别规则和限制

- 章节标题需使用 Word 的"标题 1/2/3"样式，或是以编号开头的短段落；Word 自动编号生成的数字读不到时会漏检。
- "参考文献"需要单独成段作为标题；其后到"致谢 / 附录"之前的段落视为参考文献条目。
- 字体、字号、行距、页边距、页眉页码等版式请对照学校模板人工确认。

## 4. 处理问题

逐条告诉用户位置和修改方法；引用顺序不对时，建议在参考文献管理软件中按引用顺序重新生成，而不是手动改号。
