# 平台与类型脚本

完整示例：`references/example-script.md`（相对本技能目录）。脚本格式见 AGENTS.md。

## 1. 平台差异

| 平台 | 用户与节奏 | 时长建议 | 写法要点 |
|------|------------|----------|----------|
| 抖音 / 快手 | 泛人群，划走快 | 15–60 秒 | 前 3 秒强钩子；信息密度高；每 3–5 秒一个画面变化；结尾引导互动 |
| 视频号 | 熟人社交、偏中年 | 30 秒–3 分钟 | 观点和故事更受欢迎；语气真诚，少用网络梗；适合知识、情感、正能量 |
| 小红书 | 女性为主、搜索种草 | 30 秒–2 分钟 | 真实体验感；"干货清单"结构；画面精致；标题含搜索关键词 |
| B 站 | 年轻、深度、弹幕文化 | 3–15 分钟 | 可以长，但要有章节和节奏点；欢迎梗和自嘲；结尾"一键三连" |

## 2. 结构模板（时长按 60 秒示例）

| 类型 | 结构 |
|------|------|
| 口播知识 | 钩子 0–3s → 痛点/问题 3–10s → 干货 1/2/3 10–50s → 总结+互动 50–60s |
| 观点 | 反常识结论 0–3s → 常见误区 → 我的观点+论据（案例、数据）→ 一句金句收尾 |
| 剧情 | 冲突开场 0–3s → 铺垫 → 反转 → 结局/笑点 → 点题（植入不超过 5 秒且自然） |
| 教程 | 成品展示 0–3s → 准备材料 → 步骤 1/2/3（每步特写）→ 常见错误 → 成品再现 |
| 测评 | 结论先行 0–3s → 测评维度 → 逐项实测（画面证据）→ 优缺点 → 适合谁 |
| Vlog | 场景钩子 → 时间线推进（3–5 个片段）→ 情绪高点 → 感悟/预告 |
| 带货 | 痛点 0–3s → 产品出场+核心卖点 → 使用演示（真实效果）→ 信任背书 → 价格与福利 → 下单指引 |

## 3. 写作要点

- **口播字数**：约 4 字/秒（60 秒约 240 字，留出停顿和纯画面时间则 200 字左右）。
- **画面**：写清楚拍什么（谁、在哪、做什么、特写还是全景），避免"相关画面"这类空话。
- **花字/字幕**：每段 1 句屏幕大字，提炼关键词，不超过 12 字。
- **节奏**：长段落拆成多个时间段；纯画面段（录屏、空镜）可以没有口播。
- **把文章改成视频**：只保留 1 个核心观点和 3 个支撑点，其余删掉；书面语全部改口语。

## 4. 交付清单

脚本正文 + 5 个标题 + 5–8 个话题标签 + 封面文案 + 评论区置顶话术（见 `hook-and-title`），再运行 `script-check` 的两个脚本。
