# 开头钩子与发布文案

## 1. 前 3 秒钩子（每次给 3 个不同类型）

| 类型 | 示例 |
|------|------|
| 结论前置 | "用这 3 个提示词，周报 10 分钟写完。" |
| 提问 | "周报写了一小时还是一片空白？" |
| 反常识 | "写得越详细的周报，越没人看。" |
| 冲突/悬念 | "老板看完我的周报，直接把我叫进了办公室。" |
| 数字承诺 | "30 秒教你一个 Excel 技巧，每天省 1 小时。" |
| 身份点名 | "做行政的姐妹一定要看完。" |
| 视觉冲击 | 画面先出成品/前后对比，口播一句"这是怎么做到的？" |
| 痛点共鸣 | "每次开会都被问'你这周干了啥'？" |

要求：口播 8–14 字；画面和口播同时给信息；不用"大家好，我是……"开场。

## 2. 标题（5 个）

- 抖音/视频号：12–20 字，结果 + 悬念（"3 个提示词，周报 10 分钟搞定，最后一个绝了"慎用夸张词）。
- 小红书：≤ 20 字，含搜索关键词，可带 1–2 个 emoji（"周报模板｜打工人 10 分钟写完周报📝"）。
- B 站：可长一些，信息完整，可带【】标签（"【效率】我用 AI 写了 3 个月周报，总结出这套流程"）。

## 3. 话题标签

5–8 个，组合：1–2 个大流量话题（#职场）+ 2–3 个垂直话题（#周报 #AI工具）+ 1–2 个长尾话题（#打工人效率）+ 活动话题（如有）。不堆砌无关热门话题。

## 4. 封面文案

≤ 12 字的大字，3 秒内能读完；与标题互补而不是重复（标题讲方法，封面讲结果）。给出版式建议：人物表情 + 大字，或前后对比。

## 5. 评论区置顶

一句补充信息或互动问题："提示词放这里了：……你们周报一般写多久？"

## 6. 爆款拆解与仿写

用户贴来爆款文案或描述时：
1. 拆结构：钩子类型、信息点顺序、节奏（每段秒数）、情绪曲线、结尾动作；
2. 总结可复用的"公式"；
3. 按用户的选题仿写**结构**，内容和表达全部原创，不搬运原文。
