# 脚本自查

> `scripts/` 路径相对于本技能目录。

## 1. 时长核对

```bash
python scripts/script_timer.py outputs/video/<标题>.md [--rate 4] [--target 60]
```

- 输出每段的时长、口播字数、需要的秒数和状态；
- "超出 x 秒"：口播装不进时间段，按提示删字或拉长时间段；
- "偏空"：口播不到时间段一半，确认是否本来就是纯画面段（录屏、空镜），否则补内容或缩短；
- 还会检查：时间段之间有无空档或重叠、每段有没有"画面："、钩子是否超过 3 秒或 16 字、总时长是否接近目标（front matter 的 `时长` 或 `--target`）。
- `--rate`：语速，默认 4 字/秒；语速快的博主可设 4.5–5。

退出码 3 表示有需要调整的地方，改完重跑。

## 2. 合规检查

```bash
python scripts/content_check.py outputs/video/<标题>.md
```

检查广告法极限用语（最、第一、顶级……）、医疗功效（根治、7 天见效……）、金融承诺（稳赚、保本……）、诱导分享关注、夸大表达。命中不一定违规，逐条结合语境判断，确属风险的改写。带货、健康、金融内容必须执行；平台规则以官方最新规范为准。

## 3. 交付前人工检查

- 开头 3 秒画面和口播是否同时有信息；
- 每 5–8 秒是否有变化点；
- 结尾是否只有一个明确动作；
- 出现的品牌、人物、音乐是否有授权（音乐建议用平台曲库）。
