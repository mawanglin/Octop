# 投标响应与自查

> `scripts/` 路径相对于本技能目录。

## 1. 技术方案目录（按评分标准调整）

1. 项目理解与需求分析：背景、目标、重点难点及对策
2. 总体方案 / 技术路线
3. 实施方案：分阶段工作内容、方法
4. 进度计划与保障措施
5. 质量保障、安全保障措施
6. 项目团队与人员配置（附证书清单）
7. 服务承诺与售后（响应时间、驻场、培训）
8. 类似业绩（附合同关键页）

**原则：** 每个评分项对应一个章节或小节，标题使用评分标准里的原话，评委翻到即见得分点；分值高的评分项写得最充分。

## 2. 点对点应答

技术要求逐条应答格式：

| 招标要求 | 投标响应 | 偏离 | 证明材料页码 |
|----------|----------|------|--------------|
| ★ 7×24 小时响应，故障到场不超过 2 小时 | 承诺 7×24 小时响应，故障 1.5 小时内到场 | 正偏离 | P45 |

- 不要只写"满足"，写出具体响应内容和承诺；
- 正偏离（优于要求）写清楚优于多少；有负偏离的必须告诉用户，★ 条款负偏离会导致投标无效。

## 3. 自查

```bash
python scripts/bid_check.py matrix outputs/bid/响应矩阵.xlsx
python scripts/bid_check.py doc outputs/bid/投标文件.docx --bidder "公司全称" --project-no ZB-2026-0815 --other "旧标书中的公司名" --deadline 2026-11-20
```

- matrix：★/否决/资格条款是否都填写了响应情况和页码、是否有负偏离、评分自评是否填完。
- doc：残留占位符（XX、【】、___、待定）、出现其他公司名称、投标人名称写法不统一、项目编号写错、落款日期晚于截止日或明显是旧日期、金额大写与小写不一致、不存在的日期。

## 4. 递交前清单

- [ ] 投标函、报价表金额一致，大小写一致，未超预算 / 最高限价
- [ ] 法定代表人证明 / 授权委托书齐全，授权代表身份证复印件
- [ ] 所有要求签字、盖章的位置已签章（含骑缝章）
- [ ] 资质、业绩、人员证书、社保、财务报表在有效期内且清晰
- [ ] 投标保证金已按要求缴纳，凭证附后
- [ ] 正本副本份数、电子版、密封和封面标识符合要求
- [ ] 电子招投标：CA 证书有效，文件已加密上传并确认回执
- [ ] 递交时间、地点、开标需要携带的原件
