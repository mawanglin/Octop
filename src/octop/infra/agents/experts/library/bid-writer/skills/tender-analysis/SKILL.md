# 招标文件解析

> `scripts/` 和 `references/` 路径相对于本技能目录；示例招标文件：`references/example-tender.md`（虚构）。

## 1. 运行

```bash
python scripts/tender_scan.py inbound/招标文件.docx -o outputs/bid/响应矩阵.xlsx
```

- 推荐使用 Word 版招标文件；PDF 需要文字版（扫描件请先做文字识别）。
- 终端输出关键信息、条款数量和评分合计；Excel 有三个工作表：
  - **关键信息**：每项带"核对"列，请对照原文确认；
  - **实质性条款**：类型（★实质性 / ▲重要 / 否决/无效 / 资格）、原文、位置、响应情况、偏离、投标文件页码、负责人；★ 和否决条款标红、▲ 标黄；
  - **评分标准**：评分项、分值、标准、自评得分、得分依据，带合计公式。

## 2. 识别规则

- ★ / ▲：段落开头（含编号后）的 ★ ▲ 标记。
- 否决 / 无效：含"否决投标""废标""无效投标""不予受理"等的条款；"出现下列情形之一的……无效"这类引导句下面的编号小条自动归为否决类。
- 资格：含营业执照、资质证书、类似业绩、信用中国、社保、财务报告等关键词的条款；"资格要求"章节下的编号小条自动归为资格类。
- 评分标准：表头含"分值/分数/满分"的表格；没有表格时识别"××（10 分）"形式的文字。

## 3. 解析后向用户汇报

1. **时间节点**：答疑截止、投标截止、开标时间，倒排准备计划。
2. **门槛**：资格要求逐条列出，标注需要用户确认是否具备的。
3. **★ 条款和否决情形**：逐条列出，强调任何一条不满足即无效。
4. **评分结构**：价格分、技术分、商务分占比；分值高的评分项是方案重点。
5. **疑问**：前后矛盾或不清楚的条款，建议在答疑期内书面提问。

## 4. 限制

自动提取依赖关键词和版式，可能漏掉写在长段落中间的要求、多抓非条款的描述；**必须对照招标文件原文逐条核对**，尤其是前附表、技术参数表和合同条款中的要求。
