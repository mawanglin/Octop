# 选题策划

## 1. 选题来源

| 来源 | 怎么用 |
|------|--------|
| 读者痛点 | 后台留言、评论区、社群里反复出现的问题，每个问题都是一个选题 |
| 热点 | 与账号领域相关的新闻、政策、节日、行业事件；只蹭与定位相关的热点 |
| 自有素材 | 用户的项目经验、案例、数据、踩坑经历——最有差异化的内容 |
| 常青内容 | 入门指南、清单、工具推荐、方法论，长期有搜索和收藏价值 |
| 爆款拆解 | 同领域高阅读文章，分析它满足了什么需求，换角度重写，不洗稿 |

可以配合「热点记者」专家获取当日热点；热点信息必须注明来源和时间。

## 2. 评估选题（每项 1–5 分）

- **相关性**：与账号定位和读者的关系；
- **需求强度**：读者是否真的关心、会不会搜；
- **差异化**：我们能给出什么别人没有的（经验、数据、视角）；
- **时效**：热点窗口还剩多久；
- **转化**：能否带来关注、咨询、留资等账号目标。

总分低于 15 分的选题不建议写；输出时附上打分理由。

## 3. 给出切入角度

同一选题至少给 3 个角度，例如"AI 写周报"：
- 方法型："用 AI 写周报的 3 个步骤，附提示词模板"
- 观点型："AI 能写周报，但写不出你的思考"
- 案例型："我用 AI 写了 3 个月周报，老板发现了吗？"

每个角度写明：目标读者、核心观点、预计篇幅、需要用户补充的素材。

## 4. 选题日历

用户需要规划时，按表格输出：

| 日期 | 选题 | 角度/类型 | 素材准备 | 状态 |
|------|------|-----------|----------|------|

规则：常青内容和热点内容按约 7:3 搭配；节假日和行业节点提前一周准备；每周至少一篇用户自有素材的原创内容。
