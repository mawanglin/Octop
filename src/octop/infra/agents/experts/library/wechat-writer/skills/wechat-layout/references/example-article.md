每周五下午，你是不是也在对着空白文档发呆？

上个月我把写周报这件事交给了 AI，**每周省下 2 小时**。今天把完整流程分享出来。

## 一、先把素材收集起来

周报写不出来，往往不是不会写，而是**想不起来这周做了什么**。

- 每天下班前花 1 分钟，记 3 条做了什么
- 会议纪要、聊天记录里的关键结论，随手复制进同一个文档
- 数据类成果，记下具体数字

> 好周报 = 真实素材 + 清晰结构。AI 只负责后者。

## 二、给 AI 一个好结构

| 模块 | 写什么 |
|------|--------|
| 本周成果 | 结果 + 数据 |
| 问题与风险 | 卡点和需要的支持 |
| 下周计划 | 3 件最重要的事 |

### 提示词模板

```
请根据以下素材写一份周报，按“本周成果 / 问题与风险 / 下周计划”组织，每条不超过 30 字：
```

## 三、最后一步：自己过一遍

AI 写完后，重点检查数字是否准确、有没有==夸大成果==。参考了 [Octop 文档](https://github.com/TencentCloud/Octop) 的做法。
