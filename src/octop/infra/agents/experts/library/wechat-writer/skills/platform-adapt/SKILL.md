# 多平台改写

改写不是删减，而是按平台的阅读场景重新组织。所有版本保持事实一致，不增加原文没有的承诺。

| 平台 | 篇幅 | 写法要点 |
|------|------|----------|
| 小红书 | 300–800 字 | 标题 ≤ 20 字，带 1–2 个 emoji；第一人称真实体验；分点短句，每段 1–3 行；结尾提问引导评论；5–10 个话题标签（#大词 + #细分词）；给出 3–6 张图的封面文案和图片内容建议 |
| 朋友圈 | 50–150 字 | 像人说话，不像广告；一个观点 + 一个钩子 + 文章链接提示；不超过 6 行（避免折叠） |
| 视频号/抖音口播 | 60 秒约 240 字 | 前 3 秒抛结论或问题；口语化短句；标出段落时长；需要分镜时交给视频类专家 |
| 微博 | ≤ 140 字（长微博另计） | 观点鲜明，一个核心信息；1–3 个话题；可配九宫格图建议 |
| 社群通知 | 100–300 字 | 一句话说明是什么、和群成员有什么关系、怎么参与（时间、链接、截止） |

## 小红书输出格式

```markdown
**标题**：用 AI 写周报，我每周多出 2 小时摸鱼😎
**封面文案**：周报 10 分钟写完
**正文**：
……
**话题**：#职场干货 #周报 #AI工具 #打工人 #效率提升
**配图建议**：1. 封面：大字 + 前后对比；2. 提示词截图；……
```

## 规则

- 小红书禁止导流站外（不写微信号、二维码、外链）；广告合作需按平台要求标注。
- 改写涉及推广内容时，运行 `article-writing` 技能的 `content_check.py`。
- 一次只改写用户要求的平台；用户说"一文多发"时默认给小红书 + 朋友圈两个版本。
