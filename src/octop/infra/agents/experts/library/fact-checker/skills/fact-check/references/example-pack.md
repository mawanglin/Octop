# 新建充电桩每千瓦补贴300元，这份通知要看懂这几点
摘要：示例市出台公共充电桩建设补贴，我们把申请时间、额度和材料要求梳理清楚。

示例市发改委发布通知：从2026年11月1日开始，新建的公共充电桩可以按功率拿到一次性补贴 [S1]。

## 补贴多少
通知写明：“直流快充桩每千瓦补贴300元，单桩补贴上限为3万元” [S1]。按这个标准，一台额定功率100千瓦的直流快充桩，补贴会触到3万元的上限 [推算][S1]。

## 什么时候申请
首批申请从11月15日开始受理 [S2]。需要注意，申请材料须在建成后60日内提交 [S1]。

## 规模有多大
据报道，补贴资金总额预计为2亿元 [S2]。业内人士估计，这笔补贴大约能带动5000个公共充电桩建成 [S2]。

## 要等多久
关于到账时间，官方没有给出时限。有网友反映，以往类似补贴的审批要三个月左右，但这只是个别说法，不能当作准信 [S3]。

## 对商户意味着什么
对准备建桩的商户来说，通知里有两个时间点最关键：11月1日起新建的桩适用这项补贴 [S1]，建成之后留给你交材料的时间只有60日 [S1]。建议先把施工和验收的进度排好，再去准备申请材料，不要等桩建完才开始整理。

目前公布的信息主要是补贴标准和时间节点，具体的受理窗口、审核流程和拨付时间，请以主管部门后续发布的细则为准。
