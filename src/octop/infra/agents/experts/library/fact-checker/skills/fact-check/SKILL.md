# 事实核验

> `scripts/`、`references/` 路径相对于本技能目录。

## 1. 四项检查

```bash
python scripts/claim_trace.py 文章包.md                      # 事实溯源
python scripts/overlap_check.py 文章包.md                    # 原创性
python scripts/compliance_check.py 文章包.md [--commercial]  # 合规
python scripts/format_check.py 文章包.md --platform wechat   # 格式
```

所有脚本都支持 `--json`；退出码 0 表示没有“必须处理”项，3 表示有，1 表示输入有误。

### 事实溯源 `claim_trace.py`

把初稿拆成句子，找出每句里的**数字**（含 %、万、亿的换算）、**日期**和**加引号的引语**（≥6 字），逐个到句子所标 `[S1]` 的来源摘录里核对：

| 结果 | 级别 | 含义和处理 |
|------|------|-----------|
| 引用错位 | 必须处理 | 内容在别的来源里，所标编号不对：改引用编号 |
| 缺来源编号 | 必须处理 | 句子没标 `[S#]`，但内容能在某条来源里找到：补上编号 |
| 对不上 | 必须处理 | 所标来源的摘录里找不到：可能写错或编造，退回核对 |
| 无出处 | 必须处理 | 句子没标来源，全文也没有来源提到它：补出处或删掉 |
| 引语对不上 / 不逐字 | 必须处理 | 引语必须和原文逐字一致（忽略空白标点）；会给出最接近的原文 |
| 存疑写成事实 | 必须处理 | 引用了“存疑”来源，句子里却没有“有网友反映/据称”这类限定语 |
| 需人工复算 | 请确认 | 句子标了 `[推算]`：由来源数字算出来的，核验员自己复算一遍 |
| 绝对化表述 | 请确认 | “最、第一、唯一、所有、首次”在被引用的摘录里没有，确认来源是否真这么说 |
| 名称/书名对不上 | 请确认 | 型号、英文名、《书名》没出现在摘录里，确认拼写 |
| 低可信来源 | 请确认 | 引用了 C/D 级来源，确认是否需要限定语或换来源 |

局限（报告里要写明）：只认阿拉伯数字，不识别“三百万”这类中文数字；只核对稿子和线索包是否一致，不能证明来源本身是真的；“带事实的句子”靠数字、日期、引语识别，纯观点和没有数字的断言脚本看不到，要人工读。

### 原创性 `overlap_check.py`

去掉标点和空白后，找出初稿里和来源逐字相同、≥18 字（`--min-run` 可调）的连续片段，统计占正文的比例；加引号的引语、标题和小标题不算。≥50% 必须处理，25%–50% 请确认。默认只比对摘录；要查得彻底，用 `--extra` 给出来源页面的完整正文。

### 合规 `compliance_check.py`

广告法极限用语、医疗功效、金融承诺、诱导分享、夸大表达、个人信息（手机号、身份证号、邮箱、银行卡号）、标题党、推广未标注，以及需人工把关的话题（用药建议、买卖建议、法律结论、未成年人）。`--commercial` 表示商业推广，极限用语升级为必须处理。**只是关键词提示**：引用官方原文时命中的词可以保留，但要加引号并标来源。

### 格式 `format_check.py`

按平台检查：`wechat` 标题 5–64 字、摘要 ≤120 字、正文 300–20000 字；`xiaohongshu` 标题 ≤20、正文 ≤1000、至少 1 个话题；`toutiao` 标题 5–30、正文 ≥300；`generic` 只查结构。数值是常见经验值，以平台后台提示为准，可用 `--title-max` 等参数覆盖。另外检查：空小标题、小标题层级跳级、过长段落、图片缺图注、http 图片、本地图片不存在、遗留的占位符（〔待核实〕、TODO、［…］）。

## 2. 文章包工具 `article_pack.py`

```bash
python scripts/article_pack.py validate 文章包.md     # 结构检查：来源字段、引用的编号是否存在、是否引用了不可用来源、核验报告是否过期
python scripts/article_pack.py hash 文章包.md          # 当前初稿的哈希，写进核验报告的“核验对象”
python scripts/article_pack.py show 文章包.md          # 一屏概览
python scripts/article_pack.py get 文章包.md 核验报告   # 取出某一节（贴进回复）
python scripts/article_pack.py put 文章包.md 核验报告 --file 报告.md
```

## 3. 脚本之外要人工看的

- 转述有没有走样：“部分”→“全部”、“可能”→“将”、“计划”→“已经”、“预计”→“确定”；
- 因果和相关性：来源只说“同时出现”，稿子写成“导致”；
- 范围和时间：来源说“某市”，稿子写“全国”；来源是去年的数据，稿子写成今年；
- 来源之间的矛盾有没有被抹平；
- 图片和图注、表格里的数字是否和来源一致（脚本只看正文）；
- 稿子是否把观点写成了事实。
