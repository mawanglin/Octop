# 月度、季度与项目汇报

## 结构（金字塔：结论 → 支撑 → 细节）

1. **总体情况**（3–5 句）：核心指标完成情况 + 一句话判断（超预期/符合预期/低于预期及主因）。
2. **关键指标**：用表格，列"指标 / 目标 / 实际 / 完成率 / 同比或环比 / 说明"。只放 3–8 个真正重要的指标。
3. **重点工作完成情况**：按目标或业务线分 3–5 条，每条"观点句 + 做法 + 结果数据"。
4. **问题与原因分析**：2–3 个主要问题，每个写现象（数据）→ 原因（直接/根本）→ 影响。
5. **下阶段计划**：与问题对应；每项写目标、关键动作、负责人、时间节点。
6. **需要的支持**（可选）：资源、政策、跨部门协调，具体到"需要谁、在什么时间前、提供什么"。

## 指标计算规则

- 完成率 = 实际 / 目标；同比 = (本期 − 去年同期) / 去年同期；环比 = (本期 − 上期) / 上期。
- 百分比保留 1 位小数，金额统一单位（万元/亿元），表格内单位写在表头。
- 用户只给了部分数据时，只计算能算的，其余标〔待补充〕；不倒推、不估算。
- 指标异常（波动超过 ±20%）时，正文必须给出原因或标"原因待分析"。

## 项目阶段汇报

结构：项目概况（目标、范围、周期、当前阶段）→ 里程碑完成情况（表格：里程碑 / 计划日期 / 实际日期 / 状态）→ 本阶段成果 → 风险与问题（等级、应对措施、负责人）→ 下阶段计划 → 需决策事项。状态用"正常 / 有风险 / 延期"三档，延期必须写新的预计日期。

## 写法提示

- 观点句提炼示例："渠道结构优化见效，获客成本环比下降 8%"，而不是"渠道工作情况"。
- 汇报对象是高层时：总体情况 + 关键指标表 + 需要的支持，控制在一页。
- 需要汇报 PPT 时：把定稿交给「PPT 设计专家」，指标表对应 kpi/chart/table 版式。
