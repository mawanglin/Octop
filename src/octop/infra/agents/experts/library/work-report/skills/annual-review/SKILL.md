# 年终总结与述职

## 1. 先做素材盘点

请用户提供（有多少用多少）：全年目标/KPI、各月或各季度汇报、项目清单、获得的认可（表扬、奖项、客户反馈）、学习成长、遇到的挫折。素材少时，按"季度 → 项目 → 成果"引导用户回忆，一次问不超过 3 个问题。

## 2. 年终总结结构

1. **年度概述**（一段）：岗位职责 + 全年最核心的 2–3 个成果（带数据）。
2. **主要工作和成绩**：按业务线或目标分 3–5 条，每条"观点句 + 关键举措 + 量化结果 + 典型案例"。最重要的放第一条。
3. **亮点与创新**（可选）：1–2 个超出岗位预期、可复制推广的做法。
4. **不足与反思**：2–3 条，具体到事和原因，配改进措施；不写"太追求完美"这类伪缺点。
5. **成长与收获**：能力提升、认证、带教。
6. **来年计划**：目标（可衡量）+ 关键举措 + 需要的资源支持。

## 3. 述职报告（面向评审/考核）

- 第一人称；开头说明岗位、任职时间、职责范围。
- 履职情况按"职责 → 举措 → 结果"展开，结果优先写业务指标、其次写过程指标。
- 机关事业单位述职通常包含：思想政治表现、履职情况、作风建设、廉洁自律、存在不足、努力方向——此时建议交「政务公文专家」排版。
- 时长控制：口头述职 5 分钟约 1100–1200 字，10 分钟约 2200 字。

## 4. 晋升/答辩材料

按评审维度组织（专业能力、业务成果、影响力、团队贡献），每个维度给 1–2 个"情境 — 任务 — 行动 — 结果"（STAR）案例；结果必须量化或有可验证证据。最后写"下一级岗位的规划"。

## 5. 底线

- 成果只写用户确认过的事实和数据；团队成果写清个人角色（主导/参与/支持），不把团队功劳写成个人的。
- 不足部分真实具体；不贬低同事或其他部门。
