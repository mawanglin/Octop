# 解说词

## 1. 篇幅

宣传片配音语速较慢，约 3–3.5 字/秒（每分钟 180–210 字），并且要给纯画面和音乐留出空间：3 分钟片子的解说词通常 450–550 字，5 分钟约 750–900 字。

## 2. 文风

| 类型 | 文风 | 示例句式 |
|------|------|----------|
| 政务/城市 | 大气、凝练、有诗意，四字短语和排比 | "千年文脉，在这里赓续；创新浪潮，在这里奔涌。" |
| 企业形象 | 叙事、真诚、有温度，少用空洞形容词 | "二十年前，我们从一间不足五十平方米的厂房出发。" |
| 产品 | 简洁、具体、利益点清楚 | "一次充电，续航 30 天。" |
| 招商 | 理性、说服、数据支撑 | "两小时车程，覆盖 1 亿人口市场。" |
| 年会 VCR | 温暖、有情绪起伏、具体到人 | "这一年，有 128 个深夜，我们的灯一直亮着。" |

## 3. 写法

- 按段落写，每段标注对应的画面段落和预计时长；
- 第一句定调，最后一句点题（通常是片名或口号）；
- 数据要"可感"："年产值 500 亿元"可以配一句"相当于每天创造 1.4 亿元"（换算必须准确）；
- 少用"领先""一流""国际化"等空泛词，用具体事实替代；
- 留白：情绪高点和转场处不配旁白，只用音乐和画面；
- 每段配 1 句**字幕金句**（屏幕大字，≤ 12 字）。

## 4. 片名和口号

给 3–5 个片名备选：4–8 字、易记、与概念一致（如《向新而行》《一城山水半城诗》）。口号可与片名一致，也可单独提炼。

## 5. 输出格式

```markdown
## 片名：《〔片名〕》（备选：……）

### 第一段｜开篇｜0:00–0:30｜约 90 字
【画面】航拍日出江面……
【旁白】……
【字幕】〔金句〕
```

成稿后统计总字数并按 3.2 字/秒估算时长；需要配音时提醒用户选择与调性匹配的配音员（政务片常用浑厚男声，企业片可用温暖女声或双人配音）。
