# 创意策划

## 1. 常见类型和结构

| 类型 | 时长 | 结构 |
|------|------|------|
| 企业形象片 | 3–5 分钟 | 愿景开场 → 发展历程（简）→ 核心业务与实力 → 人才与文化 → 社会责任 → 未来展望 + Logo 定版 |
| 城市/区县宣传片 | 3–8 分钟 | 城市意象开场 → 历史文化 → 产业发展 → 生态宜居 → 民生幸福 → 城市精神/口号 |
| 园区招商片 | 3–5 分钟 | 区位优势（地图动画）→ 产业基础与链条 → 政策与服务 → 成功企业案例 → 招商口号与联系方式 |
| 产品片 | 30 秒–2 分钟 | 痛点或场景 → 产品出场 → 核心卖点逐一演示 → 使用场景 → 品牌定版 |
| 校园片 | 3–5 分钟 | 校园四季 → 历史与学科 → 师生故事 → 校园生活 → 校训定版 |
| 年会/晚会 VCR | 2–5 分钟 | 年度关键词 → 高光时刻（员工群像、项目里程碑）→ 感谢 → 新年展望 |

## 2. 创意方向（每次给 2–3 个）

每个方向写清：
- **概念**：一句话（"一座让年轻人留下来的城市"）；
- **叙事方式**：宏大叙事 / 人物故事（以 1–3 个真实人物串联）/ 一天的时间线 / 第一人称自述 / 数据可视化；
- **调性**：大气、温暖、科技、青春、人文；
- **影像风格**：色调、运镜、航拍比重、是否有演员；
- **音乐**：交响、电子、民乐、钢琴等；
- **预算级别**：低（实拍为主、少量航拍、无演员）/ 中（含演员、专业灯光、调色）/ 高（大场面、特殊设备、三维动画）。

## 3. 分段画面构想

```markdown
| 段落 | 时间 | 主题 | 画面构想 | 旁白要点 |
|------|------|------|----------|----------|
| 开篇 | 0:00–0:30 | 城市晨曦 | 航拍日出江面、早高峰地铁、早餐店蒸汽 | 一座城市的一天，从…开始 |
```

画面构想要具体到地点和动作，每段 3–5 个代表画面；涉及的地标、企业、人物标注"需协调拍摄许可"。

## 4. 政务宣传片注意

- 表述以官方口径为准：地名全称、规划名称、口号、数据，用户未提供的标〔待核实〕；
- 避免出现敏感地图问题（使用标准地图）、领导人画面使用规范；
- 民生画面真实自然，避免摆拍痕迹过重；体现群众获得感。
