# 书单与阅读计划

## 1. 分类方法

| 方式 | 适合 | 分类示例 |
|------|------|----------|
| 简化中图法 | 书多、想长期维护 | 文学 / 历史地理 / 哲学心理 / 经济管理 / 政治法律 / 自然科学 / 计算机 / 艺术 / 生活 |
| 按主题 | 有明确兴趣方向 | 科幻、推理、商业传记、育儿、理财 |
| 按用途 | 学习和工作 | 正在读、待读、参考书、已读精选 |

在书单 Excel 里加一列"分类"即可，不一定要移动文件；需要按分类建目录时，用 `ebook-toolkit` 的 plan 配合 layout，并在方案 CSV 里批量修改目标路径。

## 2. 阅读计划

1. 估算：每天阅读 30 分钟，中文书平均每分钟 300–400 字，一本 20 万字的书约 2 周。
2. 年度目标 = 每月 2–4 本 × 12，留 20% 余量。
3. 每月初从"待读"里选书：1 本专业 + 1 本兴趣 + 1 本轻松读物。
4. 在书单的"已读"列写完成日期，月底统计完成率。

## 3. 读书笔记模板

```markdown
# 书名 — 作者
- 读完日期：
- 一句话总结：
- 三个关键观点：
  1.
  2.
  3.
- 我能用在哪里（行动）：
- 印象深的句子：
- 评分（1–5）：
```

## 4. 阅读器与格式

| 设备 | 推荐格式 | 说明 |
|------|----------|------|
| Kindle | azw3 / mobi，新机型支持 epub（通过官方邮箱推送） | pdf 小屏阅读体验差 |
| 文石、掌阅等墨水屏 | epub、pdf（大屏） | 支持格式多 |
| iPad / 手机 | epub、pdf | Apple Books、多看、静读天下 |
| 电脑 | pdf、epub | Calibre 可管理和转换格式 |

txt 出现乱码多为 GBK 编码：用记事本或 VS Code"另存为 UTF-8"，另存时保留原文件。扫描版 pdf 只能看图片，无法调整字号。
