# 待办追踪

> `scripts/actions_xlsx.py` 相对于本技能目录；示例：`references/example-actions.md`。

## 1. 维护清单

所有会议的待办汇总在 `outputs/meetings/待办.md` 一张 Markdown 表里（新会议的待办追加到末尾）：

```markdown
| 待办 | 负责人 | 截止 | 状态 | 来源 | 备注 |
|------|--------|------|------|------|------|
| 提交 Q4 预算调整方案 | 张三 | 2026-10-15 | 进行中 | 10月13日经营例会 | |
```

状态写"未开始 / 进行中 / 已完成 / 已取消"；截止支持 2026-10-20、10/20、10月20日。

## 2. 生成追踪表

```bash
python scripts/actions_xlsx.py outputs/meetings/待办.md -o outputs/meetings/待办追踪.xlsx [--today 2026-10-18] [--soon 3] [--overwrite]
```

- 「待办」工作表：按逾期 → 临期 → 未完成 → 已完成排序；逾期红底、临期黄底、完成绿底；含"剩余天数"列。
- 「按负责人」工作表：每人的未完成、逾期、临期数量。
- 终端输出逾期和临期清单，以及没有负责人或截止日期的待办数量。
- 用户在 Excel 里改了状态后，可以把这个 xlsx 当作输入重新生成（加 `--overwrite`）。

## 3. 跟进提醒

逾期或临期事项按负责人起草跟进消息，语气礼貌、具体：

```
@张三 你好，10月13日经营例会上的待办「提交 Q4 预算调整方案」原定 10月15日完成，目前状态是进行中。方便的话同步一下进展和预计完成时间？如需支持请告诉我。
```

消息由用户确认后再发送，不自动发给他人。建议用户创建定时任务（如每个工作日 9:00）运行本技能，只把摘要发给用户本人。
