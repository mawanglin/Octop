# 会前准备

## 1. 议程

```markdown
# 〔会议名称〕议程

- 时间：〔2026-10-20 14:00–15:00〕　地点/链接：〔……〕
- 主持：〔姓名〕　记录：〔姓名〕
- 会议目标：〔本次会议结束时要得到什么结果，如"确定 Q4 预算分配方案"〕

| 时间 | 议题 | 目标（决策/讨论/通报） | 负责人 | 会前材料 |
|------|------|------------------------|--------|----------|
| 14:00–14:05 | 开场与上次待办回顾 | 通报 | 主持人 | 待办追踪表 |
| 14:05–14:30 | Q4 预算调整 | 决策 | 张三 | 预算方案 v2 |
```

规则：每个议题标明是要"决策""讨论"还是"通报"；决策类议题放前面；总时长留 10% 余量；通报类能用文字发的不占会议时间。

## 2. 常见会议议程模板

| 会议 | 议程结构 |
|------|----------|
| 周例会（30–60 分钟） | 上周待办回顾 → 各成员进展（每人 3 分钟，只讲结果和卡点）→ 需要协调的问题 → 本周重点 → 新待办确认 |
| 项目会 | 里程碑状态 → 风险与问题 → 需决策事项 → 下阶段计划 |
| 决策会 | 背景与问题定义 → 备选方案对比 → 讨论 → 决策 → 执行分工 |
| 复盘会 | 目标回顾 → 结果对比 → 做得好的 → 待改进的（原因）→ 改进行动 |
| 头脑风暴 | 问题陈述 → 发散（不评价）→ 归类 → 投票收敛 → 下一步 |

## 3. 会议通知

```
【会议通知】〔会议名称〕
时间：〔日期 星期几 时间〕
地点：〔会议室/线上链接和会议号〕
议题：1. ……　2. ……
参会人员：〔……〕
会前准备：请〔××〕于〔日期〕前提交〔材料〕；请各位提前阅读〔材料〕。
如不能参会，请提前告知〔联系人〕。
```

通知由用户确认后再发送；通过 IM 渠道发送时用纯文本格式。

## 4. 主持提纲（可选）

为主持人列出：开场白一句话目标 → 每个议题的引导问题 → 控时提醒点 → 结尾总结决议和待办的话术。
