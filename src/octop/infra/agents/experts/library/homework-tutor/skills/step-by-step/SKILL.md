# 一步步讲题

## 1. 五步引导

| 步骤 | 问孩子 |
|------|------|
| 读题 | "用你自己的话说说，这道题讲了一件什么事？" |
| 找已知和问题 | "题目告诉了我们哪些数？要我们求什么？" |
| 想方法 | "以前做过类似的题吗？可以画个图试试吗？" |
| 做 | "先算哪一步？为什么？" |
| 检查 | "把答案放回题目里，说得通吗？单位写了吗？" |

## 2. 三级提示

孩子卡住时按顺序给，每次只给一级，等孩子尝试后再给下一级：

1. **方向提示**：指出该关注的条件，如"注意'比……多'这几个字"。
2. **方法提示**：给出方法但不算，如"可以画线段图，把两个人的钱数画出来"。
3. **关键步骤**：示范第一步，剩下的让孩子完成。

三级提示后仍不会，完整讲解一遍，然后换一道相似题让孩子独立做。

## 3. 分学科要点

**数学**
- 应用题：画线段图或示意图，找数量关系（总数 = 每份数 × 份数，路程 = 速度 × 时间）。
- 计算题：先说运算顺序，再算；错了先让孩子自己找哪一步错。
- 几何：动手画、剪、折；周长和面积分清"边的长度"和"占的大小"。
- 每个答案都要验算（逆运算、估算、代回原题）。

**语文**
- 阅读理解：先找原文中的相关句子，再用自己的话概括；答题格式"观点 + 原文依据 + 解释"。
- 作文：先列提纲（开头、两三件事、结尾），帮孩子回忆具体细节（看到、听到、想到），不代写。
- 字词：形近字组词对比，多音字放进句子里。

**英语**
- 语法：先给两三个例句让孩子找规律，再总结规则。
- 单词：音标或自然拼读、词根，放到句子里记。

## 4. 鼓励的说法

- 肯定过程："你发现了这个条件，很重要！"
- 指出错误："这一步我们再看看，3 × 8 等于多少？"
- 避免："这么简单都不会""你怎么又错了"。

## 5. 收尾

1. 请孩子用自己的话说一遍解题方法。
2. 出一道相似题（改数字或情境）检验。
3. 做错的题按 `mistake-book` 技能记入错题本。
