# 存证清单

> `scripts/` 路径相对于本技能目录。

## 1. 生成和核验

```bash
python scripts/evidence_hash.py make 作品目录 -o outputs/版权/存证清单.csv --owner 张三 --title 江南系列摄影 --xlsx
python scripts/evidence_hash.py verify outputs/版权/存证清单.csv
python scripts/evidence_hash.py verify outputs/版权/存证清单.sha256 --root 作品目录   # 同时列出清单外的新文件
```

- 生成后**不要再修改**作品文件和 `.sha256` 文件；需要修改作品时，修改后重新生成一份新清单，保留旧清单作为过程证据；
- 没有本工具也能核验：Linux / macOS 在作品目录运行 `sha256sum -c 存证清单.sha256`，Windows 用 `certutil -hashfile 文件 SHA256` 逐个对照。

## 2. 指纹能证明什么

SHA-256 指纹是文件内容的"数字指纹"：内容改动一个字节，指纹就完全不同。所以它能证明**文件没有被改过**，但**不能证明文件在什么时间已经存在**、是谁创作的。要证明时间，需要把指纹交给可信的第三方固定下来：

| 方式 | 证明什么 | 特点 |
|------|----------|------|
| 可信时间戳 | 某个时间点该文件（指纹）已存在且未被修改 | 成本低、速度快，电子数据取证中常用；选择有资质的时间戳服务机构 |
| 区块链存证 | 同上，记录上链不可篡改 | 优先选择与法院、公证处对接的平台；了解平台在司法实践中的认可情况 |
| 公证 | 公证员见证取证或保全的过程和内容 | 证明力强，费用较高；适合重要作品和侵权取证 |
| 作品登记 | 登记机构出具证书，作为权属初步证明 | 形式审查，不审查独创性；见 `copyright-registration` |
| 自存证据 | 底稿、过程文件、原始文件、发布记录、邮件和聊天记录 | 平时就要保留，形成完整证据链 |

建议做法：作品完成时生成清单，把"清单总指纹"提交时间戳或存证平台；重要作品再办理作品登记；发现侵权时对侵权页面另行取证（录屏、截图加时间戳或公证）。具体平台和收费以服务方最新说明为准，可以联网搜索核实。

## 3. 交付给用户

说明生成了哪些文件、清单总指纹是多少、下一步把指纹提交到哪里，以及"不要再改动文件"的提醒。
