# 著作权法律法规要点

> 供快速查阅，**不是法条原文**。引用时核对国家法律法规数据库或国家版权局发布的正式文本；条款号以现行版本为准。最后整理：2026 年 10 月。

## 一、主要法律法规

| 名称 | 层级 | 要点 |
|------|------|------|
| 《中华人民共和国著作权法》（2020 年第三次修正，2021 年 6 月 1 日起施行） | 法律 | 作品定义、权利内容、归属、保护期、合理使用、法定许可、侵权责任 |
| 《中华人民共和国著作权法实施条例》 | 行政法规 | 作品类型的具体含义、登记、使用规则 |
| 《计算机软件保护条例》 | 行政法规 | 软件著作权的产生、归属、权利限制、侵权责任 |
| 《信息网络传播权保护条例》 | 行政法规 | 网络传播、"通知—删除"、技术措施、网络服务提供者责任 |
| 《计算机软件著作权登记办法》 | 部门规章 | 软件登记的申请、鉴别材料、审查 |
| 《作品自愿登记试行办法》 | 部门规章 | 作品登记的基本规则（注意关注是否有新的作品登记办法出台） |
| 《中华人民共和国民法典》 | 法律 | 知识产权的一般规定、合同、诉讼时效（一般三年） |
| 《人工智能生成合成内容标识办法》 | 部门规定（多部门联合发布） | AI 生成合成内容的显式、隐式标识要求 |

## 二、《著作权法》核心条文要点（2020 年修正版）

| 条款 | 要点 |
|------|------|
| 第二条 | 中国公民、法人或者非法人组织的作品，不论是否发表，依法享有著作权 |
| 第三条 | 作品：文学、艺术和科学领域内具有独创性并能以一定形式表现的智力成果；列举文字、口述、音乐戏剧曲艺舞蹈杂技、美术建筑、摄影、视听、图形和模型、计算机软件、符合作品特征的其他智力成果 |
| 第五条 | 不适用：法律法规和国家机关具有立法、行政、司法性质的文件及其官方正式译文；单纯事实消息；历法、通用数表、通用表格和公式 |
| 第十条 | 人身权：发表权、署名权、修改权、保护作品完整权；财产权：复制、发行、出租、展览、表演、放映、广播、信息网络传播、摄制、改编、翻译、汇编等 |
| 第十二条 | 在作品上署名的为作者（有相反证明的除外）；作者等著作权人可以向登记机构办理作品登记 |
| 第十三条至第十七条 | 演绎作品、合作作品、汇编作品、视听作品的权利归属 |
| 第十八条 | 职务作品：一般职务作品归作者，单位优先使用；特殊职务作品作者享有署名权，其他权利归单位 |
| 第十九条 | 委托作品：有约定从约定，无约定归受托人 |
| 第二十二条、第二十三条 | 署名权、修改权、保护作品完整权不受期限限制；自然人作品的发表权和财产权保护期为作者终生及死亡后五十年（截至第五十年 12 月 31 日）；法人或非法人组织的作品、特殊职务作品、视听作品一般为首次发表后五十年 |
| 第二十四条 | 合理使用：个人学习研究欣赏、适当引用、新闻报道、课堂教学等法定情形，应指明作者姓名和作品名称，不得影响正常使用、不得不合理损害权利人合法权益 |
| 第二十六条、第二十七条 | 许可使用合同和转让合同的主要条款；转让应当订立书面合同 |
| 第五十二条、第五十三条 | 侵权行为及民事、行政、刑事责任 |
| 第五十四条 | 赔偿：实际损失或违法所得 → 参照权利使用费 → 故意侵权情节严重的一倍以上五倍以下 → 都难以计算的五百元以上五百万元以下；包括制止侵权的合理开支 |

## 三、2020 年修正的主要变化

- 作品定义改为"具有独创性并能以一定形式表现的智力成果"，作品类型兜底条款改为"符合作品特征的其他智力成果"；
- "电影作品和以类似摄制电影的方法创作的作品"改为"视听作品"；
- 法定赔偿上限从五十万元提高到五百万元，增加五百元下限和惩罚性赔偿；
- 增加作品登记的规定，完善技术措施和权利管理信息保护。

## 四、软件保护要点

- 软件著作权自软件开发完成之日起产生，不登记也享有；
- 保护的是程序和文档的表达，不保护开发软件所用的思想、处理过程、操作方法或数学概念；
- 鉴别材料：源程序和文档各提交前、后连续 30 页，不足 60 页全部提交；程序每页不少于 50 行，文档每页不少于 30 行（以登记机构最新要求为准）。

## 五、AI 生成内容

- 法律没有专门规定，司法实践以"是否体现人的独创性智力投入"为核心，个案判断；
- 发布 AI 生成合成内容需按规定标识；
- 训练数据、风格模仿涉及的权利问题仍有争议，给出意见时说明不确定性。
