# 著作权登记与业务规则

> 法律条文要点见 `copyright-policy` 技能的参考资料。办理流程、费用、时限常有调整，给出具体数字前先联网核实官方最新说明，并注明来源和日期。

## 1. 要不要登记

- 著作权自作品**创作完成时自动产生**，不登记也享有；
- 登记证书是权属的**初步证明**：维权时举证方便，也常用于版权交易、融资质押、项目申报、企业资质认定和各地资助；
- 登记是形式审查，不审查独创性，**不等于**作品一定受保护、一定不侵犯他人权利。

建议登记：有商业价值、可能被盗用、需要用于申报或交易的作品；软件产品一般都应登记。

## 2. 作品登记与软件登记

| | 作品登记 | 计算机软件著作权登记 |
|--|----------|------------------------|
| 对象 | 文字、美术、摄影、音乐、视听、图形、模型等作品 | 计算机程序及其文档 |
| 办理机构 | 中国版权保护中心，或作品所在地省级版权主管部门/其指定机构 | 中国版权保护中心 |
| 主要材料 | 申请表、身份证明、权属证明、作品样本、作品创作说明 | 申请表、身份证明、权属证明、源程序和文档鉴别材料（见 `softcopy-doc`） |

**作品样本**：文字作品提交全文；美术、摄影作品提交清晰的作品图片（系列作品逐幅列出）；音乐作品提交曲谱或音频；视听作品提交视频文件及内容简介。格式和大小以登记系统要求为准。

## 3. 材料清单

1. 登记申请表（作品名称、类别、创作完成日期、首次发表日期和地点、作者、著作权人、权利取得方式）；
2. 身份证明：个人身份证件；单位营业执照或法人证书；
3. 权属证明（非本人独立原创时）：委托创作合同、职务作品约定、合作创作协议、转让合同、继承证明；
4. 作品样本；
5. 作品创作说明；
6. 代理办理时的委托书和代理人身份证明。

**作品创作说明**写法：创作目的和背景 → 创作过程（时间线、构思、草稿和修改，用了哪些工具）→ 独创性体现（选择、编排、表达上的个人特色）→ 素材来源（引用、借鉴的内容及授权情况）。如实写明 AI 工具的使用情况。

## 4. 权属认定

| 情形 | 归属规则（《著作权法》） | 建议 |
|------|-------------------------|------|
| 一般职务作品 | 著作权归作者；单位在业务范围内优先使用，完成两年内未经单位同意作者不得许可第三方以相同方式使用 | 劳动合同或制度里约定清楚 |
| 特殊职务作品 | 主要利用单位物质技术条件创作并由单位承担责任的工程设计图、产品设计图、地图、示意图、计算机软件等，以及法律法规规定或合同约定归单位的：作者享有署名权，其他权利归单位 | 软件、设计类岗位务必书面约定 |
| 委托作品 | 有约定从约定；没有约定或约定不明的，归**受托人** | 外包设计、拍摄、开发一定要在合同里约定权利归属 |
| 合作作品 | 合作作者共同享有；能分割使用的，各自对自己创作部分单独享有 | 签合作协议，约定使用和收益分配 |
| 演绎作品 | 改编、翻译、注释、整理他人作品，演绎者享有著作权，但行使时不得侵犯原作著作权 | 先取得原作授权 |

## 5. AI 生成内容

- 现行法律没有专门规定，司法实践看**人是否作出了独创性的智力投入**：北京互联网法院 2023 年一起 AI 文生图案件中，法院认为原告通过设计提示词、调整参数、多轮选择修改体现了个性化表达，认定图片构成作品；也有法院在投入不足时不予支持。
- 建议留痕：保存提示词和修改过程、参数和随机种子、生成的多个版本、选择理由和后期加工的源文件；
- 登记和维权时**如实说明** AI 的使用情况，不隐瞒；
- 发布 AI 生成合成内容，应遵守《人工智能生成合成内容标识办法》等规定进行标识（以最新规定为准）；
- 使用 AI 工具前看清平台用户协议中对生成内容权利归属和商用的约定。

## 6. 授权许可与转让

**许可合同要点**：许可的权利种类（复制、发行、信息网络传播、改编……）、专有或非专有、地域、期限、方式和用途、付酬标准和支付方式、是否可以转授权、署名方式、违约责任。转让合同同样要写明转让的权利种类、地域、价款，并采用书面形式。

| 常见授权 | 说明 |
|----------|------|
| CC 协议 | BY（署名）、SA（相同方式共享）、NC（非商业）、ND（禁止演绎）的组合；CC0 为放弃权利。商用前确认没有 NC |
| 图库授权 | RF（一次付费、范围内多次使用）和 RM（按用途、期限、地域单独授权），注意人像和物权授权 |
| 字体、音乐 | 免费下载不等于可商用；字体在商业海报、视频中使用通常需要商用授权 |

合同起草和审阅交给「合同审阅专家」。

## 7. 平台原创声明

公众号、视频号、抖音、小红书、B 站、站酷等平台都有原创声明或原创保护机制。原创声明是平台规则，不替代法律上的权属证明；侵权投诉时平台通常要求提供权属证明（底稿、登记证书、存证记录）和侵权链接。各平台规则以最新说明为准。

## 8. 侵权应对流程

1. **固定证据**：对侵权页面录屏、截图并做可信时间戳或公证；记录网址、账号、发布时间、浏览和销售数据；
2. **准备权属证据**：原始文件、底稿、存证清单（`evidence-hash`）、登记证书、首次发表记录；
3. **比对**：用 `sample-inspect` 初筛相似度，整理"原作—侵权"对照表；
4. **选择途径**：平台投诉（"通知—删除"规则，提交权属证明和侵权链接）→ 发送警告函或协商许可 → 向版权行政执法部门投诉 → 起诉；
5. **注意时效**：民事诉讼时效一般为三年，自知道或应当知道权利受到损害以及义务人之日起计算。

赔偿计算、诉讼文书交给「生活法律助手」或建议咨询律师。
