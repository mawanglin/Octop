# 维权路径与常用文书

> `references/` 路径相对于本技能目录：`references/labor-arbitration-template.md`、`references/civil-complaint-template.md`、`references/consumer-complaint-template.md`。

## 1. 找谁

| 纠纷 | 先做 | 再做 |
|------|------|------|
| 欠薪、不签合同、不缴社保 | 保留证据，书面催要 | 劳动保障监察投诉（12333）/ 劳动人事争议仲裁委员会申请仲裁（免费） |
| 被辞退、经济补偿、加班费 | 要求书面解除通知 | 劳动仲裁（劳动争议须先仲裁才能起诉） |
| 网购、商品质量、虚假宣传 | 与商家、平台协商 | 12315 平台投诉；金额较大可向法院起诉 |
| 租房押金、维修 | 书面沟通，拍照留证 | 街道 / 社区人民调解；法院起诉（小额诉讼程序快） |
| 借钱不还 | 书面催告（中断诉讼时效） | 法院起诉；可申请支付令 |
| 交通事故 | 报警 122，拍照，保险报案 | 交警调解；法院起诉 |
| 不知道怎么办 | 12348 公共法律服务热线 | 符合条件的可申请法律援助 |

## 2. 证据清单

- 按"证明什么"组织，每份证据写：名称、来源、证明内容、页数。
- 聊天记录：保留原始载体（手机），截图要显示对方身份信息和时间；重要语音整理成文字。
- 录音：自己参与的对话录音一般可以作为证据，但不得以侵害他人隐私等非法方式取得。
- 社保、个税、银行流水可以自己在官方 App 或柜台打印。

## 3. 起草文书

1. 读取对应模板，按用户提供的事实填写；身份证号、住址等由用户自己填写，用 `【】` 占位。
2. 请求事项要具体到金额和计算方式（金额用 `legal-calc` 计算）。
3. 事实部分按时间顺序，一句话一件事，每个关键事实对应证据编号。
4. 结尾提示：提交前核对当事人信息、请求金额、证据编号；文书仅供参考，复杂案件请律师审阅。

## 4. 催告函要点

写明：债权或权利内容、金额、依据（合同 / 借条）、要求履行的期限、逾期将采取的措施（仲裁 / 诉讼）。通过 EMS 寄送并保留回执，或用可证明送达的方式发送——这同时可以中断诉讼时效。
