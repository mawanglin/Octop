# 消费投诉（模板）

> 渠道：商家客服 → 电商平台投诉 → 全国 12315 平台（www.12315.cn、12315 小程序）或 12315 热线。写清事实、诉求和证据，语气克制。

**投诉人**：【姓名】，联系电话【……】
**被投诉方**：【商家 / 店铺名称、平台、地址或网址】

**购买信息**：【日期】在【平台 / 门店】购买【商品或服务名称、型号】，订单号【……】，实付【……】元。

**问题经过**：
1. 【收到商品 / 接受服务的时间】，发现【具体问题：如与描述不符、质量故障、虚假宣传、拒绝七日无理由退货】；
2. 【日期】联系商家，商家【回应内容】；
3. 【其他沟通经过】。

**诉求**：【退货退款 / 换货 / 维修 / 赔偿……元】。依据《消费者权益保护法》第【二十四 / 二十五 / 五十五】条。

**证据**：订单截图、商品照片或视频、商家宣传页面截图、聊天记录、检测报告（如有）。

**期望处理时间**：【如：希望 7 个工作日内答复】
