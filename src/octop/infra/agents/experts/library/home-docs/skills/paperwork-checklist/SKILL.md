# 办事材料清单

> 各地要求不同，以下为常见做法；办理前在官方 App、网站或电话核实，并提醒用户预约。

## 1. 家里该有哪些（盘点分类）

| 类别 | 项目 |
|------|------|
| 证件 | 身份证、护照、港澳通行证、台湾通行证、驾驶证、社保卡、居住证 |
| 户籍婚育 | 户口本、结婚证、出生医学证明、独生子女证 |
| 房产租房 | 不动产权证、购房合同、贷款合同、租赁合同、物业缴费 |
| 车辆 | 行驶证、机动车登记证书、交强险、商业险、年检 |
| 保险 | 医疗险、重疾险、意外险、寿险、财产险（保单号后 4 位、保险公司、缴费日） |
| 教育医疗 | 学历学位证、职业资格证、疫苗接种本、病历和体检报告 |
| 保修会员 | 家电保修卡和发票、手机电脑保修、会员和订阅续费日 |

## 2. 常见事项

| 事项 | 提前多久 | 材料（常见） | 渠道 |
|------|----------|--------------|------|
| 身份证到期换领 | 到期前 3 个月内 | 旧身份证；部分地区可异地办理 | 户籍地或居住地派出所，部分城市政务 App 预约 |
| 护照换发 | 有效期不足 6 个月或签证页用完 | 旧护照、身份证；现场拍照 | 出入境接待大厅，"移民局" App 预约 |
| 港澳通行证 | 签注用完或到期前 | 身份证、旧证 | 出入境大厅或自助机签注 |
| 驾驶证换证 | 有效期满前 90 日内 | 身份证、体检证明（可在定点医院做） | 交管 12123 App 或车管所 |
| 车辆年检 | 检验有效期满前 3 个月内 | 行驶证、交强险凭证 | 交管 12123 预约，6 年内非营运小客车可申领免检标志 |
| 车险续保 | 到期前 1 个月 | 行驶证、上年保单 | 多家保险公司比价，注意交强险不能断保 |
| 租房续签 | 到期前 2 个月 | 原合同、身份证 | 与房东书面约定租金和期限 |
| 家电保修 | 故障时 | 发票、保修卡、购买记录 | 品牌官方客服 |

## 3. 证件丢失

1. 身份证：尽快到派出所挂失补领，可申请临时身份证；如可能被冒用，向派出所报案并留存回执。
2. 护照：向出入境管理部门报失；在境外丢失立即联系当地中国使领馆。
3. 银行卡、社保卡：先电话挂失，再带身份证补办。
4. 驾驶证、行驶证：通过交管 12123 补领。

## 4. 出国 / 出行前检查

- [ ] 护照有效期 6 个月以上，签证 / 签注有效
- [ ] 身份证、驾驶证（境外自驾需要翻译件或国际驾照认可文件）
- [ ] 境外医疗和意外保险
- [ ] 银行卡开通境外支付，告知银行出行
- [ ] 证件复印件和电子版与原件分开存放
