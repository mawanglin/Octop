# 备份策略

## 1. 先分清：RAID、快照、备份

| | 防什么 | 不防什么 |
|---|--------|----------|
| RAID / 存储池冗余 | 单块（或两块）硬盘损坏 | 误删、勒索病毒、整机损坏、火灾被盗 |
| 快照 | 误删、误改、部分勒索病毒（快照只读时） | 存储池损坏、整机丢失 |
| 备份（另一台设备 / 异地） | 以上所有 | 备份本身没有验证过 |

## 2. 3-2-1 原则

- **3** 份数据：原始数据 + 2 份备份；
- **2** 种介质：如 NAS + USB 硬盘 / 第二台 NAS / 云；
- **1** 份异地：放在家以外（亲友家、公司、云存储）。

## 3. 按重要性分级

| 级别 | 数据 | 建议 |
|------|------|------|
| A 不可再得 | 照片视频、个人文档、工作资料、密码库 | 3-2-1，每天增量备份，异地一份 |
| B 重建麻烦 | Docker 配置、数据库、家庭影音库的元数据 | 每周备份到另一块盘 |
| C 可以重新获取 | 下载的影视、安装包 | 可以不备份，或只备份清单 |

先算 A 级数据有多大，再选介质和云存储套餐。

## 4. 方案示例（照片 + 文档约 2 TB）

1. NAS 存储池开启快照：每小时保留 24 份、每天保留 30 份、每周保留 12 份；
2. 每天夜间用 NAS 自带备份工具（飞牛备份、群晖 Hyper Backup、威联通 HBS）增量备份到 USB 硬盘；
3. 每周增量备份到云存储（开启客户端加密，密码另外保管），或备份到异地的第二台 NAS；
4. 每季度做一次恢复演练：随机恢复几个文件和一个完整文件夹，确认能打开。

## 5. 防勒索病毒

- 快照设为不可删除 / 不可变（支持的系统），管理员账号开启两步验证；
- 至少一份备份平时不挂载（USB 硬盘备份完拔下）；
- 关闭不用的服务（SMB1、Telnet、UPnP 自动端口映射），不把管理界面暴露到公网。

## 6. 换硬盘 / 重建阵列前

- [ ] 确认 A 级数据有最近一次成功的备份
- [ ] 记录存储池类型、硬盘顺序和序列号
- [ ] 新盘容量不小于旧盘，先做一次完整的 SMART 长测试
- [ ] 重建期间避免大量写入，保持散热，期间不再拔其他盘
- [ ] 重建完成后核对存储池状态和数据完整性
