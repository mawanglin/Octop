# 家常烹饪指南

## 1. 常用调味汁（2–3 人份）

| 味型 | 比例 | 用于 |
|------|------|------|
| 糖醋汁 | 糖 2 : 醋 2 : 生抽 1 : 番茄酱 1 : 水 3，淀粉少许 | 糖醋排骨、糖醋里脊 |
| 鱼香汁 | 糖 1 : 醋 1 : 生抽 1 : 水 2，淀粉 0.5，加郫县豆瓣和泡椒 | 鱼香肉丝、鱼香茄子 |
| 宫保汁 | 糖 1 : 醋 1 : 生抽 1.5 : 水 2，淀粉 0.5 | 宫保鸡丁 |
| 红烧 | 冰糖炒糖色 + 生抽 2 : 老抽 0.5 : 料酒 1，加热水没过 | 红烧肉、红烧鱼 |
| 凉拌汁 | 生抽 2 : 香醋 2 : 糖 0.5 : 香油 0.5，加蒜末辣椒油 | 凉拌黄瓜、木耳 |

## 2. 基础技法

- **焯水**：肉类冷水下锅去血沫；青菜、西兰花沸水加少许盐和油焯 30–60 秒保持翠绿。
- **上浆**：肉丝 / 鸡丁加盐、料酒、蛋清、淀粉抓匀，最后封一层油，腌 10–15 分钟，炒出来嫩。
- **爆炒**：锅烧热再下油，油温七成热（筷子放入周围起密集小泡）下菜，全程大火。
- **判断熟度**：鸡肉切开无粉色、汁水清澈；鱼眼突出变白、筷子能轻松插入最厚处；四季豆颜色变深、无豆腥味。

## 3. 常见失败原因

| 问题 | 原因 | 解决 |
|------|------|------|
| 炒青菜出水 | 火小、盐放早、量太多 | 大火、少量分次、出锅前放盐 |
| 肉丝老 | 没上浆、炒太久 | 上浆，滑散变色即盛出 |
| 鱼煎破皮 | 锅不够热、鱼身有水 | 擦干、姜片擦锅、热锅凉油、不急着翻 |
| 茄子吸油 | 直接下油锅 | 先蒸 / 微波软或撒盐挤水 |
| 红烧肉腻 | 五花肉没煸出油 | 小火煸到表面微黄出油再烧 |

## 4. 替代食材

料酒 → 黄酒或少量白酒；冰糖 → 白砂糖；蚝油 → 生抽加少许糖；淀粉 → 土豆淀粉或玉米淀粉均可；猪里脊 → 鸡胸肉（时间减半）。

## 5. 保存与食品安全

- 冷藏（0–4°C）：熟菜 1–2 天，生肉 1–2 天，叶菜 3–5 天；冷冻（−18°C）：生肉 3–6 个月，分小份装、标日期。
- 生熟分开：刀和砧板分开，处理生肉后洗手。
- 必须煮透：四季豆、豆浆（假沸后再煮 5 分钟）、鲜黄花菜（不建议家庭食用）、发芽或变绿的土豆挖掉或丢弃。
- 剩菜：放凉后 2 小时内冷藏，彻底加热后再吃；绿叶菜和海鲜尽量当餐吃完。

## 6. 人群调整

- **儿童**：少盐少糖、不用辣，切小块，鱼去刺；
- **老人**：软烂易嚼，少油少盐，多蒸炖；
- **减脂**：多蒸煮凉拌、少勾芡少油炸，每餐一掌心蛋白质 + 两拳蔬菜；热量估算可交给「健身教练」。
