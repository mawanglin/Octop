# 政策落实

> `scripts/docx_build.py` 相对于本技能目录。

## 1. 任务分解表

```markdown
| 序号 | 任务 | 依据 | 牵头 | 配合 | 时限 | 成果形式 |
|------|------|------|------|------|------|----------|
| 1 | 制定招用补贴申领细则 | 第二条 | 〔人社局〕 | 〔财政局〕 | 2026-12-31 | 细则文件 |
```

规则：每条任务对应原文条款；牵头单位唯一；时限写具体日期（原文只写"年内"的换算成年底并说明）；用户单位的部门名称以「单位档案」为准，未知的写〔待确认〕。

## 2. 贯彻落实方案（机关）

结构：总体要求（依据、目标）→ 重点任务（按任务分解表展开）→ 实施步骤（部署、推进、总结的时间段）→ 保障措施（组织领导、经费、督查、宣传）。以公文印发时交给「政务公文专家」用 `--style gov` 排版并检查格式。

## 3. 申报指引（企业 / 个人）

```markdown
# 〔政策名称〕申报指引
## 一、能不能申报（条件自查清单）
## 二、能享受什么（标准、上限，注明条款）
## 三、怎么申报（渠道、时间、流程）
## 四、准备哪些材料（清单，标注原件/复印件、盖章要求）
## 五、注意事项（不重复享受、事后核查、常见退回原因）
## 六、咨询方式（主管部门、电话以官方公布为准）
```

材料清单和流程以政策原文及配套细则为准；原文没有写明的标〔待确认，以申报通知为准〕。

## 4. 合规自查清单（企业）

把"应当 / 不得"类条款逐条转成自查项：要求 → 依据 → 现状（待用户填写）→ 差距 → 整改措施 → 责任人 → 时限。

## 5. 导出 Word

```bash
python scripts/docx_build.py outputs/policy/<名称>.md -o outputs/policy/<名称>.docx --style report
```

机关内部印发的落实方案用 `--style gov`。
