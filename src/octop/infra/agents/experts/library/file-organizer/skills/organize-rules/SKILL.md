# 整理规则

## 1. 个人 / 家庭文件夹结构（示例）

```text
01-证件与合同/     身份证件扫描、房产、保险、合同
02-财务/           年度账单、税务、发票（按年份子目录）
03-工作/           按公司或项目
04-学习/           课程、证书、资料
05-孩子/           按孩子姓名或年级
06-健康/           体检报告、病历（按年份）
07-照片视频/       交给照片整理专家按年月归档
08-影音娱乐/       电影、剧集、音乐、电子书
09-软件与安装包/
99-归档/           不常用但要保留的旧资料
```

前面加两位数字可以固定排序；层级不超过 3–4 层。

## 2. 工作共享盘

- 顶层按部门或项目：`P2026-01-某项目/`，项目内固定子目录：`01-需求`、`02-方案`、`03-合同`、`04-过程文档`、`05-交付物`、`06-会议纪要`。
- 单独的 `00-模板` 和 `99-归档`；结束的项目整体移到归档区。
- 权限按项目组设置，不在个人目录里放共享文件。

## 3. 命名规范

- 格式：`日期_主题_版本.扩展名`，如 `2026-10-18_季度经营分析_v2.docx`。
- 日期写 `YYYY-MM-DD` 或 `YYYYMMDD`，按名称排序就是按时间排序。
- 版本用 `v1`、`v2`，不要用"最终版""最最终版"；定稿后另存 `_定稿`。
- 避免：`\ / : * ? " < > |`（Windows 不允许）、首尾空格、过长的名字（整个路径建议少于 200 字符）。

## 4. 定期维护

| 频率 | 做什么 |
|------|--------|
| 每周 | 桌面和下载目录里本周的文件归位 |
| 每月 | `file_tool.py plan --older-than 30` 整理下载目录；清理确认过的重复文件 |
| 每年 | 上一年的资料移到 `99-归档/年份/`；检查备份 |
