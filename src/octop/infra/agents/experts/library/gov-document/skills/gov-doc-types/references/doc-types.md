# 常用公文结构模板与惯用语

以下示例中的单位、事项均为虚构；〔 〕内为需要替换或核实的内容。

## 通知

**适用**：发布、传达要求下级机关执行和有关单位周知或执行的事项，批转、转发公文。

**结构**：
1. 开头：缘由 + 依据 + 目的。"为〔目的〕，根据〔依据〕，经〔批准机关〕同意，决定〔事项〕。现将有关事项通知如下："
2. 主体：一、目标任务 二、主要内容/工作安排 三、时间安排 四、工作要求（组织领导、责任落实、信息报送）
3. 结尾：联系人及电话；可用"特此通知。"（主体已分条列项时可省略）

**印发/转发类**："现将《〔文件名称〕》印发给你们，请结合实际认真贯彻落实。"——正文简短，文件作为附件或直接附后。

## 请示

**适用**：向上级机关请求指示、批准。

**要求**：一文一事；只主送一个上级机关，需要同时送其他机关的用抄送；不得抄送下级机关；一般不直接送领导个人。

**结构**：
1. 请示缘由：背景、必要性、依据（是请示能否获批的关键，要充分）
2. 请示事项：具体、明确，涉及资金写明金额、来源和用途
3. 结语："妥否，请批示。""以上请示当否，请批示。""特此请示，请予审批。"

## 报告

**适用**：向上级汇报工作、反映情况、回复询问。

**要求**：不得夹带请示事项（不出现"请批示""妥否"）。

**结构**：
1. 开头：报告缘由，"现将〔××〕情况报告如下："
2. 主体：基本情况/工作进展 → 主要做法和成效 → 存在的问题 → 下一步打算
3. 结语："特此报告。"

## 函

**适用**：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。

**结构**：
1. 开头：发函缘由
2. 主体：商洽/询问/请求的具体事项
3. 结语：去函用"请予支持为盼。""盼复。""请函复。"；复函用"特此函复。""此复。"复函开头引叙来函："你单位《关于××的函》（××〔2026〕×号）收悉。经研究，现函复如下："

## 批复

**结构**：引叙来文（"你单位《关于××的请示》（××〔2026〕×号）收悉。"）→ 批复意见（同意/不同意/部分同意 + 依据和要求）→ 结语"此复。"

## 纪要

**结构**：
1. 开头：会议概况——时间、地点、主持人、参会人员、议题。"〔日期〕，〔主持人职务姓名〕主持召开〔会议名称〕，研究〔议题〕。现将会议议定事项纪要如下："
2. 主体：按议题分条写议定事项，用"会议认为""会议指出""会议同意""会议要求""会议决定"引领。
3. 结尾：出席、列席、请假人员名单（可放文末）。

纪要只写议定事项，不写讨论过程中的个人发言细节；有分歧未定的事项写"会议决定另行研究"。

## 通报

**表彰通报**：先进事迹 → 表彰决定 → 号召学习。**批评通报**：事实经过 → 原因分析和定性 → 处理决定 → 教训和要求。**情况通报**：情况概述 → 分析 → 要求。

## 意见

**结构**：总体要求（指导思想、基本原则、主要目标）→ 主要任务（分条）→ 保障措施（组织领导、政策支持、督查考核）。

## 常用过渡语和结语速查

| 场景 | 惯用语 |
|------|--------|
| 引出主体 | 现将有关事项通知如下：／现将有关情况报告如下：／现就有关问题提出如下意见： |
| 依据 | 根据《〔文件〕》（〔文号〕）精神／按照〔上级〕部署要求／经〔机关〕研究同意 |
| 要求 | 各单位要高度重视……／请于〔日期〕前将……报送〔单位〕 |
| 结尾 | 特此通知。／特此报告。／妥否，请批示。／请函复。／此复。 |

## 常见错误

- 标题"关于"重复、缺文种、加标点；"通知的通知"。
- 请示多事一文、多头主送、主送领导个人；报告里"请批示"。
- 层次序数"一、"后接"1."又接"（一）"，顺序颠倒。
- 日期写成"2026.10.17""二〇二六年"（2012 版国标统一用阿拉伯数字）。
- "有关部门要尽快落实"——没有责任主体和时限，应写明"〔牵头单位〕要于〔日期〕前完成"。
