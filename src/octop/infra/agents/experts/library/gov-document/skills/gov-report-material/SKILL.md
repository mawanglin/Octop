# 政务汇报材料

汇报材料不是法定文种，但机关日常使用最多。排版用 `gov-format` 的 `--style gov`，不填版头字段；需要副标题时在 front matter 写 `副标题`（如"——在市委督查组座谈会上的汇报"），落款写 `署名` 和 `日期`。

## 1. 先问清三件事

1. **向谁汇报、什么场合**：上级领导调研、督查检查、专题会议、年度考核——决定篇幅和侧重点。
2. **汇报时长或篇幅**：口头汇报按 200–230 字/分钟估算（10 分钟约 2000–2300 字）；书面材料一般 3000–5000 字。
3. **重点诉求**：想让听众记住什么、需要上级支持什么。

## 2. 工作汇报（最常用）

**结构**：
1. **开头**（不超过全文 10%）：简要情况 + 总体评价。"今年以来，在〔上级〕的坚强领导下，我〔单位〕坚持〔主线〕，〔核心成效〕。"
2. **主要工作和成效**（约 50%）：分 3–5 条，每条"观点句 + 做法 + 数据 + 典型例子"。观点句要提炼，例如"坚持项目为王，经济发展动能持续增强"。
3. **存在的问题**（约 15%）：实事求是，3 条左右，具体不空泛，不写成变相表功。
4. **下一步打算**（约 15%）：与问题对应，有措施、有目标、有时间。
5. **意见建议 / 需要支持的事项**（如有）：具体到政策、资金、项目，便于上级研究。

**提炼标题的常用句式**：
- "坚持〔做法〕，〔领域〕取得新成效"
- "聚焦〔重点〕，推动〔工作〕走深走实"
- "以〔抓手〕为牵引，〔结果〕"
同一层级的标题字数、句式尽量对称。

## 3. 调研报告

结构：调研背景和方法（时间、范围、方式、样本）→ 基本情况 → 主要做法与成效 → 存在的问题及原因分析 → 对策建议。问题和建议一一对应；数据注明来源和口径，缺失的写〔待补充〕。

## 4. 经验交流材料

结构：基本情况（一段）→ 主要做法（3–4 条，每条"做法 + 机制 + 成效 + 案例"）→ 几点体会（可选）。突出可复制、可推广的做法，避免罗列日常工作；标题可用"以……推动……的实践与探索"。

## 5. 述职报告

结构：岗位职责概述 → 履职情况（政治理论学习、主要工作成效、作风建设、廉洁自律）→ 存在不足 → 今后努力方向。第一人称，实事求是，成绩用数据说话，不足要具体。

## 6. 交付前检查

- 观点句是否提炼到位，同级标题是否对称；
- 数据前后一致、口径清楚，引用文件名称和文号准确（不确定的标〔待核实〕）；
- 问题部分是否避重就轻；
- 篇幅是否符合汇报时长；
- 运行 `gov_lint.py` 检查格式问题。
