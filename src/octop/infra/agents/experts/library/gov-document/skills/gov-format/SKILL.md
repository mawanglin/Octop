# 公文排版与规范检查

> `scripts/`、`references/` 路径相对于本技能目录。完整示例：`references/example-notice.md`。

## 1. 写成 Markdown 源稿

```markdown
---
发文机关标志: 示例市人民政府办公室文件
发文字号: 示政办发〔2026〕12号
主送: 各区人民政府，市政府各部门
附件: 检查表；重点企业名单
署名: 示例市人民政府办公室
日期: 2026年10月17日
附注: 此件公开发布
抄送: 市委办公室，市人大常委会办公室
印发机关: 示例市人民政府办公室
印发日期: 2026年10月17日
---
# 关于开展2026年秋冬季安全生产\n大检查的通知

为……，现将有关事项通知如下。

一、检查时间

（一）道路交通安全。重点检查……

1. 疏散通道是否畅通。
```

**front matter 键名**（全部可选，不填就不输出该要素）：

| 键 | 说明 |
|----|------|
| `份号` `密级` `紧急程度` | 版心左上角 |
| `发文机关标志` | 红色版头，如"××市人民政府文件"或"××市人民政府" |
| `发文字号` | 如"示政办发〔2026〕12号" |
| `签发人` | 只用于上行文（请示、报告）；填写后发文字号居左、签发人居右 |
| `主送` | 主送机关，结尾冒号自动补 |
| `副标题` | 标题下方楷体一行（汇报材料常用"——在××会议上的汇报"） |
| `附件` | 附件名称，多个用"；"分隔，自动编号 |
| `署名` `日期` | 发文机关署名和成文日期（日期右空四字，署名居中于日期上方） |
| `附注` | 自动加圆括号 |
| `抄送` `印发机关` `印发日期` | 版记 |

**正文约定**：每个非空行是一个段落，自动首行缩进二字。以"一、""（一）""1.""（1）"开头的段落自动使用黑体、楷体、仿宋加粗等层次字体；"（一）小标题。正文"这种写法只把小标题部分设为楷体。标题过长时用 `\n` 在词意完整处手动分行。表格用 Markdown 表格；`<!-- pagebreak -->` 单独一行分页。

**不填 `发文机关标志`** 时没有版头，适合政府工作汇报、调研报告等汇报材料。

## 2. 规范检查

```bash
python scripts/gov_lint.py outputs/gov/<标题>.md [--doc-type 请示]
```

退出码 3 表示有问题，逐条修改后重查。检查项：标题标点和长度、文种、层次序数连续性、日期写法、半角标点、发文字号格式、签发人用法、请示结尾和主送、报告夹带请示、函的结语、附件说明。它是辅助工具，内容是否恰当仍要人工把关。

## 3. 排版

```bash
python scripts/docx_build.py outputs/gov/<标题>.md -o outputs/gov/<标题>.docx --style gov
```

版式要点（GB/T 9704-2012）：A4，版心 156×225mm（上 37mm、左 28mm）；正文 3 号仿宋_GB2312，每页 22 行；标题 2 号方正小标宋简体；一级标题黑体、二级标题楷体_GB2312；版头红色小标宋，下接红色分隔线；版记 4 号仿宋，首末线粗、中间线细；页码 4 号半角宋体"— 1 —"，单页居右、双页居左。

- 字体按名称写入文档，打开文档的电脑需要安装方正小标宋简体、仿宋_GB2312、楷体_GB2312，未安装时 Word/WPS 会自动替换。单位要求不同字体时用 `--fonts '{"title": "黑体", "body": "仿宋"}'` 覆盖（键：title、h1、h2、h3、body、header、page）。
- 版记紧跟正文排在文末，不会自动贴到页面底部；需要时告诉用户在版记前按回车调整，并确认版记位于最后一页。
- 印章、签发、正式编号由用户单位按程序办理。
