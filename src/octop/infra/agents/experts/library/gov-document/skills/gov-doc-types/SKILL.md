# 法定公文写法

各文种的结构模板和惯用语见 `references/doc-types.md`（相对本技能目录），起草前读取对应小节。

## 1. 选文种

| 要办的事 | 文种 | 行文方向 |
|----------|------|----------|
| 向上级请求指示、批准（要政策、要资金、要编制） | 请示 | 上行 |
| 向上级汇报工作、反映情况、答复询问 | 报告 | 上行 |
| 答复下级的请示 | 批复 | 下行 |
| 布置工作、转发/印发文件、告知事项 | 通知 | 下行（也可平行） |
| 表彰先进、批评错误、传达重要情况 | 通报 | 下行 |
| 对重要问题提出见解和处理办法 | 意见 | 上行/平行/下行 |
| 不相隶属机关之间商洽、询问、答复、请求批准 | 函 | 平行 |
| 记载会议主要情况和议定事项 | 纪要 | 下行/平行 |
| 对重要事项作出决策和部署、奖惩、变更 | 决定 | 下行 |
| 向国内外宣布重要事项或法定事项 | 公告 | 公布 |
| 在一定范围内公布应当遵守或周知的事项 | 通告 | 公布 |

常见混用：
- **请示 vs 报告**：需要上级批复的用请示；只是汇报、不要求答复的用报告。"请示报告""报告请示"不存在。
- **函 vs 请示**：向**不相隶属**的主管部门请求批准用函（如区政府向市财政局请求拨款），向**直接上级**用请示。
- **通知 vs 通报**：布置工作用通知；表彰批评、传达情况用通报。

## 2. 起草步骤

1. 定标题：`[发文机关]关于[事由]的[文种]`。转发类：`关于转发《××》的通知`，多层转发只保留最初文件名称，不写"转发关于转发……"。
2. 写开头：依据（"根据……""为……"）+ 目的，用过渡语引出主体（"现将有关事项通知如下：""现将有关情况报告如下："）。
3. 写主体：按"一、（一）1."分层，每层先给观点句再展开；部署类写清任务、责任单位、时间节点。
4. 写结尾：使用文种对应的结语（见 references）；不加多余的客套话。
5. 交给 `gov-format` 技能检查和排版。

## 3. 修改已有公文时重点看

1. 文种与事项是否匹配，行文方向是否正确（越级行文、多头主送）。
2. 标题三要素是否齐全，是否有标点、重复的"关于"。
3. 结构层次序数是否规范、连续。
4. 是否一文一事（请示），是否夹带请示（报告）。
5. 表述：口语化、歧义、模糊表述（"尽快""有关部门"）、数据和单位不一致。
6. 格式：日期、数字、标点、附件说明、署名。

修改意见按"问题位置 — 问题 — 改法"列出，再给出修改稿。
