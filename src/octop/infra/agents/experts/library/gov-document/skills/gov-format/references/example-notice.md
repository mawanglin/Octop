# 关于开展2026年秋冬季安全生产\n大检查的通知

为深入贯彻落实安全生产工作部署，有效防范化解秋冬季安全风险，经市政府同意，决定在全市范围内开展秋冬季安全生产大检查。现将有关事项通知如下。

一、检查时间

2026年10月20日至12月31日，分动员部署、自查自改、督导检查、总结提升四个阶段进行。

二、检查重点

（一）道路交通安全。重点检查“两客一危”车辆动态监控、驾驶人资质和车辆技术状况。

（二）消防安全。重点检查人员密集场所、高层建筑和老旧小区的消防设施完好情况。

1. 疏散通道和安全出口是否畅通。

2. 消防控制室是否落实24小时值班。

三、工作要求

（一）压实工作责任。各区、各部门要按照“管行业必须管安全”的要求，切实履行监管责任。

（二）强化信息报送。各单位于每月25日前将检查情况报市应急管理局。
