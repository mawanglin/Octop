# 简历撰写

> `scripts/` 和 `references/` 路径相对于本技能目录；示例：`references/example-resume.md`（虚构）。

## 1. 经历挖掘（没有简历或经历写得太空时逐项问）

1. 这份工作主要对什么结果负责？服务的对象是谁、规模多大？
2. 做过最有成就感的 2–3 件事是什么？当时的问题是什么、你具体做了什么？
3. 结果怎么衡量：提升了多少、节省了多少时间或钱、覆盖了多少人/门店/客户？
4. 有没有被表扬、晋升、获奖，或者做法被推广到其他团队？
5. 用了哪些工具、方法、证书？

## 2. 条目写法：动作 + 对象 + 结果

| 改前 | 改后 |
|------|------|
| 负责销售数据分析 | 搭建覆盖 120 家门店的销售看板，周报制作时间从 4 小时缩短到 30 分钟 |
| 参与会员运营 | 设计会员复购分析模型，识别高流失人群，配合活动使 90 天复购率提升 6.2 个百分点 |

强动词：主导、搭建、设计、推动、优化、重构、落地、牵头、制定、上线、谈下、培训、带领。
避免：负责、参与、协助、配合、做了（确实只是参与时，写清自己负责的部分）。

## 3. Markdown 格式

```markdown
# 姓名
求职意向：数据分析师 | 上海
电话：138-0000-0000 · 邮箱：name@example.com

## 工作经历
### 公司名称 | 职位 | 2022.03 – 至今
- 条目一
```

- `##` 是模块（个人优势、工作经历、项目经历、教育背景、技能证书），`###` 是一段经历，用 `|` 分隔，最后一段写时间（`2022.03 – 至今`）。
- 模块顺序：应届生 教育 → 实习 → 项目；有经验者 个人优势 → 工作经历 → 项目 → 教育 → 技能。

## 4. 体检与导出

```bash
python scripts/resume_docx.py check outputs/resume/简历.md
python scripts/resume_docx.py build outputs/resume/简历.md -o outputs/resume/简历.docx --style modern
```

- 体检：联系方式是否齐全、敏感信息、没有数字的经历条目、弱动词开头、过长条目、时间是否倒序、6 个月以上空档和重叠、预计页数。
- 版式：`classic`（宋体、居中姓名，适合国企、事业单位、传统行业）、`modern`（雅黑、蓝色标题，适合互联网和外企）、`compact`（小字号窄边距，内容多但要压到 1 页时使用）。
- 导出后建议用户在 Word 中打开看一遍，确认在 1–2 页内；需要 PDF 时用 Word 另存为 PDF。
