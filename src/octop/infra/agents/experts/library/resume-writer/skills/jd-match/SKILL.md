# 岗位匹配

> `scripts/` 和 `references/` 路径相对于本技能目录；示例 JD：`references/example-jd.txt`。

## 1. 运行

```bash
python scripts/jd_match.py inbound/JD.txt outputs/resume/简历.md
```

JD 和简历都支持 .txt / .md / .docx。输出：必备关键词覆盖率、必备和加分项中已覆盖 / 未覆盖的关键词、学历和年限是否满足。加 `--json` 输出结构化结果。

## 2. 解读

- **覆盖率只是提示**：脚本只做字面匹配和少量同义词（如 Tableau 算"数据可视化"），未覆盖可能只是写法不同。
- **"或"关系**：JD 写"Tableau 或 Power BI"时，具备其一即可，忽略另一个的未覆盖。
- **逐个确认**：对必备未覆盖的关键词逐个问用户"有没有相关经历"。有，就写进对应经历的条目（场景 + 做法 + 结果），而不是只加到技能栏；没有，就不写，并在面试准备中想好如何回应。

## 3. 按岗位调整简历

1. **个人优势**：前两条直接回应 JD 中最重要的 2–3 项要求。
2. **经历顺序**：同一段工作里，把与 JD 最相关的条目放在最前面。
3. **用词对齐**：JD 用"用户增长"，简历就不要只写"拉新"；同一能力用 JD 的说法。
4. **删减**：与目标岗位无关的条目缩短或删除，把篇幅留给相关经历。

每个目标岗位保存一个版本，如 `outputs/resume/简历-某公司数据分析师.md`。
