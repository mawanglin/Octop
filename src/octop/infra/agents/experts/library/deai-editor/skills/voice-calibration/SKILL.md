# 声音校准

去 AI 味的终点不是"像人写的"，而是"像这个人写的"。

## 1. 要样本

向用户要 2–3 篇本人写的旧稿（不是 AI 改过的），每篇 800 字以上最好；聊天记录、朋友圈长文也可以。没有样本时，用待改文稿里明显是作者原话的段落做基准，并告诉用户校准会比较粗。

## 2. 跑 profile，写风格卡

```bash
python ../ai-tone-check/scripts/ai_tone_check.py profile 旧稿1.md 旧稿2.md
```

整理成风格卡，保存到 `outputs/去AI味/风格卡-作者名.md`，并在用户同意后记进 AGENTS.md 的「偏好」：

```markdown
# 风格卡：××

- 句子：平均 18 字，短句多，常用一句话成段
- 标点：爱用破折号（每千字 31 个，属作者习惯），几乎不用感叹号和粗体
- 口语程度：中等，常用"其实、反倒、说到底"
- 常用句首：我、那年、后来
- 不用的：排比、成语、总结段
- 三句代表性原句：……
```

## 3. 改稿时怎么用

- `scan 文稿 --profile 旧稿…`：作者本来就常用的写法标为"作者习惯"，保留；
- 作者的拧巴、自相矛盾、口头禅原样留着，那是作者的诚实，不是错误；
- 改完抽三句作者原句放在改稿旁边对照：改稿哪里更长、更满、更想讨好读者，就照着收回来；
- 风格卡和通用规则冲突时，**以风格卡为准**。

## 4. 新写或代写时怎么用

照风格卡控制句长、段长、口语程度和标点；招牌写法（比如破折号）一篇最多用到风格卡里的频率，用多了就成了模仿秀。作者独有的经历和细节不能编，留 `[请作者补]`。
