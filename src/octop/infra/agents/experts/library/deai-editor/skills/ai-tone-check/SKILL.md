# AI 味检查

> `scripts/` 和 `references/` 路径相对于本技能目录；示例：`references/example-ai.md`（AI 味重的初稿）和 `references/example-humanized.md`（清理后，信息不变）。

## 1. 三个命令

```bash
python scripts/ai_tone_check.py scan 文稿.md                         # 找 AI 痕迹
python scripts/ai_tone_check.py scan 文稿.md --profile 旧稿1.md 旧稿2.md  # 带上作者习惯
python scripts/ai_tone_check.py diff 原稿.md 改稿.md                  # 核对改稿有没有丢信息、编信息
python scripts/ai_tone_check.py profile 旧稿1.md 旧稿2.md             # 作者写作习惯
```

都支持 `--json`。代码块、行内代码、网址、front matter、表格不参与规则检查。

## 2. 读 scan 的结果

| 标记 | 含义 | 处理 |
|------|------|------|
| `[门槛]` | 半角标点、粗体过多、惊叹号、emoji | 按 `deai-rules` 第 3 节直接改 |
| `[聊天残留]` | "希望对你有帮助""以下是为您……" | 删 |
| `[偏高]` | 本文频率达到人类均值 2 倍以上且至少 2 处 | 逐处按规则改 |
| `[留意]` | 有命中但频率不高 | 逐处看上下文，判不准就不改 |
| `[作者习惯]` | 作者旧稿里同样常用（`--profile`） | 保留，这是作者的声音 |
| 黑名单词 | 只是提示 | 看是否空泛、重复、不准 |

退出码：有偏高、门槛或聊天残留时为 3。规则只认字面形态，会误报（例如"不是 A 而是 B"在辨析概念时是正常写法），每处都要看上下文。

## 3. 读 diff 的结果

- **必须处理**：数字（含"三个月、两小时"）、引语和书名、英文和专名、链接、标题（忽略序号）、段落数、列表、代码块、表格的变化。新增的撤回，丢失的补回（确实是重复内容的除外）。
- **请确认**：否定词数量、"可能 / 约 / 部分"等限定词减少、"所有 / 一定 / 总是"等绝对化词增加。按词频统计，同义改写也会触发，逐处看语义有没有变。

退出码：有任何变动时为 3。

## 4. 局限

- 频率均值来自公开研究（AI 300 篇、人类 329 篇中文语料），语料本身未公开；数字说明写法差异，**不能证明文稿是谁写的**；
- 不保证通过任何"AI 检测器"，也不以此为目标——目标是读者读着舒服、信息准确；
- 少于 50 字的文本不检查，短文本没有统计意义。
