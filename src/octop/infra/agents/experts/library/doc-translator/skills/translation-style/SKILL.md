# 译法与规范

## 1. 按文体

| 文体 | 原则 | 要点 |
|------|------|------|
| 合同 / 法律 | 准确、严谨，宁可直译 | shall=应当（义务）、may=可以、shall not=不得；"甲方/乙方"→Party A/Party B；定义词首字母大写并全文一致；不省略"including but not limited to" |
| 技术文档 | 清晰、一致 | 操作步骤用祈使句；界面文字与软件实际译法一致并加粗或引号；单位和参数不改 |
| 营销文案 | 意译、本地化 | 先理解卖点再重写；口号可给 2–3 个备选；注意目标市场的文化和广告法 |
| 学术论文 | 规范、客观 | 摘要用一般现在时（结论）和过去时（方法）；术语采用领域通用译法，首次出现可括注原文 |
| 公文 / 新闻稿 | 正式、简练 | 机构名、职务、政策名称使用官方译法；数字和日期严格核对 |

## 2. 术语表

1. 开译前通读，列出：专有名词、产品和机构名、反复出现的行业术语、缩略语。
2. 查用户提供的参考资料或官方译法；拿不准的给出 2 个候选请用户选。
3. 保存为两列 CSV：`原文,译文`；新增术语随时追加并告知用户。
4. 缩略语首次出现写全称 + 括注缩写，如"人工智能（AI）"/ "Artificial Intelligence (AI)"。

## 3. 中英文排版

- 中文中夹英文和数字：两侧加空格（如"使用 Python 3.12"），全角标点前后不加空格。
- 英文中：使用半角标点，句号后一个空格；不要出现中文标点。
- 数字：英文千分位用逗号（1,200）；"万""亿"换算成 thousand / million / billion，并核对数量级（10 万 = 100,000）。
- 日期：中文"2026 年 10 月 18 日" ↔ 英文 "October 18, 2026"（美式）或 "18 October 2026"（英式），全文统一。
- 货币：人民币写 RMB 或 CNY，金额与原文一致，不自行换算汇率。

## 4. 常见误译

- "有关部门" → relevant authorities（不是 related departments）
- "加强" 不要每处都译 strengthen，可用 improve / enhance / step up
- "进一步" 常可省略
- "落实" → implement / put into practice
- 英译中避免"被"字句泛滥和"的的的"长定语，长句拆短。
