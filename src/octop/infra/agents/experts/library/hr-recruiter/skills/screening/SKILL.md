# 简历初筛

> `scripts/` 和 `references/` 路径相对于本技能目录；示例：`references/example-criteria.csv` 和 references/example-resumes/ 目录下的 3 份虚构简历。

## 1. 评分标准 CSV

```csv
维度,权重,关键词,必备
学历,10,本科,是
工作年限,15,3,是
SQL,20,SQL|MySQL|Hive,是
可视化,15,Tableau|Power BI|帆软|看板,否
```

- **关键词**用 `|` 分隔，命中任意一个即得该维度权重分；同一能力的不同写法都列上（如 "Power BI|PowerBI"）。
- **学历**：关键词写最低学历（大专 / 本科 / 硕士 / 博士），简历中的最高学历不低于它即命中。
- **工作年限**：关键词写最少年数；优先读取简历中"X 年…经验"的说法，否则按工作经历最早的日期估算。
- **必备**：是 / 否。必备项控制在 3–4 个，避免误杀。
- 权重合计不必等于 100，结果会显示满分。
- 不能包含性别、年龄、婚育、民族、籍贯、户籍、宗教、身高体重、相貌、政治面貌等维度，脚本会拒绝。

## 2. 运行

```bash
python scripts/screen.py outputs/hr/评分标准.csv inbound/简历/ -o outputs/hr/初筛结果.xlsx
```

- 支持 .txt / .md / .docx；装有 pdftotext 时支持 .pdf（扫描件读不到文字，会在备注中标出，需要人工看）。
- 「初筛结果」表：排名、总分、必备项是否满足、每个维度命中了哪些词、未满足的维度；高分（≥80% 满分且必备全满足）标绿，必备未满足标红。
- 「评分标准」表：本次使用的标准，便于留档。

## 3. 向用户汇报

1. 共多少份，必备项全满足多少份。
2. 前 5 名及各自的亮点和缺项。
3. 需要人工看的：读取失败、未满足必备项但总分较高（可能只是写法不同）。
4. 提醒：关键词匹配只是初筛参考，邀约前请人工阅读简历。
