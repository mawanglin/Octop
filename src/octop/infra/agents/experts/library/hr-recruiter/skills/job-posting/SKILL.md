# 岗位说明书

## 1. 结构

1. **岗位名称**：用行业通用叫法（"数据分析师"而不是"数据小能手"），可带方向（"数据分析师（零售）"）。
2. **岗位概述**：1–2 句话，这个岗位为什么存在、对什么结果负责。
3. **岗位职责**：4–6 条，动词开头，写清对象和目标，如"搭建门店经营指标体系，每周输出经营分析"。
4. **任职要求（必备）**：3–5 条，只写真正筛人的条件（经验年限、关键技能、必要资质）。
5. **加分项**：2–3 条，用"优先"标明。
6. **我们提供**：薪资范围（如公开）、福利、成长空间、工作地点和时间。

## 2. 写法要点

- 必备条件越多，合适的人越少；能入职后培养的放到加分项。
- 年限要求用"X 年以上相关经验"，不写"35 岁以下"。
- 技能写具体工具和场景（"能用 SQL 独立完成取数和数据校验"），少写"学习能力强"这类无法验证的描述。
- 招聘平台标题：`岗位名称 + 方向/亮点 + 地点`，如"数据分析师（零售方向，可远程 1 天/周）- 上海"。

## 3. 不合规用语与替代

| 避免 | 原因 | 替代写法 |
|------|------|----------|
| 限男性 / 女性优先 | 性别歧视 | 删除；体力要求写具体内容（"需搬运 20kg 货物"） |
| 35 岁以下 | 年龄歧视 | "3 年以上相关经验" |
| 已婚已育优先 / 未婚 | 婚育歧视 | 删除 |
| 限本地户口 / 某地人 | 户籍地域歧视 | 删除；确需本地工作写"工作地点在上海" |
| 身高 165 以上、形象好 | 与岗位无关 | 删除；确为岗位需要时写具体职业要求 |
| 985/211 毕业 | 容易被质疑 | "本科及以上，统计/数学/计算机相关专业" |

写完后自查一遍上表，并提醒用户：涉及健康、体能等特殊要求时需有岗位必要性依据。
