# 面试工具包

> `scripts/` 和 `references/` 路径相对于本技能目录；示例题目：`references/example-questions.md`。

## 1. 设计面试题

1. 从 JD 提炼 3–5 个能力维度（如专业能力、问题解决、沟通协作、学习能力），按重要程度分配权重。
2. 每个维度 1–2 题：
   - **行为题**（过去做过什么）："讲一个你……的例子，你具体做了什么？"
   - **情景题**（假设怎么做）："如果……你会怎么处理？"
3. 每题写考察点，面试官据此追问；避免问婚育、家庭、宗教等与岗位无关的问题。

写成表格保存为 `outputs/hr/面试题.md`：

```markdown
| 维度 | 问题 | 考察点 | 权重 |
|------|------|--------|------|
| 数据分析能力 | 讲一个你用数据推动业务决策的例子 | 问题拆解、方法、结果量化 | 30 |
```

## 2. 生成评估表

```bash
python scripts/interview_sheet.py form outputs/hr/面试题.md -o outputs/hr/评估表.xlsx --position 数据分析师
```

黄色格子由面试官填写：候选人、面试官、日期、每题 1–5 分（有下拉校验）、行为事实记录、结论。加权总分自动换算成百分制。表底有 1–5 分评分锚点。每位面试官、每位候选人各填一份。

## 3. 汇总

```bash
python scripts/interview_sheet.py aggregate outputs/hr/评估表-*.xlsx -o outputs/hr/面试汇总.xlsx
```

「候选人汇总」：面试官人数、平均加权分、最高 / 最低分、分歧维度（同一维度面试官打分相差 ≥2 分）；「维度明细」：每位面试官在每个维度的得分。分歧维度建议面试官复盘讨论，而不是直接取平均。

## 4. 通知模板（发送前请用户确认）

- **面试邀约**：岗位、时间（给 2–3 个选项）、地点或会议链接、面试形式和时长、需准备的材料、联系人。
- **录用通知**：岗位、入职日期、薪资福利（以正式 offer 为准）、报到材料、回复期限。
- **婉拒通知**：感谢投入时间，说明本次未能匹配，表示会保留简历（征得同意），不评价候选人。
