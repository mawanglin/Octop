# 商务邮件

英文邮件常用句型见 `references/email-phrases.md`（相对本技能目录）。

## 1. 结构

```
主题：〔动作/事项〕+〔关键信息〕+〔时间〕，例：【请确认】Q4 采购合同终稿（10/20 前）

〔称呼〕：
〔目的句：一句话说明为什么写这封邮件、希望对方做什么〕
〔背景/细节：2–4 句或分点〕
〔下一步：谁、做什么、什么时候；附件说明〕
〔结尾礼貌语〕
〔签名〕
```

- 主题行可加标签：【请确认】【请审批】【通知】【会议邀请】【跟进】；
- 正文超过 5 行就分段或分点；
- 附件在正文中逐个说明用途；
- 抄送提醒：需要知会但不需要行动的人放抄送。

## 2. 常见邮件

| 类型 | 要点 |
|------|------|
| 询价 | 需求（规格、数量、交期）→ 希望对方提供的信息（报价、资质）→ 回复期限 |
| 报价 | 感谢询价 → 报价摘要（价格、含税与否、有效期）→ 附件说明 → 后续联系 |
| 合作邀约 | 自我介绍（一句话）→ 为什么找对方 → 合作设想 → 具体的下一步（约 30 分钟通话） |
| 会议邀请 | 目的 → 时间地点/链接 → 议程 → 需要对方准备什么 → 回复确认 |
| 会后跟进 | 感谢参会 → 达成的共识（分点）→ 待办（负责人、时间）→ 下次沟通 |
| 通知 | 事项 → 影响范围 → 时间 → 需要大家做什么 → 联系人 |
| 感谢信 | 具体感谢什么（事例）→ 带来的影响 → 期待后续合作 |

## 3. 中英文互译

不逐字直译，按目标语言的习惯重写：
- 中译英：去掉"您好！非常感谢您百忙之中……"之类的冗长客套，开门见山；避免中式英语（"Please find the attached"可用，但"Hope you have a nice day"不必每封都写）；
- 英译中：把"I was wondering if you could…"这类委婉句式转成礼貌而直接的中文请求；
- 称呼、日期格式（英文用 October 20, 2026 或 20 Oct 2026）、货币单位按收件人习惯。

## 4. 发送前自查

收件人和称呼正确；目的句在前两句；日期与星期对应；附件已列明；没有遗留的〔 〕占位。
