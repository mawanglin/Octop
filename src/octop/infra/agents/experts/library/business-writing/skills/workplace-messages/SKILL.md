# 工作消息

IM 消息的原则：**一屏读完、一次说清、对方能直接回复**。

## 1. 常见场景模板

**向上请示**（让领导只需回复"同意"）：
```
〔领导称呼〕，〔事项〕需要您定一下：
方案 A：〔……〕，优点〔……〕
方案 B：〔……〕，优点〔……〕
我建议 A，因为〔一句话理由〕。〔日期〕前需要确定，您看可以吗？
```

**催办**（礼貌、具体、给台阶）：
```
〔称呼〕，〔事项〕原定〔日期〕完成，想跟您确认下进展～
后面〔下游事项〕在等这个结果，如果有困难或需要我这边配合，随时说。
方便的话今天下班前回复一个预计完成时间？
```

**跨部门求助**：
```
〔称呼〕你好，我是〔部门〕的〔姓名〕，负责〔项目〕。
想请你帮忙〔具体事项〕，需要在〔日期〕前，大约占用你〔时间〕。
背景是〔一句话〕。如果不方便，能推荐一下对接人吗？谢谢！
```

**进展同步**：
```
【〔项目〕进展 · 〔日期〕】
✅ 已完成：〔……〕
🔄 进行中：〔……〕，预计〔日期〕
⚠️ 风险：〔……〕，需要〔谁〕〔做什么〕
```

**群通知**：
```
【通知】〔事项〕
时间：〔……〕　地点/链接：〔……〕
需要大家：〔具体动作〕，〔截止时间〕前完成
有问题找〔联系人〕
```

**工作交接**：进行中事项（状态、下一步、截止时间）→ 资料位置 → 关键联系人 → 注意事项。

## 2. 写法规则

- 第一句话就说事，不要只发"在吗？"；
- 涉及多人时 @ 到具体的人，并写清各自要做什么；
- 给选项比问开放问题好回复（"周二下午还是周三上午？"）；
- 情绪激动时先不发，按 `tricky-conversations` 的方法改写；
- 表情符号按团队习惯，对上级和外部客户少用。
