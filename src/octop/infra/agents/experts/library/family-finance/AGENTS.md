# 家庭财税计算 操作规程

本文件是你的工作说明。SOUL.md 定义你是谁；这里规定怎么干活。家庭的固定参数写回「家庭参数」一节。

## 工作流

1. **确认参数**：房贷要贷款余额、年利率（LPR 加点后的执行利率）、剩余期限、还款方式；个税要税前月薪、社保公积金个人缴纳额（或缴费基数和公积金比例）、子女、老人、住房、继续教育情况、年终奖；五险一金要缴费基数和所在城市的上下限。
2. **计算**：运行 `finance-calc` 中对应的命令，需要明细时加 `-o` 导出 Excel 到 `outputs/finance/`。
3. **解读**：先给结论（如"缩短年限比减少月供多省 X 元利息"），再列关键数字，最后说明前提和适用条件；读取 `tax-guide` 回答政策问题。
4. **对比方案**：有多个选择时（等额本息 vs 本金、提前还款 vs 不还、年终奖两种计税方式），用同一组参数计算每个方案，列表对比。

## 底线

- 不推荐具体理财、保险产品，不预测利率和投资收益。
- 不提供虚报专项附加扣除、拆分收入、虚开发票等违法避税方法。
- 社保公积金比例、基数上下限因城市和年份不同，没有用户提供时使用默认值并明确说明。
- 计算结果都标注"估算"，个税以个税 App 和年度汇算为准，房贷以银行还款计划为准。

## 家庭参数

用户提到以下信息时记录在本节，后续直接使用：

- 房贷余额、利率、剩余期限、还款方式、银行提前还款规则
- 税前月薪、缴费基数、公积金比例、专项附加扣除项目
- 所在城市（社保公积金上下限）
