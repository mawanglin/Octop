# 来源分级细则

## 1. 判断顺序

1. **它是谁说的？** 当事方本人、官方渠道、专业机构，还是转述者？
2. **它是第一次说，还是转述？** 能追到更早的出处吗？
3. **有没有可核对的凭证？** 文号、原文链接、数据表、可查询的编号。
4. **时间对吗？** 发布日期是否早于它所说的事件？有没有后续更正？
5. **利益相关吗？** 来源是否和结论有利益关系（厂商自家测评、竞争对手的评价）？

## 2. 边界情况

| 情况 | 建议级别 | 说明 |
|------|----------|------|
| 政府网站的公告、通知、统计公报 | A | 注意是否为最新版本，有无后续修订 |
| 上市公司公告和财报 | A | 来自交易所或公司官网；二手摘要不算 |
| 论文 | A（原文）/ B（媒体解读） | 预印本未经评审，要在备注里写明 |
| 企业官网和发布会 | A（对自己的事实）/ C（对竞品的评价） | 厂商宣传口径不能当第三方结论 |
| 主流媒体的一般报道 | B | 看是否署名、是否引用了可查的信源 |
| 主流媒体的“匿名消息人士” | C | 只作线索，写进稿子要限定 |
| 行业自媒体、公众号 | C | 除非本身是当事方官方号（那就是 A） |
| 论坛、问答、评论区 | C | 只用来了解舆情和线索 |
| 截图、聊天记录、没有来源的转发 | D | 无法核实就不用 |
| AI 生成的摘要、百科的二次整理 | C | 要追到它引用的源头，不能当来源 |
| 过期的政策、已被更正的报道 | D | 状态标“不可用”，备注里写明已被什么取代 |

## 3. 摘录规范

- 一条来源 1–6 句原文，覆盖稿子要用的全部事实（数字、日期、人名、引语都要在摘录里）；
- 逐字复制，保留原有的数字和标点；可以截取，但不要把两处原文拼成一句；
- 需要上下文的，多摘一两句，不要靠自己补；
- 原文是图片或 PDF 扫描件的，转写后在备注里写“据图片转写”，并附原件位置；
- 英文来源保留英文原文，翻译另写在备注里，不能代替摘录。

## 4. 状态怎么选

| 状态 | 什么时候用 |
|------|-----------|
| 可用 | 级别 A 或 B，信息完整，没发现矛盾 |
| 存疑 | C 级，或 B 级但与别的来源有出入、发布日期未知、有未解决的疑点；写进稿子必须带限定语 |
| 不可用 | D 级，或已过期、已被更正、与官方明确冲突；备注里写原因，稿子不得引用 |
