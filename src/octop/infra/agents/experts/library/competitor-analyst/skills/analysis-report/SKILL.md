# 竞品分析报告

> `scripts/` 和 `references/` 路径相对于本技能目录；完整示例：`references/example-report.md`（产品和数据为虚构，演示结构与写法）。

## 1. 报告类型

| 类型 | 篇幅 | 结构 |
|------|------|------|
| 一页速览 | 500–1000 字 | 结论 3 条 → 概览表 → 建议 |
| 深度分析 | 3000–8000 字 | 核心结论 → 范围与方法 → 竞品档案与概览 → 分维度对比 → SWOT / 定位 → 建议 → 来源 |
| 功能专项 | 1500–3000 字 | 结论 → 功能矩阵 → 体验走查（截图、步骤数）→ 用户评价 → 建议 |
| 定价专项 | 1500–3000 字 | 结论 → 定价对比表（统一口径）→ 套餐和付费点 → 价格策略建议 |
| 动态监控 | 每期 500–1500 字 | 本期要点 → 各竞品动态（版本、价格、融资、人事、营销）→ 影响判断 → 需要跟进的事 |

## 2. 竞品档案（每个竞品都要有）

先用 `product-search` 的 `product_assets.py` 为每个竞品采集素材，把生成的 `profile.md` 放进“竞品档案”一节，再补充核心功能和价格。每个竞品一个三级标题，至少包含：

```markdown
### 速笔

- 官网：[https://…](https://…)；产品介绍页：[…](…)；定价页：[…](…)
- App Store / 应用市场：[速笔](…)，评分 4.7（12.3 万人评分），版本 3.2.0，上架 2023-05-01
- 运营主体：××科技有限公司（京ICP备…号）
- 官方介绍：“官网首页原文”（官网首页，获取日期）
- 核心功能：具体功能名（实时转写、支持 12 种方言、多端同步）；价格：个人版 22 元/月，7 天试用 [3]

![速笔官网首页（来源：官网，获取日期）](assets/速笔/page-home.png)

![速笔 App Store 截图 1（来源：App Store，获取日期）](assets/速笔/appstore-shot-1.jpg)
```

- 网址必须是实际访问过的；截图注明来源和获取日期；
- 分维度对比时引用档案里的截图（“见图”），比如对比首页卖点、关键流程、定价页；
- 报告和 `assets/` 目录放在同一个目录下，导出 Word 时图片会自动嵌入。

## 3. 写作标准

1. **结论先行**：第一节就是 3–5 条核心结论，每条是"判断 + 关键证据"，让只读第一节的人也能做决策；
2. **具体，不宽泛**：每个判断都要落到具体的功能名、数字、版本、价格、页面截图或用户原话上，见下表；
3. **每个数字有来源**：用 `[1]` 角标对应文末"信息来源"，或在表格下写"来源：……，获取于 ××"；
4. **写明时间**：标题区写"数据截至 ×× 年 ×× 月 ×× 日"，价格、版本、评分都会变；
5. **事实和推断分开**：推断写"推测 / 预计"并给依据；用户评论写"用户反馈"而不是事实；
6. **对比而不是罗列**：每节都要回答"和我方相比意味着什么"；
7. **建议可执行**：至少 3 条，每条写做什么、对应哪条结论、优先级，能量化的写目标；
8. **说明局限**：样本、时间、实测环境、没拿到的数据；
9. **不贬低、不臆测**：客观描述竞品，不做无依据的负面评价；不使用未公开的内部信息。

| ✗ 宽泛 | ✓ 具体 |
|--------|--------|
| 速笔功能丰富 | 速笔有实时转写（支持 12 种方言）、智能摘要、四端同步，比小记多“方言转写”和“Windows 客户端” |
| 云签体验较好 | 云签新建团队空间只需 2 步（见图），小记需要 5 步 |
| 用户较多、口碑不错 | 速笔 App Store 评分 4.7，12.3 万人评分（2026-10-20） |
| 定价有一定优势 | 云签个人版 15 元/月，比速笔低 7 元，但不含 AI 摘要 |
| 值得借鉴 | 速笔首页首屏直接放“录音转写演示”动图（见图），我们可以在首屏放 15 秒演示视频 |

## 4. 表格和图表

- 概览表：产品、定位、人群、规模指标、价格、最近更新；
- 功能矩阵：用 ✓ / ✗ / 部分，标注版本和日期；
- 评分雷达图和排名柱状图：用 `competitive-matrix` 生成的 Excel 图表，在 Word 里引用；
- 截图：注明产品、页面、版本和获取日期；用 `![说明](图片路径)` 插入。

## 5. 检查和导出

```bash
python scripts/report_check.py outputs/竞品/报告.md --competitors 速笔,云签
python scripts/docx_build.py outputs/竞品/报告.md -o outputs/竞品/报告.docx --style report
```

- `report_check.py` 有需要补充的地方时退出码为 3；"逐段提示"逐条确认：补来源、改写成有依据的表述，或确认无误后保留；
- 它会检查每个竞品有没有官网或产品介绍链接、有没有截图、具体事实是否少于 4 处，以及“功能丰富、体验较好”等宽泛表述；
- 导出 Word 时图片自动嵌入（相对路径以报告所在目录为准），链接显示为“文字（网址）”；
- 报告开头的 front matter 写 `副标题` 和 `署名行`（见示例），导出 Word 时用作封面信息；
- 需要汇报 PPT 时，把核心结论、概览表和雷达图交给「PPT 设计专家」。
