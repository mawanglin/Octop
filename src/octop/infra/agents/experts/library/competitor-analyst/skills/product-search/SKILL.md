# 产品搜索

> `scripts/` 路径相对于本技能目录。搜索工具用平台提供的联网搜索（`tavily_search`、`kimi_search`、`yuanbao_search`、`deepseek_search`、`google_search` 等，以当前启用的为准）、`web_fetch` 读网页，需要登录或动态渲染的页面用 `browser_use`。

## 1. 结构化数据脚本

```bash
python scripts/product_search.py appstore "AI 笔记" --country cn --limit 15 -o outputs/竞品/应用商店.xlsx
python scripts/product_search.py app 6474233312 6459478672             # 应用详情、更新说明
python scripts/product_search.py reviews 6474233312 --pages 5 -o outputs/竞品/评论.xlsx
python scripts/product_search.py github "ai agent framework" --limit 10
python scripts/product_search.py site https://example.com --history
```

| 子命令 | 用来回答 |
|--------|----------|
| `appstore` | 这个品类有哪些 App、谁的评分人数多（体量代理指标）、更新是否频繁 |
| `app` | 上架时间、版本节奏、最近更新了什么（更新说明）、官方怎么介绍自己 |
| `reviews` | 用户最近在抱怨什么、夸什么、哪个版本口碑变差；典型差评原文 |
| `github` | 开源竞品的社区热度、活跃度、许可证 |
| `site` | 定价、文档、更新日志、招聘页在哪；运营主体（ICP 备案、页脚公司）；技术栈和统计工具；App 链接 |

注意：App Store 评论接口只返回最新几百条，代表近期口碑；评分人数不等于用户数；网页时光机的"最早收录"是域名的，不一定是产品上线时间。

## 2. 找全竞品：四路法

1. **关键词搜**：用户会怎么描述这个需求（"会议记录 AI""录音转文字"），而不是产品自己的叫法；中英文各搜一遍；
2. **应用商店**：同品类搜索结果、"相似应用"、分类榜单；
3. **反向找**：竞品官网的"对比 / vs / 替代"页、评测文章的"同类推荐"、用户评论里提到的其他产品（`reviews` 原文里常有"不如某某"）；
4. **生态和资本**：融资报道、行业图谱、投资机构组合、应用市场的开发者其他产品。

按关系分组：**直接竞品**（同人群同需求同方式）、**间接竞品**（同需求不同方式）、**替代方案**（手工、Excel、通用工具）、**潜在进入者**（大厂、相邻品类）。深度分析一般选 2–4 个直接竞品 + 1–2 个间接竞品。

## 3. 按信息类型选数据源

| 想知道 | 优先看 |
|--------|--------|
| 功能和定位 | 官网首页和功能页、帮助文档、产品实际使用（截图） |
| 价格和套餐 | 官网定价页（记录获取日期）、应用内购买项、电商页 |
| 迭代方向 | 更新日志、App 更新说明（`app`）、发布会、产品负责人访谈 |
| 战略意图 | 招聘岗位（在招什么岗位 = 要做什么）、融资用途、财报和招股书 |
| 规模和增长 | 财报、官方公布的数据、应用商店评分人数和排名、第三方数据平台（注明口径） |
| 用户口碑 | 应用商店评论（`reviews`）、小红书、知乎、微博、黑猫投诉、电商评价 |
| 公司背景 | ICP 备案（`site`）、工商信息平台、融资数据库、官方新闻稿 |
| 技术路线 | 技术博客、开源仓库（`github`）、专利、API 文档 |
| 实体商品 | 电商详情页和参数、价格走势、评测视频、线下渠道 |

## 4. 可信度和交叉验证

| 等级 | 来源 | 用法 |
|------|------|------|
| 高 | 官网、财报、公告、应用商店官方数据、自己实测 | 可直接引用 |
| 中 | 权威媒体、第三方数据平台、行业报告 | 注明口径；关键数字找第二个来源 |
| 低 | 自媒体、用户评论、论坛、转述 | 只作线索或"用户反馈"，不作事实陈述 |

- 关键数字（用户规模、收入、价格）至少两个独立来源一致才写成事实；不一致时写区间并说明来源差异；
- 每条信息记录：来源链接、获取日期、可信度。后续写进 `competitive-matrix` 的证据表；
- 找不到就写"未公开"，不要估算后当成事实；推断要写明依据（如"根据在招 12 个海外岗位，推测在拓展出海"）；
- 页面内容会变：重要页面（定价页）保存截图或用网页时光机快照。

## 5. 看图

竞品界面截图、宣传图、海报、PDF 报告可以用 `read_file` 直接交给模型看（需要支持看图的模型）：分析信息架构、关键流程步骤数、视觉风格、卖点表达。截图要注明来源和获取日期。
