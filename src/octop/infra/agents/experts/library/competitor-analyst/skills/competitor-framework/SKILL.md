# 竞品分析框架

## 1. 先定目的：这份分析要支撑什么决策

| 目的 | 关注重点 | 典型产出 |
|------|----------|----------|
| 新产品立项 / 进入新市场 | 市场格局、空白点、进入壁垒 | 格局图 + 机会点 + 进入策略 |
| 功能规划 | 竞品的功能实现、体验差异、用户评价 | 功能矩阵 + 体验走查 + 优先级建议 |
| 定价和商业化 | 收费模式、套餐、价格带、付费点 | 定价对比表 + 定价建议 |
| 增长和营销 | 渠道、投放素材、内容策略、口碑 | 渠道对比 + 可借鉴打法 |
| 融资 / 汇报 | 格局、差异化、护城河 | 一页定位图 + 核心优势 |
| 持续监控 | 竞品动态（版本、价格、融资、人事） | 周报 / 月报 |

动笔前用一句话写下"决策问题"，例如"小记下个季度该优先补转写准确率还是做团队协作？"。和这个问题无关的信息不写。

## 2. 互联网产品：五个层次 + 两条线

| 层次 | 看什么 | 方法 |
|------|--------|------|
| 战略层 | 目标用户、核心需求、定位、愿景 | 官网口号、产品介绍、创始人访谈、招聘 |
| 范围层 | 功能清单、内容范围、做与不做 | 功能矩阵（有 / 无 / 部分），标注版本 |
| 结构层 | 信息架构、关键流程 | 画出导航结构和核心任务流程，统计步骤数 |
| 框架层 | 页面布局、交互方式 | 关键页面截图对比 |
| 表现层 | 视觉风格、品牌调性 | 截图、配色、文案语气 |
| 商业线 | 收费模式、价格、付费点、收入结构 | 定价页、应用内购买、财报 |
| 增长线 | 获客渠道、拉新和留存手段、口碑 | 投放素材、应用商店排名、社媒、邀请机制 |

**体验走查**：选 3–5 个核心任务（如"新用户第一次记录一场会议并分享"），每个竞品亲自走一遍，记录步骤数、耗时、卡点和亮点，并截图。走查结论比功能有无更能说明差异。

## 3. 常用工具和适用场景

| 工具 | 适合 | 注意 |
|------|------|------|
| 功能矩阵 | 功能规划，看差距和空白 | 不要只数功能多少，标出"核心 / 一般"，并结合体验质量 |
| 加权评分 + 雷达图 | 综合对比、汇报 | 用 `competitive-matrix`；权重要和决策目的一致，每个分数有证据 |
| 定位图（二维象限） | 找空白定位 | 两个轴要是用户真正在意且相互独立的维度（如"个人 ↔ 团队""通用 ↔ 垂直"） |
| 用户旅程对比 | 体验差异 | 按阶段（发现、注册、首次使用、日常使用、付费）对比 |
| SWOT | 总结我方处境 | 每条要具体并有证据；SO / WO / ST / WT 推出对策，才有价值 |
| 定价对比表 | 商业化 | 统一口径（按月、按人、按用量），注明试用和限制 |

## 4. AI 产品额外要看

- **效果**：用同一组真实任务实测并保存样例，比宣传更可信；
- **任务完成度**：只给建议，还是能自己调用工具完成多步任务；
- **模型和成本**：自研还是接入、上下文长度、多模态；免费额度和限制往往决定用户体验；
- **数据和安全**：数据是否用于训练、私有化部署、合规认证。

## 5. 通用产品（硬件、消费品、服务）

| 维度 | 看什么 |
|------|--------|
| 产品 | 核心参数和实测、差异化卖点、包装和规格 |
| 价格 | 价格带分布、主销价位、促销节奏、规格单价 |
| 渠道 | 线上平台（天猫、京东、抖音、拼多多）、线下网点、区域覆盖 |
| 推广 | 品牌定位、代言和达人、内容营销、投放 |
| 用户 | 电商评价和问答、复购、社媒口碑 |
| 供应链 | 产地、产能、品控、交付时效、售后政策 |

## 6. 好结论的标准

- **具体**：写清是哪个功能、哪个页面、多少钱、几步、哪个版本，配截图或原话；“功能丰富”“体验较好”这类话不提供信息；
- **有"所以呢"**：不是"竞品 A 有某功能"，而是"竞品 A 用某功能锁住了团队用户，我们短期不该正面竞争"；
- **有证据**：每个判断能指到来源或实测；
- **有对比**：和我方比、和行业平均比，而不是孤立描述；
- **区分事实和推断**：推断写明依据和不确定性。
