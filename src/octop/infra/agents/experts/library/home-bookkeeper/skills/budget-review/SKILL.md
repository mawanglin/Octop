# 预算与复盘

## 1. 制定预算

先用 `bill-import` 生成至少 1 个月（最好 3 个月）的账本和报告，再根据实际支出定预算，不凭空拍数字。

| 方法 | 适合 | 做法 |
|------|------|------|
| 50/30/20 | 收入稳定、第一次做预算 | 税后收入的 50% 必需（居住、买菜、交通、通讯、医疗），30% 想要（餐饮外卖、购物、娱乐），20% 储蓄和还款 |
| 零基预算 | 想精细控制 | 每一元收入都分配到类别，收入 − 各类预算 = 0 |
| 信封法 | 某几类经常超 | 只给超支类别设上限，花完为止 |

预算保存为 `outputs/ledger/预算.csv`，两列 `类别,月预算`，类别名与账本一致；参考 bill-import 技能的示例文件 example-budget.csv。

## 2. 月度复盘（结构）

1. **一句话结论**：本月结余多少、储蓄率多少，和上月比如何。
2. **变化最大的 3 个类别**：增加或减少多少，可能原因（请用户确认）。
3. **超预算**：哪些类别超了、超多少；是一次性支出还是持续性的。
4. **订阅扣费**：列出疑似订阅，问用户哪些还在用。
5. **大额支出**：列出并确认是否属于计划内。
6. **下月行动**：2–3 条具体建议，例如"外卖每周控制在 3 次以内，预计每月省 300 元"，建议要能用账本验证。

## 3. 省钱建议的原则

- 先看占比最大的类别和持续性支出（订阅、话费套餐、会员），再看偶发支出。
- 给出金额和可验证的指标，不说"少花点"这类空话。
- 尊重用户的优先级：用户明确说重要的支出（孩子教育、健康），不建议削减。
- 储蓄建议优先"先存后花"：发工资当天自动转出固定金额。

## 4. 应急金和储蓄目标

通用参考：应急金为 3–6 个月的必需支出，可以根据账本里"必需"类别的月均支出估算。具体理财产品选择不在本技能范围内。
