# 剪辑方案

## 1. 收集信息

- 素材：文件列表和每段的内容（有 ffmpeg 时用 `video-processing` 的 `probe` 查看时长、分辨率、帧率、有无音轨）；
- 依据：脚本、分镜表或用户的口述要求；
- 成片：平台、时长、横竖屏、风格参考。

## 2. 剪辑清单格式

```markdown
# 剪辑清单｜〔项目〕｜目标 〔60〕 秒｜〔抖音 9:16〕

| # | 素材 | 入点 | 出点 | 时长 | 内容 | 转场 | 字幕/花字 | 音乐/音效 | 处理方式 |
|---|------|------|------|------|------|------|-----------|-----------|----------|
| 1 | A001.mp4 | 0:12.0 | 0:15.0 | 3.0 | 开头钩子：空白文档特写 | 硬切 | 花字"周报写不出来？" | 键盘声 | 自动（cut） |
| 2 | A002.mp4 | 0:03.5 | 0:11.0 | 7.5 | 口播第一句 | J-cut | 口播字幕 | BGM 起 | 自动（cut） |
| … |
合计：〔58.5〕 秒
```

- 入点/出点用素材内的时间；"处理方式"写「自动（cut/subtitle/export）」或「手动（剪映：……）」。
- 同一素材的多个片段可以合并成一次 `cut --keep A --keep B`；不同素材需要先分别粗剪，再在剪辑软件里拼接（`video_tools.py` 一次只处理一个输入文件）。

## 3. 剪辑原则

1. **先粗剪后精剪**：先按清单拼出结构，时长达标后再调节奏、加字幕和音乐；
2. **开头最强**：最有冲击力的画面和口播放在前 3 秒，哪怕它在原素材的中间；
3. **删掉不推动内容的部分**：重复、停顿、口误、等待；
4. **音乐服务内容**：口播类 BGM 音量低、节奏平稳；展示类可卡点；
5. **结尾干净**：引导动作 + 定版（账号名/Logo），不拖尾。

## 4. 交付

剪辑清单 + 预计成片时长 + 自动处理的命令（`--dry-run` 结果）+ 需要手动完成的步骤列表（按用户的剪辑软件写具体操作）。
