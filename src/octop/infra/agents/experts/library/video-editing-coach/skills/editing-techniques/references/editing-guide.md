# 剪辑软件操作对照

> 软件版本更新较快，菜单名称可能变化；以下为常见版本的路径，回答时提醒用户以实际界面为准。

## 常用操作

| 操作 | 剪映（专业版） | Premiere Pro | 达芬奇 DaVinci Resolve | Final Cut Pro |
|------|----------------|--------------|------------------------|---------------|
| 分割 | Ctrl/Cmd + B | C（剃刀）或 Ctrl/Cmd + K | Ctrl/Cmd + B | Cmd + B |
| 删除并闭合空隙 | 选中后 Delete（自动吸附） | Shift + Delete（波纹删除） | Shift + Delete | Delete |
| 标记 | M | M | M | M |
| 播放/暂停 | 空格 | 空格 | 空格 | 空格 |
| 逐帧 | ← / → | ← / → | ← / → | ← / → |
| 自动字幕 | 文本 → 智能字幕 → 识别字幕 | 文本面板 → 转录 → 创建字幕 | Studio 版：时间线 → 创建字幕 | 第三方插件或导入 SRT |
| 导入 SRT | 文本 → 本地字幕 → 导入 | 文件 → 导入 SRT | 文件 → 导入 → 字幕 | 文件 → 导入 → 字幕 |
| 文本剪口播 | 文本剪辑（智能剪口播） | 基于文本的编辑 | Studio 版：智能剪辑 | — |
| 音乐踩点 | 选中音乐 → 踩点 | 手动 M 标记节拍 | 手动标记 | 手动标记 |
| 人声闪避 | 音频 → 智能降噪/人声分离 | 基本声音 → 音乐 → 回避 | Fairlight → 闪避 | 音频增强 |
| 调色 | 调节面板（HSL、曲线） | Lumetri 颜色 | 调色页面（节点） | 颜色板/颜色轮 |
| 导出 | 右上角导出 | Ctrl/Cmd + M | 交付页面 | Cmd + E |

## 导出参数建议

| 用途 | 编码 | 码率 | 音频 |
|------|------|------|------|
| 短视频平台 | H.264，High Profile | 1080p：8–12 Mbps | AAC 128–320 kbps，44.1/48 kHz |
| B 站 / 横屏 | H.264 或 H.265 | 1080p：10–20 Mbps；4K：40–60 Mbps | AAC 320 kbps |
| 存档母版 | ProRes 422 / DNxHR | 高 | PCM |

勾选"快速启动/Fast Start"（moov 前置），网络播放更快开始。

## 常见问题

| 问题 | 原因与处理 |
|------|------------|
| 竖屏素材在横屏时间线里变小 | 时间线分辨率设成 1080×1920 后再导入 |
| 手机素材导入后变横的 | 旋转元数据未识别：在软件中手动旋转，或用 `video_tools.py export` 重新编码 |
| 导出后画面有黑边 | 时间线比例与素材不一致；选择"裁切铺满"或调整时间线 |
| 声音和画面不同步 | 可变帧率（VFR）素材；先转码为恒定帧率（CFR）再剪 |
| 字幕被平台按钮挡住 | 移到安全区内（竖屏距底部约 20%） |
| 上传后画质变差 | 平台二次压缩；用平台推荐码率，避免过低码率和过多细碎纹理 |
