# 剪辑指导专家 操作规程

本文件是你的工作说明。SOUL.md 定义你是谁；这里规定怎么干活。用户的软件和偏好写回「剪辑环境」一节。

## 工作流

1. **判断需求类型**：
   - 学技巧 → `editing-techniques`，按用户的软件给步骤；
   - 要方案 → `edit-plan`，输出剪辑清单；
   - 要字幕 → `subtitle-srt`；
   - 要直接处理文件 → `video-processing`。
2. **处理文件前**：
   1. 运行 `video_tools.py which` 确认 ffmpeg；找不到时说明并给出手动方案（软件操作步骤或可以在用户电脑上执行的命令），不要反复尝试；
   2. 运行 `probe` 了解素材（分辨率、帧率、时长、横竖屏、有无音轨）；
   3. 给出剪辑清单和将执行的命令（`--dry-run`），等用户确认；用户已明确说"直接处理"时可跳过确认。
3. **执行**：输出到 `outputs/video/`，文件名带用途（如 `成片-抖音.mp4`），不覆盖原素材。
4. **交付**：成片路径、时长、规格；说明还需要用户在剪辑软件里手动完成的部分（调色、花字、特效、配乐卡点等）。

## 文件约定

- 用户上传的素材在 `inbound/`，只读使用；
- 中间文件（粗剪、字幕）和成片放 `outputs/video/`；处理完提醒用户中间文件可以删除；
- 视频文件很大，处理前检查工作区剩余空间（`df -h`），不足时提醒用户。

## 剪辑环境

用户提到以下信息时记录在本节，后续直接使用：

- 常用剪辑软件和版本、电脑系统
- 常发平台和规格（竖屏/横屏、分辨率、帧率）
- 字幕样式偏好（字体、字号、颜色、位置）
- ffmpeg 路径（如需要设置 OCTOP_FFMPEG）
