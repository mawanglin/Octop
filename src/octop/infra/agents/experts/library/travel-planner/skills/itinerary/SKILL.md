# 行程规划

## 1. 需求清单

| 项目 | 例子 |
|------|------|
| 目的地 / 天数 | 成都 3 天 2 晚 |
| 出发城市 / 方式 | 上海，高铁 |
| 人数 / 同行人 | 2 位成人；或 2 大 1 小（6 岁） |
| 总预算 | 4000 元（含大交通 / 不含） |
| 偏好 | 美食 > 人文 > 自然；不爱爬山 |
| 节奏 | 轻松：每天 2–3 个点，早上 9 点后出门 |

## 2. 排行程的步骤

1. **列候选**：必去 + 推荐地点，标注所在片区、建议游玩时长、是否需要预约。
2. **按片区分组**：同一片区放在同一天，片区之间按地理顺序排列，减少折返。
3. **定每天主题**：如"D1 老城街巷 + 火锅""D2 熊猫基地 + 博物馆"。
4. **排时段**：

| 时段 | 安排 |
|------|------|
| 上午 | 最重要或最需要早去的地点（人少、凉快、动物活跃） |
| 午餐 | 就近，12:00–13:30；热门餐厅提醒取号或避开饭点 |
| 下午 | 室内或轻松的地点；炎热天气避开户外暴晒 |
| 晚上 | 夜景、街区、演出；最后一项离住宿近 |

5. **留余量**：两个地点之间至少留 30 分钟交通时间；跨城移动日只排 1–2 个点。

## 3. 住宿区域

- 选交通枢纽或主要片区附近，减少每天通勤；连住比每天换酒店省时间。
- 第一天早到、最后一天晚走时，提醒寄存行李。

## 4. 不同人群的节奏

- **带孩子**：每天 2 个主要点，安排午休；优先有互动的场馆和公园。
- **带老人**：少走路、少换乘，避开大量台阶；餐食清淡、准时。
- **特种兵式**：可以紧凑，但每天至少保证 7 小时睡眠和两顿正餐。

## 5. 备选方案

每天准备一个雨天或闭馆时的备选（室内场馆、商场、博物馆），写在备注里。

## 6. 出发前核实

开放时间和闭馆日、门票和预约、交通班次、天气预报、证件（身份证 / 护照 / 学生证 / 老年证）、当地防疫或特殊规定。

排好后，用 `trip-sheets` 技能把行程写成表格并汇总费用。
