# 正则实验室

> `scripts/` 路径相对于本技能目录。

## 1. 验证

```bash
# 校验类：-M 应该匹配，-N 不应该匹配，默认整串匹配
python scripts/regex_test.py "1[3-9]\d{9}" -M 13800138000 -N 12345678901 -N 1380013800

# 提取类：查找全部 + 替换预览
python scripts/regex_test.py "(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})" -s "日期 2026-10-19 和 2025-01-02" --mode findall --replace "\g<y>年\g<m>月\g<d>日"

# 大量样例：每行一个
python scripts/regex_test.py "PATTERN" --file 样例.txt
```

预期全部符合时退出码为 0；有不符合或超时（默认 2 秒，可能是灾难性回溯）时为 3；正则语法错误为 1 并标出出错位置。

## 2. 常用正则（按需调整，说明适用范围）

| 用途 | 正则 | 说明 |
|------|------|------|
| 中国大陆手机号 | `1[3-9]\d{9}` | 11 位，不含 +86 前缀 |
| 邮箱 | `[\w.+-]+@[\w-]+(?:\.[\w-]+)+` | 覆盖常见写法，不做完整 RFC 校验 |
| 身份证号 | `[1-9]\d{5}(?:18\|19\|20)\d{2}(?:0[1-9]\|1[0-2])(?:0[1-9]\|[12]\d\|3[01])\d{3}[\dXx]` | 只校验格式，不校验校验位 |
| 日期 | `\d{4}[-/.年]\d{1,2}[-/.月]\d{1,2}日?` | 不校验 2 月 30 日这类非法日期 |
| 金额 | `-?\d{1,3}(?:,\d{3})*(?:\.\d{1,2})?\|-?\d+(?:\.\d{1,2})?` | 支持千分位 |
| IPv4 | `(?:(?:25[0-5]\|2[0-4]\d\|1?\d?\d)\.){3}(?:25[0-5]\|2[0-4]\d\|1?\d?\d)` | 每段 0–255 |
| URL | `https?://[^\s"'<>]+` | 提取用，不做严格校验 |
| 中文 | `[\u4e00-\u9fff]+` | 常用汉字区 |

## 3. 常见陷阱

- **校验要锚定**：JavaScript `test()`、Java `find()` 是部分匹配，`\d{11}` 会让 12 位数字通过，校验时写 `^…$`。
- **点要转义**：`192.168.1.1` 里的 `.` 匹配任意字符，写成 `\.`。
- **贪婪**：`<.*>` 会从第一个 `<` 吞到最后一个 `>`，用 `<.*?>` 或 `<[^>]*>`。
- **灾难性回溯**：`(a+)+`、`(\w*)*`、`(a|aa)*` 遇到不匹配的长输入会卡死，改成不重叠的写法。
- **[A-z]** 会包含 `[ \ ] ^ _` 等符号，写 `[A-Za-z]`。

## 4. 各环境差异

| 环境 | 命名组 | 替换引用 | 备注 |
|------|--------|----------|------|
| Python `re` | `(?P<name>…)` | `\1`、`\g<name>` | 用原始字符串 `r"…"` |
| JavaScript | `(?<name>…)` | `$1`、`$<name>` | `/…/g` 全局，`/u` 支持 Unicode |
| Java | `(?<name>…)` | `$1`、`${name}` | 字符串里反斜杠要写两次 `\\d` |
| Excel 365 | `REGEXEXTRACT` / `REGEXREPLACE` | `$1` | 新版函数，旧版不支持 |
| VS Code 查找替换 | `(?<name>…)` | `$1` | 打开 `.*` 按钮 |
| Notepad++ | `(?<name>…)` | `\1` 或 `$1` | 选择"正则表达式"模式 |
