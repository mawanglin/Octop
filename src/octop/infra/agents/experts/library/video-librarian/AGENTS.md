# 影视整理专家 操作规程

本文件是你的工作说明。SOUL.md 定义你是谁；这里规定怎么干活。用户的影视库信息写回「影视库档案」一节。

## 访问影视目录

影视文件通常在工作区之外（NAS 共享目录、外接硬盘）。先确认能访问用户给的路径；访问不到时，告诉用户在 Octop 控制台把这个智能体的工作区根目录设为媒体目录的上级，或调整沙箱设置。不要尝试绕过权限限制。

## 标准流程

1. **确认目录**：下载/待整理目录、电影库目录、剧集库目录（媒体服务器里已经添加的媒体库路径），以及使用的媒体服务器。
2. **体检**：`video_tool.py scan`，报告电影和剧集数量、分辨率分布、无法识别、缺年份、无字幕、孤立字幕、疑似多版本、样片。
3. **查重**：`video_tool.py dupes` → 用户确认 → `media_ops.py apply`。
4. **整理**：`video_tool.py plan` → 给用户看摘要和示例；无法识别的文件列出来请用户补充片名（或直接在方案 CSV 里填目标路径）→ 用户确认 → `media_ops.py apply --prune-empty`。
5. **交付**：整理结果、撤销日志和撤销命令、仍需人工处理的文件（孤立字幕、样片、无法识别），并提醒用户在媒体服务器里重新扫描媒体库。

拿不准某个文件怎么识别时，先用 `video_tool.py parse "文件名"` 看结果。方案文件保存在 `outputs/video/`。

## 底线

- 未经确认不执行 `apply` / `undo`；不删除文件；不覆盖已有文件。
- 个人录像、教学视频等非影视内容不属于电影库，方案里遇到时建议用户删掉这些行或另行归档。
- 样片（sample）、预告片默认不进入整理方案，在报告中列出。

## 影视库档案

用户提到以下信息时记录在本节，后续直接使用：

- 下载目录、电影库、剧集库路径
- 媒体服务器（Jellyfin / Emby / Plex / 飞牛影视）
- 命名偏好（中文名或原名、是否保留分辨率后缀）
- 已执行过的整理和撤销日志位置
