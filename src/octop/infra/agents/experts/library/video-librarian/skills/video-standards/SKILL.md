# 影视库规范

## 1. 推荐结构

```
电影/
└── 流浪地球2 (2023)/
    ├── 流浪地球2 (2023).mkv
    ├── 流浪地球2 (2023).zh.srt
    └── 流浪地球2 (2023) - 2160p.mkv        ← 多版本
剧集/
└── 三体/
    ├── Season 01/
    │   ├── 三体 S01E01.mp4
    │   └── 三体 S01E01.zh.ass
    └── Specials/                           ← 特别篇按 Season 00 处理
```

- **一部电影一个文件夹**，文件夹名和文件名都是"片名 (年份)"；年份对刮削准确度影响最大。
- **剧集按季分文件夹**：`Season 01`、`Season 02`；文件名必须含 `S01E01`。
- 片名用中文还是原名都可以，与刮削源（TMDB、豆瓣插件）的标题越接近越容易匹配；两种都匹配不上时，可以在文件夹名后加 TMDB 编号，如 `流浪地球2 (2023) [tmdbid=〔在 TMDB 网站查到的编号〕]`（Jellyfin、Emby、飞牛影视支持该写法，建议核实对应版本）。

## 2. 特殊情况

| 情况 | 写法 |
|------|------|
| 多版本 | `片名 (年份) - 1080p.mkv`、`片名 (年份) - 2160p.mkv` 放在同一文件夹 |
| 分段电影（CD1/CD2） | `片名 (年份) - part1.mkv`、`- part2.mkv` |
| 特典、花絮 | 电影文件夹下建 `extras/` 子目录 |
| 一个文件包含两集 | `剧名 S01E01-E02.mkv` |
| 特别篇 | `Season 00` 或 `Specials` 文件夹，`剧名 S00E01.mkv` |
| 动画绝对集数（第 1000 集） | 按播出季拆分，或使用支持绝对集数的刮削插件 |

## 3. 字幕

- 与视频同名，加语言后缀：`.zh`（简体/中文）、`.zh-TW`（繁体）、`.en`、`.ja`；双语字幕按主要语言标注。
- 一个视频多份同语言字幕：`.zh.srt`、`.zh.2.srt`。
- 内封字幕（MKV 内）不需要外挂文件；字幕不显示时检查播放器是否支持 ASS 特效字幕。

## 4. 刮削问题排查

| 现象 | 可能原因和处理 |
|------|----------------|
| 匹配成同名的另一部片子 | 补上年份；或加 TMDB 编号 |
| 剧集季号错乱 | 文件不在 `Season XX` 文件夹里，或文件名缺 `S01`；按规范整理 |
| 中文片名搜不到 | 改用原名或英文名，或在媒体服务器中手动识别 |
| 多版本被显示成两部片子 | 两个文件不在同一文件夹，或文件夹名不一致 |
| 字幕没有被识别 | 字幕文件名与视频不一致或缺语言后缀 |
| 整理后海报丢失 | 媒体服务器缓存未更新；重新扫描媒体库并刷新元数据 |
