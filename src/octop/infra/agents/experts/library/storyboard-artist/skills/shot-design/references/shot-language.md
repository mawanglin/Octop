# 镜头语言速查

## 景别（分镜表「景别」列使用这些写法）

| 景别 | 画面范围 | 作用 |
|------|----------|------|
| 大远景 | 广阔环境，人物很小或不出现 | 开场交代、气势、城市/自然风光 |
| 远景 | 环境为主，人物可辨 | 交代人物所处环境 |
| 全景 | 人物全身 + 周边环境 | 动作、人物关系、空间位置 |
| 中景 | 膝盖或腰部以上 | 叙事主力、对话、动作 |
| 中近景 | 胸部以上 | 口播常用，兼顾表情和手势 |
| 近景 | 胸部以上偏紧/肩部以上 | 表情、情绪、口播 |
| 特写 | 脸部或物体局部 | 强调细节、情绪高点 |
| 大特写 | 眼睛、嘴角、产品某个按键 | 极强调、悬念、质感 |

## 运镜（分镜表「运镜」列使用这些写法）

| 运镜 | 说明 | 适用 |
|------|------|------|
| 固定 | 机位不动 | 口播、对话、稳重 |
| 推 / 缓推 | 镜头向主体靠近 | 强调、进入情绪 |
| 拉 | 镜头远离主体 | 揭示环境、结束 |
| 摇 | 机位不动，镜头左右/上下转动 | 扫视环境、关联两个主体 |
| 移 / 滑轨 | 机位平行移动 | 展示空间、产品陈列 |
| 跟 | 跟随主体运动 | 代入感、探店、运动 |
| 升 / 降 / 升降 | 机位垂直移动 | 开场、收尾、气势 |
| 环绕 | 围绕主体旋转 | 产品展示、人物高光 |
| 手持 | 手持拍摄，轻微晃动 | 纪实感、紧张感 |
| 航拍 | 无人机 | 城市、风光、宣传片开场（需报备空域） |
| 甩 | 快速摇动形成模糊 | 转场 |
| 变焦 | 改变焦距 | 快速强调（慎用） |
| 升格 / 降格 | 高帧率慢动作 / 低帧率快动作 | 情绪、动作细节 / 时间流逝 |
| 延时 | 长时间间隔拍摄 | 日夜变化、人流车流 |
| 主观镜头 | 模拟人物视角 | 代入、悬念 |

## 机位角度

平拍（客观）、俯拍（弱小、全局）、仰拍（高大、力量）、顶拍/俯视 90°（美食、桌面操作）、过肩（对话）、侧拍（动作）。

## 构图

三分法、中心构图（口播、对称建筑）、引导线、框架构图（门窗）、前景遮挡（层次感）、留白（视线方向留空间）。竖屏 9:16 注意人物头顶留白不超过画面 1/10，底部为字幕和平台按钮留出安全区（约下方 1/5）。

## 转场

硬切（默认）、动作匹配、遮挡转场（物体挡住镜头）、甩镜转场、叠化（时间流逝）、黑场/白场（段落分隔）、卡点切（跟音乐节拍）、相似形状/颜色匹配。

## 声音

现场同期声、旁白/画外音、口播、音效（环境声、动作声、提示音）、BGM（起、高潮、收）。分镜表「音效/音乐」列写出关键的起止点。
