# 拍摄计划

## 1. 拍摄通告单

```markdown
# 拍摄通告｜〔项目〕｜〔日期〕

- 集合：〔时间〕〔地点〕（附导航地址/停车说明）
- 收工预计：〔时间〕
- 天气/日出日落：〔用户提供或〔待查〕〕
- 联系人：导演〔姓名电话〕，制片〔姓名电话〕

| 时间 | 场景/地点 | 镜号 | 内容 | 人员 | 备注 |
|------|-----------|------|------|------|------|
| 09:00–10:30 | 工位 | 1、2、4、5 | 口播主镜头 + 录屏 | 出镜人、摄影 | 自然光，避开正午 |

注意事项：服装〔颜色要求，避免细条纹〕、道具〔清单〕、场地许可〔已确认/待确认〕
```

排时间时：同场景镜头集中（参考分镜表的「拍摄顺序」工作表）；室外镜头按光线安排（早晚光线柔和，正午避免人像）；先拍难度大、依赖演员状态的镜头；每 2 小时留休息，预留 20% 机动时间。

## 2. 器材清单

按"摄影 / 镜头 / 稳定 / 灯光 / 收音 / 存储供电 / 其他"列出，标明数量和负责人。根据分镜里的运镜反推：跟拍、环绕 → 稳定器；滑轨镜头 → 滑轨；航拍 → 无人机 + 备用电池 + 报备；口播 → 领夹麦 + 补光灯；升格 → 支持高帧率的机身和足够快门光线。

## 3. 现场检查表

- 开拍前：电池、存储卡格式化、分辨率帧率（与成片一致，竖屏还是横拍竖裁）、白平衡、收音电平；
- 每条拍完：回看焦点和收音，关键镜头多拍 2–3 条；
- 场记：记录每个镜号的最佳条数，方便剪辑（可以在分镜表「备注」列补充）；
- 收工前：对照分镜表逐个镜号确认无遗漏，素材双备份。

## 4. 备用方案

列出主要风险和预案：下雨（改室内场景/调整顺序）、演员迟到（先拍空镜和产品）、场地临时不可用（备用场地）、设备故障（备用机身/手机拍摄的降级方案）。
