# 镜头设计

镜头语言速查（景别、运镜、角度、构图、转场的含义和适用场景）见 `references/shot-language.md`（相对本技能目录）。

## 1. 拆镜头的步骤

1. **按信息点切**：脚本里每个新信息、新动作、新地点都是一个新镜头。
2. **定景别**：先交代（全景/远景）→ 再叙事（中景）→ 后强调（近景/特写）；情绪越强景别越近。
3. **定运镜**：没有理由就用固定镜头；运镜要有目的——推（强调、进入）、拉（揭示、离开）、跟（陪伴、代入）、摇（扫视、关联）、移（展示空间）、升降（开场、收尾、气势）。
4. **定时长**：信息量小的空镜 1–2 秒；口播主镜头按台词字数（约 4 字/秒）；动作镜头按动作完成时间。
5. **定转场**：默认硬切；同一动作跨镜头用动作匹配剪辑；时间流逝用叠化或黑场；节奏点上用卡点。

## 2. 常见视频类型的镜头配方

| 类型 | 配方 |
|------|------|
| 口播 | 主镜头近景（对镜头）+ 每 5–8 秒插入 1 个 B-roll（特写细节、操作画面、相关场景）；关键句切中景/特写变化 |
| 产品展示 | 全景出场 → 环绕/推近 → 细节特写（材质、按键、接口）→ 使用场景中景 → 产品 + 品牌定版 |
| 教程 | 成品全景 → 材料俯拍 → 每个步骤的手部特写 → 关键步骤慢动作（升格）→ 成品再现 |
| 探店/Vlog | 门头远景 → 跟拍进入 → 环境摇镜 → 菜品/商品特写 → 人物反应近景 |
| 宣传片 | 航拍/大远景开场 → 人物与场景交替 → 数据或成就用特写/图形 → 群像全景收尾 → 标志定版 |

## 3. 自查

- 连续 3 个镜头景别相同 → 调整其中一个；
- 运镜方向前后矛盾（上一个镜头向左摇，下一个向右）→ 统一或用固定镜头隔开；
- 越轴：两人对话时摄影机保持在轴线同一侧；
- 每个镜头都能回答"为什么要这个镜头"。
