# 讲话稿结构模板

以下〔 〕内为需要替换的内容，示例单位和事项均为虚构。

## 部署讲话（工作会议、专项部署会）

```
同志们：
今天召开〔会议名称〕，主要任务是〔贯彻……，分析……，部署……〕。刚才，〔××同志〕通报了〔情况〕，〔几个单位〕作了发言，讲得都很好，我都同意。下面，我讲〔三〕点意见。

一、提高站位，充分认识〔工作〕的重要性和紧迫性
（意义 → 形势 → 差距，各 1–2 段）

二、突出重点，扎实推进〔工作〕各项任务
（一）〔任务一〕。……要……
（二）〔任务二〕。……
（三）〔任务三〕。……

三、压实责任，确保〔工作〕取得实效
（组织领导、责任落实、督查考核、宣传引导）

同志们，〔工作〕任务艰巨、责任重大。让我们〔号召〕，为〔目标〕作出新的更大贡献！
```

## 总结表彰讲话

开场（会议目的 + 向受表彰者祝贺）→ 一、充分肯定成绩（数据 + 典型）→ 二、认真总结经验（3 条"坚持……"）→ 三、清醒看到不足 → 四、明确下步任务 → 结尾号召。

## 交流发言 / 典型发言（下级在会上）

```
尊敬的〔领导〕，各位同志：
根据会议安排，现将〔单位〕〔工作〕情况汇报如下，不妥之处请批评指正。
一、〔做法一〕：做法 + 成效 + 小案例
二、〔做法二〕
三、〔做法三〕
下一步，我们将……（2–3 句）
汇报完毕，谢谢！
```
时长通常 5–8 分钟（1100–1800 字）。

## 表态发言

```
尊敬的〔领导〕，同志们：
刚才，〔领导〕作了重要讲话，……。我们坚决拥护、全力落实。我代表〔单位〕作如下表态：
一是提高认识，……
二是聚焦任务，……（具体措施和目标）
三是压实责任，……
我们将以〔态度〕，确保〔目标〕。我的表态完毕，谢谢！
```
3–5 分钟（700–1100 字），"一是、二是、三是"并列，每条一个承诺。

## 开幕致辞 / 欢迎致辞 / 签约仪式致辞

问候 → 祝贺/欢迎（代表谁、向谁）→ 活动意义（1–2 段）→ 期望（2–3 点）→ 祝愿（"预祝……圆满成功！"）。时长 2–3 分钟（500–700 字）。称呼按"尊敬的〔最高领导〕，尊敬的〔嘉宾〕，各位〔来宾〕，女士们、先生们"排列。

## 闭幕致辞

会议/活动评价（"这是一次……的会议"）→ 主要成果 → 落实要求 → 感谢（主办、承办、服务人员）→ 宣布闭幕。

## 年会致辞（企业负责人）

感谢（员工、家属、客户、伙伴）→ 回顾一年（3 个高光时刻，各配一个具体的人或事）→ 正视挑战（一句话）→ 新一年目标和期望 → 新年祝福。温暖、具体，避免念报表；3–5 分钟。

## 竞聘演讲

开场（姓名、现任岗位、竞聘岗位，一句话动机）→ 我的优势（经历、业绩、能力，各配事实）→ 对岗位的认识 → 工作设想（3 条，具体可行）→ 结尾表态（"无论结果如何……"）。通常 5–8 分钟，忌贬低他人、空喊口号。

## 常用句式

| 用途 | 句式 |
|------|------|
| 承接 | 刚才……讲得很好，我都同意。／这是第一点。下面讲第二点。 |
| 强调 | 必须清醒地看到……／特别是……／关键在于…… |
| 要求 | 要坚持……，做到……／各级各部门要…… |
| 号召 | 让我们……，以……的精神，奋力……！ |
| 祝愿 | 预祝本次大会圆满成功！祝大家身体健康、工作顺利、阖家幸福！ |
