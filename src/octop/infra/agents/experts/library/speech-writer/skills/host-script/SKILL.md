# 主持词与串词

## 1. 先拿到流程单

请用户提供活动流程（环节顺序、每个环节的内容、上场人员姓名职务、时长）。没有流程单时，先根据活动类型给出一份常见流程请用户确认。

## 2. 结构

1. **开场白**：问候 → 活动主题和意义 → 介绍出席领导和嘉宾（按职务高低，"让我们以热烈的掌声欢迎……"）→ 宣布开始。
2. **环节串词**：每个环节"承上（一句评价/感谢上一环节）→ 启下（引出下一环节和上场人员）"，30–60 字。
3. **互动**（年会、沙龙）：抽奖、游戏、提问的规则说明和控场话术。
4. **结束语**：总结 → 感谢 → 祝福 → 宣布结束和后续安排（合影、用餐、离场）。

## 3. 写法规则

- 会议主持：简洁庄重，不抢领导讲话的内容；每个环节"下面，请〔职务〕〔姓名〕同志〔讲话/发言〕，大家欢迎。"讲话后可简要概括一句。
- 晚会/年会双主持：标注"男：""女：""合："，台词交替、长度相近；节目串词结合节目内容，避免千篇一律的"让我们掌声欢迎"。
- 颁奖：先读奖项意义或颁奖词（50–80 字），再公布获奖者，再请颁奖嘉宾上台。
- 姓名和职务务必与用户提供的一致，不确定的写〔待核实〕；介绍顺序按用户单位惯例。
- 预留应急串词：环节延误、设备故障、嘉宾未到时的过渡句 2–3 条。

## 4. 输出格式

```markdown
## 【开场】（约 2 分钟）
男：尊敬的各位领导、各位来宾，
女：亲爱的同事们，
合：大家晚上好！
……

## 【环节一：领导致辞】
女：……下面，让我们以热烈的掌声，有请〔职务〕〔姓名〕致辞！
```

每个环节标注预计时长，合计与活动总时长核对；需要照读版时用 `speech-export` 导出。
