# 讲话稿写作

各类讲话的结构模板和常用句式见 `references/speech-types.md`（相对本技能目录），动笔前读取对应小节。

## 1. 按身份和场合定口吻

| 讲话人与场合 | 口吻 | 主体内容 |
|--------------|------|----------|
| 上级/主要领导在部署会、动员会 | 有力、明确，多用"要""必须" | 形势判断 → 重点任务 → 工作要求 |
| 领导在总结表彰会 | 肯定、鼓舞 | 成绩回顾 → 经验启示 → 下步要求 |
| 下级/部门在会上发言 | 务实、谦逊 | 工作做法 → 成效 → 下步打算 |
| 表态发言 | 坚定、简短（3–5 分钟） | 认识到位 → 措施到位 → 决心到位 |
| 嘉宾在开幕式、签约仪式致辞 | 热情、得体（3 分钟内） | 祝贺 → 意义 → 期望与祝愿 |
| 年会、联欢致辞 | 温暖、有感染力 | 感谢 → 回顾高光时刻 → 展望 → 祝福 |
| 竞聘、述职演讲 | 自信、真诚 | 我是谁 → 我做了什么 → 我将怎么做 |

## 2. 开头和结尾

**开头**（全文 5–10%）：
- 会议讲话："同志们：今天召开……会议，主要任务是……。刚才，……我都同意。下面，我讲几点意见。"
- 致辞："尊敬的……，各位……：大家上午好！金秋十月，……。在此，我谨代表……，向……表示热烈的祝贺！"
- 演讲：一个具体故事、一个问题或一句与主题相关的话，30 秒内点题。

**结尾**（全文 5–10%）：总结一句 + 号召/展望/祝愿。部署讲话可用"同志们，……任务艰巨、责任重大，让我们……"；致辞以祝愿收尾；演讲以"谢谢大家！"收尾。

## 3. 让稿子"好念"

- 观点句排比：三个部分的观点句字数、结构对称（"提高站位，……；聚焦重点，……；压实责任，……"）。
- 每 1–2 分钟设一个"抓耳点"：数据、案例、金句或设问。
- 少用括号、引号套引号、长串并列名词；需要列举时控制在 3–4 项。
- 承上启下的过渡句："这是第一点。第二，……""成绩来之不易，问题也不容忽视。"

## 4. 篇幅控制

目标字数 = 时长（分钟）× 语速。正式讲话约 220 字/分钟，致辞约 240，演讲约 260。成稿后运行 `speech-export` 技能的 `speech_timer.py` 核对，偏差超过 10% 时增删。

## 5. 修改已有讲话稿

先按"身份口吻是否对、结构是否清楚、时长是否合适、哪些句子不好念"列出问题，再给修改稿；保留讲话人原有的个人风格和口头习惯。
