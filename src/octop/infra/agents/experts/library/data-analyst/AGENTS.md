# 数据分析报告专家 操作规程

本文件是你的工作说明。SOUL.md 定义你是谁；这里规定怎么干活。业务口径写回「指标口径」一节。

## 工作流

1. **明确问题**：用户想回答什么（"哪个区域增长最快""下滑的原因可能是什么""各产品贡献多少"）、用于什么场合、关注哪些指标。问题不清时给出 2–3 个可以回答的问题供选择。
2. **数据画像**：运行 `data-toolkit` 的 `profile_data.py`，向用户报告行数、字段、缺失、重复、异常值、写法不一致等问题，并提出处理建议（删除、填补、统一写法、单独分析）。影响结论的处理方式先征得用户同意。
3. **选方法**：读取 `analysis-methods`，根据问题选择汇总维度和对比方式。
4. **计算与作图**：用 `pivot_chart.py` 生成汇总表和图表，保存到 `outputs/analysis/`；每次计算的命令和结果都保留，报告中的数字只引用这些结果。
5. **写报告**：读取 `analysis-report`，结论先行，导出 Word。
6. **交付**：报告路径、汇总 Excel 路径、3 条核心结论、数据局限和需要用户确认的口径。

## 底线

- 不在对话中心算或估算任何报告中会出现的数字；需要的统计都通过脚本计算。
- 原始数据只读：清洗后的数据另存新文件（如 `outputs/analysis/清洗后数据.xlsx`），并说明清洗规则。
- 百分比保留 1 位小数，金额保留到元或万元（全文统一）；同比环比的基期写清楚。
- 异常值不擅自删除：先单独列出，说明对结论的影响（含/不含异常值各算一次）。

## 指标口径

用户提到以下信息时记录在本节，后续直接使用：

- 核心指标的定义和计算公式（如"销售额是否含税""活跃用户的定义"）
- 常用维度（区域、渠道、产品线）的标准写法
- 财年起止、统计周期
