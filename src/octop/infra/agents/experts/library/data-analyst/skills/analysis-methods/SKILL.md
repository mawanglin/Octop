# 分析方法

## 1. 问题 → 方法

| 业务问题 | 方法 | pivot_chart.py 用法 |
|----------|------|---------------------|
| 整体在涨还是跌？ | 趋势 + 同比环比 | `--date 日期 --period month` |
| 谁贡献最大？ | 构成占比 / 排名 | `--rows 维度 --values 指标` |
| 少数对象贡献了多少？ | 帕累托（前 20% 对象占多少） | `--rows 客户 --values 销售额`，按占比累加判断 |
| 不同组有没有差异？ | 分组对比（均值、计数） | `--rows 组别 --values 指标 --agg mean` |
| 两个维度的组合情况？ | 交叉分析 | `--rows A --columns B` |
| 涨跌由哪部分带来？ | 贡献度拆解：各组变化量 ÷ 总变化量 | 分别按时间和维度汇总后计算 |
| 目标完成得怎么样？ | 目标达成率 = 实际 ÷ 目标 | 汇总实际值后与目标表对比 |
| 用户在哪一步流失？ | 漏斗转化 | 按步骤计数，计算步骤间转化率 |

## 2. 解释波动的步骤

1. **确认是真波动**：排除口径变化、数据缺失、异常值、统计周期不同（天数、节假日）；
2. **拆维度**：按区域、渠道、产品、客户等维度拆分，找出变化最大的部分（贡献度）；
3. **找关联**：变化部分同期发生了什么（活动、价格、竞品、政策）——这一步需要用户提供业务信息；
4. **给结论**：写"主要由 ×× 带来（贡献 ××%），可能原因是 ××（待确认）"。

## 3. 指标口径

报告中的每个核心指标都写清：定义、计算公式、统计周期、数据来源、是否含税/退款。与用户确认后记录到 AGENTS.md 的「指标口径」。常见陷阱：
- 环比受天数影响（2 月天数少），必要时用日均值比较；
- 同比需要去年同期数据，数据不足一年时不能写同比；
- 均值受异常值影响大，同时给出中位数；
- 占比的分母要说清（占全部还是占某一类）。

## 4. 常用分析框架

- **5W2H**：What、Why、Who、When、Where、How、How much——梳理问题全貌；
- **杜邦分析**：净资产收益率 = 销售净利率 × 资产周转率 × 权益乘数——财务指标拆解；
- **AARRR**：获取、激活、留存、变现、推荐——用户增长；
- **对比四法**：与目标比、与去年比、与上期比、与同行比。
